# QC

make quality control of the reads data

+ [trim_low_quality](QC/trim_low_quality.1) removes the low quality reads
+ [trim_reads_headers](QC/trim_reads_headers.1) trim the primers or adapters sequence at read header region
+ [nano_plot](QC/nano_plot.1) make stats of the reads and export the nano plot formated stats result
+ [nano_report](QC/nano_report.1) generates the fastq reads QC summary text
