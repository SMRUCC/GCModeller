# gene_quantification

gene expression quantify tools

+ [read_featureCounts](gene_quantification/read_featureCounts.1) read feature counts tsv table file
+ [counts_matrix](gene_quantification/counts_matrix.1) make assemble of the reads sample counts as a gene expression matrix object
+ [deseq2_norm](gene_quantification/deseq2_norm.1) Apply DESeq2 Median of Ratios normalization method to the raw counts matrix.
+ [edgeR_norm](gene_quantification/edgeR_norm.1) Apply of the edgeR TMM factor normalization method to the raw counts matrix
+ [edgeR_tmm](gene_quantification/edgeR_tmm.1) get edgeR TMM factors
+ [gene_indexstats](gene_quantification/gene_indexstats.1) 
+ [read_genedata](gene_quantification/read_genedata.1) read gene data csv table file
+ [convert_to_tpm](gene_quantification/convert_to_tpm.1) make normalize of the feature counts data as TPM expression value
+ [expression_data](gene_quantification/expression_data.1)
