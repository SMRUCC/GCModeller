# bioseq.blast

Blast search tools

+ [blosum](bioseq.blast/blosum.1) Parse blosum from the given file data
+ [align.smith_waterman](bioseq.blast/align.smith_waterman.1) do the local pairwise sequence alignment via the smith-waterman 
+ [HSP](bioseq.blast/HSP.1) get the high score region(HSP) from the given alignment result
+ [align.needleman_wunsch](bioseq.blast/align.needleman_wunsch.1) do the global pairwise sequence alignment via the needleman-wunsch
