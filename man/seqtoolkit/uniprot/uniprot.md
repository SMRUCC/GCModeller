# uniprot

The Universal Protein Resource (UniProt)

+ [open.uniprot](uniprot/open.uniprot.1) open a uniprot database file
+ [parseUniProt](uniprot/parseUniProt.1) parse the uniprot xml document text data as the protein entry object 
+ [parseHeader](uniprot/parseHeader.1) Parse the uniprot fasta header text
+ [read.proteinTable](uniprot/read.proteinTable.1) read uniprot protein export output tsv file
+ [proteinTable](uniprot/proteinTable.1) export protein annotation data as data frame.
+ [get_domain](uniprot/get_domain.1) get the protein domain region annotation data from the given uniprot 
+ [get_sequence](uniprot/get_sequence.1) extract the protein sequence data from the given uniprot protein entry 
+ [get_description](uniprot/get_description.1) get the protein full name and function description text from the given 
+ [get_subcellularlocation](uniprot/get_subcellularlocation.1) get subcellular location of current protein
+ [get_pathways](uniprot/get_pathways.1) get related pathway names of current protein
+ [get_reactions](uniprot/get_reactions.1) get the catalytic activity reaction data of the given uniprot protein 
+ [get_xrefs](uniprot/get_xrefs.1) get external database reference id set
+ [get_keywords](uniprot/get_keywords.1) get keyword dataframe about the given protein data
+ [protein.seqs](uniprot/protein.seqs.1) populate all protein fasta sequence from the given uniprot database reader
+ [id_unify](uniprot/id_unify.1) id unify mapping
+ [metaboliteSet](uniprot/metaboliteSet.1) build the metabolite set collection from the catalytic activity
