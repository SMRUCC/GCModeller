# bioseq.patterns

Tools for sequence patterns

+ [open.seedFile](bioseq.patterns/open.seedFile.1) open the sequence seed scan data file
+ [pull.all_seeds](bioseq.patterns/pull.all_seeds.1) pull all of the sequence seed data from the given seed scan data file
+ [read.meme_xml](bioseq.patterns/read.meme_xml.1) read the xml motif data model output from the meme program
+ [toPWM](bioseq.patterns/toPWM.1) convert the meme document to motif PWM model object
+ [gibbs_scan](bioseq.patterns/gibbs_scan.1) make a motif scan from the given sequence collection
+ [view.sites](bioseq.patterns/view.sites.1) display the motif match sites on the given target sequence
+ [read.motifs](bioseq.patterns/read.motifs.1) read sequence motif json file.
+ [read.scans](bioseq.patterns/read.scans.1) read the motif match scan result table file
+ [top_sites](bioseq.patterns/top_sites.1) takes the top motif match sites by a set of the given filter threshold 
+ [as.seq_graph](bioseq.patterns/as.seq_graph.1) make the sequence graph embedding data of the given sequence collection
+ [motif.find_sites](bioseq.patterns/motif.find_sites.1) find the target loci match sites of the given sequence data based on 
+ [palindrome.mirror](bioseq.patterns/palindrome.mirror.1) Search mirror palindrome sites for a given seed sequence
+ [seeds](bioseq.patterns/seeds.1) create all of the possible seed sequence fragments of the given 
+ [motifString](bioseq.patterns/motifString.1) convert the given sequence motif object as a regexp liked format 
+ [create.seeds](bioseq.patterns/create.seeds.1) create the sequence seeds data from the given fasta sequence 
+ [find_motifs](bioseq.patterns/find_motifs.1) find possible motifs of the given sequence collection
+ [plot.seqLogo](bioseq.patterns/plot.seqLogo.1) Drawing the sequence logo just simply modelling this motif site 
+ [scaffold.orthogonality](bioseq.patterns/scaffold.orthogonality.1) analyses orthogonality of two DNA-Origami scaffold strands.
+ [split_match_source](bioseq.patterns/split_match_source.1) split the motif matches result in parts by its gene source
