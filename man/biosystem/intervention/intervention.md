# intervention

permutation experiment and analysis tools for the in silico gene perturbation experiment

+ [knockouts](intervention/knockouts.1) run the in silico gene knockout experiment on the given network model
+ [overexpress](intervention/overexpress.1) run the in silico gene overexpression experiment on the given network model
+ [knockdown](intervention/knockdown.1) run the in silico gene knockdown experiment on the given network model
+ [target_gene](intervention/target_gene.1) 
+ [make_exports](intervention/make_exports.1) export the virtual permutation result as csv table files
