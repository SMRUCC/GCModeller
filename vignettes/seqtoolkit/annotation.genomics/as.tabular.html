as.tabular {annotation.genomics} R Documentation

export the gene annotation data as the tabular format table object

Description

Usage

as.tabular(genes,
    title = "n/a",
    size = 0,
    format = "PTT|GFF|GTF");

Arguments

genes

a vector of the GeneBrief gene annotation object for export as the tabular table. [as GeneBrief]

title

the title text of the generated tabular table. [as string]

size

the genome size in bp of the generated tabular table. [as integer]

format

the tabular table format of the generated output. Only the PTT format is implemented at this moment. [as string]

env

the R# runtime environment object. [as Environment]

Details

Authors

seqtoolkit

Value

a PTT tabular table object of the given gene annotation data;

this function returns a R# error message object if the given table format is not supported.

clr value class
