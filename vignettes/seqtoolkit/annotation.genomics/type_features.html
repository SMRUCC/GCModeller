type_features {annotation.genomics} R Documentation

get the genomics features from the given gff table by its feature type

Description

Usage

type_features(gff, type);

Arguments

gff

a GFFTable genomics feature annotation table object for query the feature data. [as GFFTable]

type

the feature type of the target features, example as gene, CDS or mRNA. [as string]

Details

Authors

seqtoolkit

Value

a vector of the Feature genomics feature object that its feature type matches the given type name.

clr value class

  • Feature
