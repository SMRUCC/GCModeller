extract_gff_seqs {annotation.genomics} R Documentation

extract the sequence region data of the genomics features in the given

Description

gff3 table from the reference sequence data

Usage

extract_gff_seqs(gff3, seqs);

Arguments

gff3

a GFFTable genomics feature annotation table object, which provides the location region information of the target sequence extraction. [as GFFTable]

seqs

the reference sequence data source for extract the feature region sequence, which can be a FastaFile object, a collection of the FastaSeq object, or a character vector of the raw sequence data.

env

the R# runtime environment object. [as Environment]

Details

Authors

seqtoolkit

Value

a vector of the FastaSeq feature region sequence object;

this function returns NULL if the given reference sequence data can not be cast to a fasta sequence collection.

clr value class

  • any kind
