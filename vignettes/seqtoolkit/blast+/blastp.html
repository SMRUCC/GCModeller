blastp {blast+} R Documentation

Protein-Protein BLAST

Description

Usage

blastp(query, subject, output,
    evalue = 0.001,
    n.threads = 2);

Arguments

query

the file path of the query protein fasta sequence file. [as string]

subject

the file path of the subject protein sequence database file. [as string]

output

the file path of the blastp alignment result output file. [as string]

evalue

the e-value threshold of the accepted blastp hits. [as double]

n.threads

the thread number for run the blastp program. [as integer]

env

the R# runtime environment object. [as Environment]

Details

Authors

seqtoolkit

Value

a character value of the standard output log message of the blastp program run, and the alignment result data will be saved into the given output file.

clr value class

  • any kind
