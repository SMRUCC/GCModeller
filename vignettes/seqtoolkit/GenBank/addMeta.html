addMeta {GenBank} R Documentation

add metadata into a given feature object

Description

Usage

addMeta(feature, ...);

Arguments

feature

the target Feature genbank feature object for add the metadata. [as Feature]

meta

a R# list object of the metadata: the name of each list element is the qualifier name, and the element value is the qualifier value. [as list]

env

the R# runtime environment object. [as Environment]

Details

Authors

seqtoolkit

Value

the modified Feature genbank feature object.
