add.RNA.gene {GenBank} R Documentation

add the RNA gene feature data into the given genbank assembly by the

Description

blastn mapping result

Usage

add.RNA.gene(gb, RNA);

Arguments

gb

the File ncbi genbank assembly object for add the RNA gene feature data. [as File]

RNA

the blastn mapping result data of the RNA sequence, which can be a vector of the BlastnMapping object or a pipeline object that produces this mapping data.

env

the R# runtime environment object. [as Environment]

Details

Authors

seqtoolkit

Value

the modified File ncbi genbank assembly object;

this function returns a R# error message object if the input RNA mapping data is not a supported data model.
