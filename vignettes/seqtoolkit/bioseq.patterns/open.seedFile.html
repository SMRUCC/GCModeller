open.seedFile {bioseq.patterns} R Documentation

open the sequence seed scan data file

Description

Usage

open.seedFile(file);

Arguments

file

the file path of the seed scan data file, or a file stream object of the target seed scan data file.

env

the R# runtime environment object. [as Environment]

Details

Authors

seqtoolkit

Value

a ScanFile sequence seed data file object for read or save the seed data in a stream manner, which can be used by the pull.all_seeds api or the create.seeds api;

this function returns a R# error message object if the given file can not be opened for read/write.

clr value class

  • any kind
