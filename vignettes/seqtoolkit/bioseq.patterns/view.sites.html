view.sites {bioseq.patterns} R Documentation

display the motif match sites on the given target sequence

Description

Usage

view.sites(sites, seq,
    deli = ", ");

Arguments

sites

a collection of the motif match site data(Site) for display on the target sequence.

seq

the target sequence data for display the motif match sites, which can be a raw sequence text or a fasta sequence object.

deli

the delimiter string for display the sequence fragment of each match site. [as string]

env

the R# runtime environment object. [as Environment]

Details

Authors

seqtoolkit

Value

a character value of the formatted motif match site display text.

clr value class
