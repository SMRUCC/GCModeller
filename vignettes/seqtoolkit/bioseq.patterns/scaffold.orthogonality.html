scaffold.orthogonality {bioseq.patterns} R Documentation

analyses orthogonality of two DNA-Origami scaffold strands.

Description

Multiple criteria For orthogonality Of the two sequences can be specified<br /> to determine the level of orthogonality.

Usage

scaffold.orthogonality(scaffolds,
    segment.len = 7,
    is.linear = FALSE,
    rev.compl = FALSE);

Arguments

scaffolds

a collection of the DNA-Origami scaffold nucleotide sequences for evaluate the pairwise orthogonality, which can be a FastaFile object, a collection of the FastaSeq object, or a character vector of the raw sequence data.

segment.len

segment length. [as integer]

is.linear

scaffolds are not circular. [as boolean]

rev.compl

also count reverse complementary sequences. [as boolean]

env

the R# runtime environment object. [as Environment]

Details

Authors

seqtoolkit

Value

a vector of the Output orthogonality evaluation result: one result element for each of the scaffold sequence pair in the input sequence collection.
