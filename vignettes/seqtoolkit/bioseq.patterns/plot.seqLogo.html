plot.seqLogo {bioseq.patterns} R Documentation

Drawing the sequence logo just simply modelling this motif site

Description

from the clustal multiple sequence alignment.

Usage

plot.seqLogo(MSA,
    title = "");

Arguments

MSA

the multiple sequence alignment data for drawing the sequence logo, which can be a MSAOutput alignment result object, a SequenceMotif motif object, a MSAMotif gibbs sampler result, a Probability PWM model object, or a fasta sequence collection.

title

the title text of the generated sequence logo graphics. [as string]

env

the R# runtime environment object. [as Environment]

Details

Authors

seqtoolkit

Value

a GraphicsData graphics data object of the sequence logo, which can be saved as a image file via the bitmap or svg api.

clr value class
