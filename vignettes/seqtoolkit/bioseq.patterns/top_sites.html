top_sites {bioseq.patterns} R Documentation

takes the top motif match sites by a set of the given filter threshold

Description

values

Usage

top_sites(sites,
    identities = NULL,
    pvalue = NULL,
    minW = NULL);

Arguments

sites

a vector of the MotifMatch motif match scan result for make the filter. [as MotifMatch]

identities

the minimum identity threshold value of the accepted motif matches. [as double]

pvalue

the maximum p-value threshold of the accepted motif matches. [as double]

minW

the minimum motif width of the accepted motif matches. [as integer]

Details

Authors

seqtoolkit

Value

a vector of the MotifMatch object that contains the accepted motif match sites: the input motif matches will be passed through each of the specified filter thresholds in turn, and only the matches that satisfies all of the specified threshold conditions will be kept in the returned result.

clr value class

  • MotifMatch[]
