seeds {bioseq.patterns} R Documentation

create all of the possible seed sequence fragments of the given

Description

alphabet base letters

Usage

seeds(size, base);

Arguments

size

the seed length in chars, i.e. the k value of the k-mer seeds. [as integer]

base

a character value of the sequence alphabet letters, example as ACGT for the nucleotide sequence. [as string]

Details

Authors

seqtoolkit

Value

a character vector of all of the possible combination of the seed sequence fragments, and the size of the generated seed collection is len(base) ^ size.

clr value class

  • string
