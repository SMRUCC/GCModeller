ligands {proteinKit} R Documentation

list the small molecule ligand compound data from the given protein

Description

structure object

Usage

ligands(pdb,
    key = NULL,
    number = -1);

Arguments

pdb

a PDB protein structure object for list its ligand compound data. [as PDB]

key

the compound name for filter the ligand data. [as string]

number

the sequence number of the target ligand for filter the ligand data, a negative value means no filter. [as integer]

Details

Authors

seqtoolkit

Value

a vector of the HETRecord ligand compound object when no filter condition is specified, or the single ligand compound object that matches the given compound name and sequence number.

clr value class

  • HETRecord
