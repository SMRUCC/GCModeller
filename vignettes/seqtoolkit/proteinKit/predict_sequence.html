predict_sequence {proteinKit} R Documentation

generate the protein sequence data from the given EC number via the

Description

enzyme transformer model

Usage

predict_sequence(model, ec.number);

Arguments

model

a TransformerModel enzyme protein sequence model, which is created by the enzyme_builder api. [as TransformerModel]

ec.number

a character vector of the enzyme commission(EC) number for generate the corresponding protein sequence data.

env

the R# runtime environment object. [as Environment]

Details

Authors

seqtoolkit

Value

a vector of the generated FastaSeq protein sequence object, one sequence element for each of the given EC number.

clr value class

  • FastaSeq
