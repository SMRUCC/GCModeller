pdb_centroid {proteinKit} R Documentation

get the geometry center coordinates of the given protein structure

Description

object

Usage

pdb_centroid(pdb,
    as.vector = FALSE);

Arguments

pdb

a PDB protein structure object for evaluate its centroid coordinates. [as PDB]

as.vector

returns the centroid coordinates as a numeric vector? if this parameter is FALSE(the default value), then a Point3D coordinates object will be returned. [as boolean]

Details

Authors

seqtoolkit

Value

the centroid coordinates of the given protein structure object.

clr value class
