hmmer_search {hmmer} R Documentation

run the HMMER profile HMM search for protein function annotation

Description

Usage

hmmer_search(hmmer, x);

Arguments

hmmer

a ProteinAnnotator object that contains the loaded HMMER3 profile models, which is created by the load_hmmer api. [as ProteinAnnotator]

x

a protein fasta sequence collection for run the HMMER search, which can be a FastaFile object, a collection of the FastaSeq object, or a character vector of the raw sequence data.

env

the R# runtime environment object. [as Environment]

Details

Authors

seqtoolkit

Value

a lazy pipeline collection of the AnnotationResult domain annotation result, one result element for each of the profile HMM hit that found in the input protein sequence collection;

this function returns NULL if the input sequence data can not be cast to a fasta sequence collection.

clr value class

  • AnnotationResult
