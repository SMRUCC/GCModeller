parse_kofamscan {hmmer} R Documentation

Parse the kofamscan table output

Description

Usage

parse_kofamscan(file);

Arguments

file

the input source: a file path of the kofamscan annotation table output file, or a file stream object of the target table file.

env

the R# runtime environment object. [as Environment]

Details

Authors

seqtoolkit

Value

a lazy pipeline collection of the KOFamScan KEGG orthology annotation result record object;

this function returns a R# error message object if the given file can not be opened for read.
