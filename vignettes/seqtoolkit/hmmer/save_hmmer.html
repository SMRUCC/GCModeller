save_hmmer {hmmer} R Documentation

save the hmmer profile HMM model collection as a model package

Description

archive file(*.zip)

Usage

save_hmmer(hmmer, file);

Arguments

hmmer

a ProteinAnnotator object that contains the loaded HMMER3 profile models. [as ProteinAnnotator]

file

the file path of the target model package archive file(*.zip) for save the model data. model data will be saved in binary format inside the zip archive for get the maximum of the io performance. [as string]

env

the R# runtime environment object. [as Environment]

Details

Authors

seqtoolkit

Value

the file path of the created model package archive file.
