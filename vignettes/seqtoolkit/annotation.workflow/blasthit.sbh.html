blasthit.sbh {annotation.workflow} R Documentation

Export single side besthit

Description

Usage

blasthit.sbh(query,
    idetities = 0.3,
    coverage = 0.5,
    topBest = FALSE,
    keepsRawName = FALSE);

Arguments

query

the blast reader result from the read.blast iterator function. [as pipeline]

idetities

the minimum identity threshold value of the accepted hits. [as double]

coverage

the minimum coverage threshold value of the accepted hits. [as double]

topBest

only export the top best hit for each query?. [as boolean]

keepsRawName

keep the raw query name text in the exported best hit data?. [as boolean]

env

the R# runtime environment object. [as Environment]

Details

Authors

seqtoolkit

Value

a lazy pipeline collection of the BestHit single side best hit result;

this function returns a R# error message object if the input query pipeline data type is not the Query object.
