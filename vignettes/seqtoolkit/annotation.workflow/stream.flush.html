stream.flush {annotation.workflow} R Documentation

Save the annotation rawdata into the given stream file.

Description

Usage

stream.flush(data, stream);

Arguments

data

a lazy pipeline collection of the annotation data for write into the target stream file, the supported data element types are: BestHit, BiDirectionalBesthit, BlastnMapping and RankTerm. [as pipeline]

stream

a stream data handler that generated via the open.stream function.

env

the R# runtime environment object. [as Environment]

Details

Authors

seqtoolkit

Value

this function returns a R# error message object if the output stream device is nothing, the input data is nothing, or the stream device type is not matched with the incoming data type.

clr value class

  • any kind
