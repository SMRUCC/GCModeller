blastn.maphit {annotation.workflow} R Documentation

export results of fastq reads mapping to genome sequence.

Description

Usage

blastn.maphit(query,
    top.best = FALSE);

Arguments

query

a lazy pipeline collection of the blast query hits result (Query), which is created by the read.blast api. [as pipeline]

top.best

only export the top best mapping for each query?. [as boolean]

env

the R# runtime environment object. [as Environment]

Details

Authors

seqtoolkit

Value

a lazy pipeline collection of the BlastnMapping reads mapping result;

this function returns a R# error message object if the input query pipeline data type is not the Query object.
