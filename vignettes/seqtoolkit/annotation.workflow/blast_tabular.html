blast_tabular {annotation.workflow} R Documentation

cast the blastn tabular format hits result as a data frame object

Description

Usage

blast_tabular(hits, args);

Arguments

hits

a vector of the blastn tabular format hit record (HitRecord) for cast as the data frame. [as HitRecord]

args

the additional arguments for the data frame cast, this parameter is not used in this function. [as list]

env

the R# runtime environment object. [as Environment]

Details

Authors

seqtoolkit

Value

a data frame object of the blastn hits result: each row is one hit, and the columns are the hit details: query_id, subject_id, identities, alignment_length, mis_matches, gap_opens, query_start, query_end, subject_start, subject_end, e_value and bit_score.

clr value class

  • any kind
