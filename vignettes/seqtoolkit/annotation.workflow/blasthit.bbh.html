blasthit.bbh {annotation.workflow} R Documentation

export the bi-directional best hit(BBH) result from the given forward

Description

and reverse best hit data streams

Usage

blasthit.bbh(forward, reverse,
    algorithm = Naive);

Arguments

forward

a lazy pipeline collection of the forward direction hits data, which could be the raw query(Query) stream, the single side best hit(BestHit) stream, or the diamond m8 annotation (DiamondAnnotation) stream. [as pipeline]

reverse

a lazy pipeline collection of the reverse direction hits data, which accepts the same data models as the forward parameter. [as pipeline]

algorithm

the BBH match algorithm of the bi-directional best hit search. [as BBHAlgorithm]

env

the R# runtime environment object. [as Environment]

Details

Authors

seqtoolkit

Value

a lazy pipeline collection of the BiDirectionalBesthit bi-directional best hit result;

this function returns a R# error message object if the input data streams are nothing or their element types are not supported.
