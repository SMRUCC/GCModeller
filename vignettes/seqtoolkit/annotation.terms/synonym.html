synonym {annotation.terms} R Documentation

query the id synonyms of the given id list from the id mapping solver

Description

object

Usage

synonym(idlist, idmap,
    excludeNull = FALSE);

Arguments

idlist

a character vector of the query id for get its synonyms. [as string]

idmap

a SecondaryIDSolver id mapping solver object, which is created by the read.id_maps api. [as SecondaryIDSolver]

excludeNull

remove the query id which has no synonym data from the result?. [as boolean]

Details

Authors

seqtoolkit

Value

a vector of the Synonym id synonym query result object.
