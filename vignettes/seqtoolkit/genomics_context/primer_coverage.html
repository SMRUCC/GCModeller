primer_coverage {genomics_context} R Documentation

evaluate the primer hit coverage of the candidate primer regions on the

Description

given chromosome context

Usage

primer_coverage(targetHits, chr, chr.seq);

Arguments

targetHits

a vector of the NucleotideLocation primer hit location data on the target chromosome. [as NucleotideLocation]

chr

a GenomeContext genomics context object of the target chromosome, which provides the gene context information of the candidate primer regions. [as GenomeContext`1]

chr.seq

the sequence data slicer object of the target chromosome for extract the sequence region data, which can be created by the slicer api. [as ISlicer]

a vector of the PrimerCoverage primer hit coverage analysis result object.
