TSS_upstream {genomics_context} R Documentation

get TSS upstream site sequence data

Description

Usage

TSS_upstream(genome,
    genes = NULL,
    upstream.len = 150,
    simple.title = TRUE);

Arguments

genome

the genome reference sequence data source, which can be a File ncbi genbank assembly object or a FastaSeq nucleotide sequence object.

genes

gene list could be omit if the input genome data is a ncbi genbank model object. then all gene features inside the input genbank assembly will be used for export of the TSS upstream site.

upstream.len

the length in nucleotide of the TSS upstream region. [as integer]

simple.title

generate the fasta headers title of the output sequence in a simple format?. [as boolean]

env

the R# runtime environment object. [as Environment]

Details

Authors

seqtoolkit

Value

a vector of the FastaSeq TSS upstream region nucleotide sequence data, one sequence element for each of the target gene;

this function returns NULL if the input genome data is nothing, or a R# error message object if the given genome data type is not supported.

clr value class

  • any kind
