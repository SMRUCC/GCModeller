relationship {genomics_context} R Documentation

get the segment relationship of two location

Description

Usage

relationship(a, b);

Arguments

a

the first location for evaluate the segment relationship, which can be a gene model object(IGeneBrief), a contig object(Contig), or a NucleotideLocation nucleotide location object.

b

the second location for evaluate the segment relationship, which accepts the same data models as the a parameter.

env

the R# runtime environment object. [as Environment]

Details

Authors

seqtoolkit

Value

a SegmentRelationships segment relationship enum value of the given two location regions;

this function returns a R# error message object if the given location data can not be cast to a nucleotide location object.

clr value class

  • SegmentRelationships
