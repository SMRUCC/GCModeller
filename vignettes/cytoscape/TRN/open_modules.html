open_modules {TRN} R Documentation

read the WGCNA module map sidecar cache that was written by `write_bicor`

Description

Usage

open_modules(repo);

Arguments

repo

the same data repository directory that was passed to write_bicor (reads {repo}/modules.dat). [as string]

env

the R# runtime environment object. [as Environment]

Details

pass the returned object to build_grn via the modules parameter to skip the WGCNA blockwise module detection. Note that the cache carries a fingerprint (gene id row order + WGCNA configuration); when it does not match the current data, build_grn will ignore it and rebuild automatically.

Authors

cytoscape

Value

the cached module map object, or Nothing when the cache file does not exist (in that case build_grn will fall back to running the WGCNA blockwise module detection and write the cache automatically).

clr value class

  • WGCNAModuleMap

Examples

 let modules = open_modules("Z:/hsa_mat");
 let grn = WGCNA::build_grn(hsa, TF$Ensembl, opts, bicor = bicor, modules = modules);
