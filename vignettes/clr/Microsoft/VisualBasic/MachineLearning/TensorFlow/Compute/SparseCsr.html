SparseCsr {Microsoft.VisualBasic.MachineLearning.TensorFlow.Compute} .NET clr documentation

SparseCsr

Description

CSR 稀疏矩阵载体（行 = 突触前，列 = 突触后）。 承载 ITensorCompute.SpMM() 算子所需的全部稀疏结构信息。

Declare

            
# namespace Microsoft.VisualBasic.MachineLearning.TensorFlow.Compute
export class SparseCsr {
   # 非零元素的列索引（长度 = 非零数，每段内非降序）
   ColumnIndices: integer;
   # 突触后神经元数量（矩阵列数）
   Columns: integer;
   # 非零元素（突触）数量
   NonZeros: integer;
   # 行偏移数组（长度 Rows+1，单调非降，首元素 0、末元素 = 非零数）
   RowPointers: integer;
   # 突触前神经元数量（矩阵行数）
   Rows: integer;
   # 非零元素的权重（长度 = 非零数；就地修改后必须调用 SparseCsr.MarkModified())
   Values: double;
   # 数据版本号。任何就地修改 SparseCsr.Values 之后都应调用 SparseCsr.MarkModified() 使其自增，供设备端缓存判断失效。
   Version: integer;
}
