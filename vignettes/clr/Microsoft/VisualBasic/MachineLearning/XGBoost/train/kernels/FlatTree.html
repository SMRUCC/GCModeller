FlatTree

Description

扁平化（编译后）的树，用于批量预测。

旧实现的预测路径是「每棵树一次 PLINQ + 每样本一个 PredictCallable 对象 + OrderBy 排序」， 复杂度 O(T · N log N) 且产生 T × N 次堆分配。编译后每个节点只占用几条平行数组， 预测变成纯粹的整数索引跳转与一次浮点比较，整体降为 O(T · N) 且零分配。
