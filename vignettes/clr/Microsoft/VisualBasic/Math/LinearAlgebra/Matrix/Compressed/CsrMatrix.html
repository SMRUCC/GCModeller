CsrMatrix {Microsoft.VisualBasic.Math.LinearAlgebra.Matrix.Compressed} .NET clr documentation

CsrMatrix

Description

压缩行存储（Compressed Sparse Row, CSR）稀疏矩阵。

内部由三个平行数组构成：indptr（长度 rows + 1）、indices（列下标）、 values（元素值）。第 i 行的非零元素位于 indices(indptr(i)) .. indices(indptr(i + 1) - 1)，且同一行内的列下标严格升序， 因此单行的列定位是 O(log nnz_row) 的二分查找。

与 SparseMatrix（字典套字典）不同，本类型是"可计算的矩阵"： 三次稀疏矩阵-向量乘法、稀疏×稀疏、转置、行/列子集都只依赖 nnz 的单遍扫描， 不会把内部结构稠密化。适用于单细胞计数矩阵（1e7 以上非零元）这类规模。

本类型是不可变容器：所有"修改类"操作（CsrMatrix.EliminateZeros()、CsrMatrix.ScaleRows()、 CsrMatrix.Slice() 等）都返回新实例，不会改写当前实例， 因此可以安全地被多个线程共享读取（批量统计算子的并行只读前提）。
