ODESolution

Description

ODEs output, this object can populates the ODESolution.y variables values through its enumerator interface. (常微分方程求解结果，同时也是所有求解器 —— 内建求解器与外部插件求解器 —— 的统一输出模型)

除了原来的 x / y / y0 / params 之外，这个类型还提供了与具体求解器无关的 通用访问接口（ODESolution.Count、ODESolution.Item、ODESolution.GetComponent()、 ODESolution.ToCSV()），因此像 Sundials.CVODE 这类只知道「N 维状态向量」的求解器也可以直接 使用它来输出结果，而不需要为每个求解器维护一套独立的结果类型。

注意：ODESolution.y 是按键排序的字典（SortedDictionary(Of String, T)）， 所以列顺序必须通过 ODESolution.columnNames 显式指定，不能依赖 ODESolution.y 的枚举顺序。

# namespace Microsoft.VisualBasic.Math.Calculus.Dynamics.Data
export class ODESolution {
   # The column order of ODESolution.y: the index of this array is the state variable index, when this value is not presented the key order of ODESolution.y will be used. (列顺序，按状态变量序号排列；未指定的时候使用 y 的键顺序)
   columnNames: string;
   # The number of the sampling points of the integration result.(采样点个数)
   Count: integer;
   # 得到进行积分的步进值，采样点不足的时候返回零
   dx: double;
   # Is there NAN value in the function value ODESolution.y ???
   HaveNaN: boolean;
   # The solver specific diagnostics, e.g. the integration steps, the right-hand side evaluations of the external solvers. (求解器诊断信息)
   info: list;
   params: list;
   # 获取得到积分计算的分辨率的数值，采样点不足的时候返回零
   Resolution: double;
   # The sampling time points of the integration result.(积分结果的采样时间点)
   x: double;
   # The result series of each state variable, the key is the variable name. (各个状态变量的结果序列，键为变量名称)
   y: list;
   # 方程组的初始值，积分结果会受到初始值的极大的影响
   y0: list;
}
