ODESolverMethod {Microsoft.VisualBasic.Math.Calculus.Dynamics} .NET clr documentation

ODESolverMethod

Description

The available integration algorithms of the ODEs dynamics system. (常微分方程组可用的积分算法)

方法阶数类型适用
ODESolverMethod.Euler1显式固定步长教学 / 快速原型
ODESolverMethod.RK22显式固定步长一般用途
ODESolverMethod.Gill4显式固定步长长时程积分(舍入误差累积较小)
ODESolverMethod.RK44显式固定步长默认推荐
ODESolverMethod.ABM44显式多步预测-校正光滑非刚性问题的批量仿真
ODESolverMethod.BackwardEuler1隐式(L-稳定)强刚性问题
ODESolverMethod.Trapezoidal2隐式(A-稳定)一般刚性问题
ODESolverMethod.BDF22隐式刚性问题
ODESolverMethod.RosenbrockROS22线性隐式(L-稳定)刚性问题(无需 Newton 迭代)
ODESolverMethod.RK233(2)自适应显式粗略/低频仿真
ODESolverMethod.RK455(4)自适应显式高精度通用
ODESolverMethod.Verlet2辛几何哈密顿系统(位置/动量可分裂)
ODESolverMethod.Yoshida44辛几何哈密顿系统(高精度能量守恒)

Declare

            
# namespace Microsoft.VisualBasic.Math.Calculus.Dynamics
export class ODESolverMethod extends Enum {
   # Forward Euler method, 1st order.(前向欧拉法)
   Euler: ODESolverMethod = 0;

   # The improved Euler (Heun) method, 2nd order.(改进欧拉法)
   RK2: ODESolverMethod = 1;

   # The 4-stage 4th order Gill method, it has a smaller round-off accumulation than RK4. (四阶 Gill 方法，舍入误差累积较小)
   Gill: ODESolverMethod = 2;

   # The classical 4-stage 4th order Runge-Kutta method.(经典四阶龙格库塔法)
   RK4: ODESolverMethod = 3;

   # The 4th order Adams-Bashforth-Moulton predictor-corrector method.(四阶阿当姆斯预测-校正法)
   ABM4: ODESolverMethod = 4;

   # The implicit backward Euler method (BDF1), L-stable.(隐式后向欧拉法)
   BackwardEuler: ODESolverMethod = 5;

   # The implicit trapezoidal rule (Crank-Nicolson), A-stable.(隐式梯形法)
   Trapezoidal: ODESolverMethod = 6;

   # The 2nd order backward differentiation formula, it is suitable for the stiff problems. (二阶后向微分公式)
   BDF2: ODESolverMethod = 7;

   # The 2-stage 2nd order L-stable Rosenbrock method (linearly implicit).(二阶线性隐式方法)
   RosenbrockROS2: ODESolverMethod = 8;

   # The Bogacki-Shampine 3(2) adaptive step size method.(自适应 RK23 方法)
   RK23: ODESolverMethod = 9;

   # The Dormand-Prince 5(4) adaptive step size method.(自适应 RK45 方法)
   RK45: ODESolverMethod = 10;

   # The 2nd order Stormer-Verlet symplectic method.(二阶辛几何算法)
   Verlet: ODESolverMethod = 11;

   # The 4th order Yoshida composition of the Stormer-Verlet method.(四阶吉田分解)
   Yoshida4: ODESolverMethod = 12;

}
