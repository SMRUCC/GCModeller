VirtualCellModel

Description

可持久化的虚拟细胞模型：参数 + 三个 view 的摘要 + 对照矩阵 + 细胞元数据。

保存的是"装配结果"，不是原始 CSV：加载之后可以直接跑 ContextPipeline.Predict，无需再解析 4.6 GB 表达矩阵。

版本与基因轴指纹在加载时严格校验：换了一套基因轴却复用旧模型，会让面板与矩阵错位， 这种错误在数值上表现为"结果看起来还行但完全不对"，必须在入口处拒绝。

Declare

            
# namespace SMRUCC.genomics.Analysis.VirtualCellular.Model
export class VirtualCellModel {
   # 训练摘要（三个 view）。
   Bundle: SummaryBundle;
   CellCount: integer;
   # 细胞轴（barcode）。
   Cells: string;
   # 对照矩阵（细胞 × 基因）。
   Controls: CsrMatrix;
   GeneCount: integer;
   # 基因轴。
   Genes: string;
   # 构建清单。
   Manifest: ModelManifest;
   # 细胞元数据。
   Metadata: CellMetadata;
   # CellularAI 参数。
   Options: CellularAiModel;
   # 全部伪扰动名（各 view 的并集，保持首次出现顺序）。
   Perturbations: string;
}
