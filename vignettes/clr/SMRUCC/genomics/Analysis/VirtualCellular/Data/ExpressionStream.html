ExpressionStream

Description

流式装配：把一个"基因 × 细胞"的 CSV 变成 CellularAI 需要的"细胞 × 基因"对照矩阵。

流程只有一次磁盘扫描：先读表头拿到细胞轴，再让 Document.StreamRows() 逐行吐出基因，直接交给 AsCsrMatrix 转置成"细胞 × 基因"的 CSR。

基因轴怎么来：转换函数只返回矩阵、不返回行名，因此在枚举外层套一个 "记录 + 透传"的迭代器（ExpressionStream.Trace()）在同一个枚举过程中收集 geneID， 既不二次遍历，也不把行缓存下来。

列过滤：Document.StreamRows() 只支持"排除列"， 因此按期别过滤时把"不保留的 barcode"整体作为 excludes 传进去， 行内的 experiments 会自动只包含保留列。

# namespace SMRUCC.genomics.Analysis.VirtualCellular.Data
export class ExpressionStream {
   # 细胞轴（顺序 = 保留列顺序）。
   Cells: string;
   # 对照矩阵：细胞 × 基因。
   Controls: CsrMatrix;
   # 基因轴（顺序 = CSV 行序）。
   Genes: string;
   # 细胞元数据。
   Metadata: CellMetadata;
   # 没有元数据记录的细胞。
   MissingMetadata: string;
   # 实际使用的期别过滤（未过滤时为空数组）。
   StageFilter: string;
}
