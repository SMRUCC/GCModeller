CellMetadata

Description

细胞级元数据：barcode → 患者 / 期别 / 组织类型 / 分组。

元数据表用 SampleInfo 承载（与 ExperimentDesigner 的模板一致）， 通过 LoadCsv(Of SampleInfo) 反序列化：ID/sample_name/sample_info 落到强类型属性，其余列（patient_id、stage、type、group 等） 由读取器自动收进 SampleInfo.metadata 字典。

为什么保留原始 SampleInfo 而不是先拍平成 POCO：不同数据集的元数据列并不统一， 拍平会丢掉未知列；保留下字典之后，CellMetadata.ValueOf() 可以按名字取任意列， 而强类型字段（ID / sample_name）仍然可用。
