CellularAIPerturbation

Description

基于 CellularAI 的虚拟扰动实验：把 KO / KD / OE 映射成合成作业的方向与强度。

扰动的两个来源：

  1. 自身靶：直接给定目标基因的 log2 变化方向与强度（OE 取正、KO 取强负、KD 取弱负）；
  2. 下游响应：从模型的 signature view 取该基因的"高表达签名"面板，

作为其他基因的效应方向（联合过表达时把多个签名叠加）。

合成完全走 CellularAI 的 SynthesisEngine + CellSynthesizer， 因此计数守恒、2²⁴ 上限、同 seed 可复现这些约束与算法层一致。
