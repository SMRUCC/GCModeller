SSystemNetwork {SMRUCC.genomics.Analysis.SGrid.GRN} .NET clr documentation

SSystemNetwork

Description

The fitted S-system gene regulatory network model. (拟合得到的基因表达调控网络模型)

本对象是 SGrid 的门面类型：它同时持有

  1. 预处理之后的时序数据 SSystemNetwork.Series
  2. 动力学参数 SSystemNetwork.Parameters
  3. 稀疏化之后的调控拓扑 SSystemNetwork.Edges

并且可以生成可以直接被 PLAS 运行的 S-system 模型对象。

Declare

            
# namespace SMRUCC.genomics.Analysis.SGrid.GRN
export class SSystemNetwork {
   # 稀疏化之后的有向调控边集合
   Edges: RegulatoryEdge[];
   # 本次拟合所使用的配置
   Options: FittingOptions;
   # 拟合得到的动力学参数
   Parameters: SSystemParameters;
   # 本次拟合所使用的先验知识网络（基因符号已经映射到规整化之后的编号）
   Prior: PriorNetwork;
   # 先验知识与拟合拓扑之间的对照指标；没有启用先验的时候为空
   PriorStatistics: PriorMetrics;
   # 预处理之后的基因表达时序数据
   Series: ExpressionTimeSeries;
   # 拟合过程的诊断信息
   Warnings: iterates(String);
}
