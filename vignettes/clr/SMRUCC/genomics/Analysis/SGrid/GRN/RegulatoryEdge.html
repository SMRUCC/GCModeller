RegulatoryEdge {SMRUCC.genomics.Analysis.SGrid.GRN} .NET clr documentation

RegulatoryEdge

Description

A directed regulatory interaction edge of the gene regulatory network. (基因调控网络之中的一条有向调控边)

边的权重取净调控弹性 g_ij - h_ij：为正表示源基因激活靶基因， 为负表示源基因抑制靶基因，零表示不存在调控关系。

Declare

            
# namespace SMRUCC.genomics.Analysis.SGrid.GRN
export class RegulatoryEdge {
   # 合成项之中的动力学阶 g_ij
   g: double;
   # 降解项之中的动力学阶 h_ij
   h: double;
   # 调控的类型：激活或者抑制
   interaction: string;
   # 先验知识所记录的置信度（0~1，零表示没有先验支持）
   PriorConfidence: double;
   # 本条调控关系是否在先验知识之中有记录
   PriorSupported: boolean;
   # 先验知识所记录的调控方向（Activator/Inhibitor/Unknown）
   PriorType: string;
   # 稀疏化排序时施加的先验加权（0 表示没有先验支持）
   PriorWeight: double;
   # 调控因子的基因编号
   source: string;
   # 靶基因的基因编号
   target: string;
   # 净调控弹性 g_ij - h_ij
   weight: double;
}
