ModulePriorNetwork {SMRUCC.genomics.Analysis.CellPhenotype.RegulationNetwork} .NET clr documentation

ModulePriorNetwork

Description

单个 WGCNA 模块的先验调控网络

ModulePriorNetwork.moduleNetwork 只含模块内部的调控边； ModulePriorNetwork.crossModule 含以本模块基因为上游（TF）、指向其他模块基因的跨模块边。 这样每条跨模块边只归属一个模块，合并时不会重复。

Declare

            
# namespace SMRUCC.genomics.Analysis.CellPhenotype.RegulationNetwork
export class ModulePriorNetwork {
   # 本模块的全部调控边（模块内 + 跨模块）
   allEdges: iterates(RegulatoryEdge);
   # 以本模块基因为上游的跨模块先验调控网络
   crossModule: PriorNetwork;
   # 该模块包含的基因 ID
   genes: string;
   # WGCNA 模块名称
   moduleName: string;
   # 模块内的先验调控网络
   moduleNetwork: PriorNetwork;
   # 构建过程统计
   statistics: ModuleStatistics;
}
