GRNBuildResult {SMRUCC.genomics.Analysis.CellPhenotype.RegulationNetwork} .NET clr documentation

GRNBuildResult

Description

基因表达调控先验网络的构建结果：按 WGCNA 模块拆分的 PriorNetwork 集合

每个 ModulePriorNetwork 持有一个 PriorNetwork， 其 PriorNetwork.Edges 元素类型为 RegulatoryEdge。 需要单一网络的下游算法（DBN / GNN）可直接调用 GRNBuildResult.ToPriorNetwork() 合并。

Declare

            
# namespace SMRUCC.genomics.Analysis.CellPhenotype.RegulationNetwork
export class GRNBuildResult {
   # 全部调控边（模块内 + 跨模块）
   allEdges: iterates(RegulatoryEdge);
   # 按 WGCNA 模块拆分的先验网络集合
   modules: ModulePriorNetwork[];
   # 汇总统计
   summary: BuildSummary;
   # 本次构建使用的 WGCNA 分析结果（含 TOM、模块划分、eigengene 等）
   wgcna: Result;
}
