CodonUsageProfile

Description

The codon usage profile of a gene collection (the relative codon frequencies and amino acid frequencies). This is the c(x, y, z) reference class data used by the B(F|C) bias measure (see CodonBiasMeasure) and the f^H(codon) reference set of the CAI (see CodonWeightTable).

Declare

            
# namespace SMRUCC.genomics.Analysis.SequenceTools.DNA_Comparative.DeltaSimilarity1998
export class CodonUsageProfile {
   # the display name of the gene collection
   Name: string;
   # Total number of counted codons.
   TotalCodons: integer;
}
