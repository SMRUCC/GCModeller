CodonWeightTable

Description

CODON ADAPTATION INDEX (CAI, Sharp & Li) weight table.

This specifies a reference set of genes, H, chosen from among "highly expressed genes". Defining

    w(codon) = f^H(codon) / max_{synonyms} f^H(.)

as the ratio of the frequency of the codon to the maximal codon frequency in H for the same amino acid, the CAI of a gene of length L is taken as

    CAI(gene) = (w1 * w2 * ... * wL)^(1/L)

(the geometric mean, computed numerically through the log-average).

This is a two-step API: first build the w table from the reference gene set H (this class), then evaluate the target genes (see CodonAdaptationIndexEvaluation.CAI()).

(compatible rename of the legacy RelativeCodonBiases class, which mistakenly used each single ORF as its own reference set and thus always produced CAI values close to 1)
