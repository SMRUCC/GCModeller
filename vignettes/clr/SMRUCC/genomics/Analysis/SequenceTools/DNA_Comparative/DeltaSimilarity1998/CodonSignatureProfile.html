CodonSignatureProfile

Description

The codon signature profile of a gene collection: per-site nucleotide counts, site-specific dinucleotide counts, codon counts and the derived codon signature odds ratios {rhoXY(1,2)}, {rhoYZ(2,3)}, {rhoXZ(1,3)}, {rhoZW(3,4)}.

Declare

            
# namespace SMRUCC.genomics.Analysis.SequenceTools.DNA_Comparative.DeltaSimilarity1998
export class CodonSignatureProfile {
   # Total number of valid codons (no ambiguous base) counted in the profile.
   Codons: integer;
   # Total number of valid codon junctions (3, 4) counted in the profile.
   Junctions: integer;
   # the display name of the gene collection
   Name: string;
}
