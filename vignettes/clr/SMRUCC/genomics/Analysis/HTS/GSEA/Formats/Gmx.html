Gmx

Description

GMX: Gene Matrix file format (*.gmx)

The GMX format is the transposed variant of the Gmt format: in the GMX format each column represents a gene set, while in the GMT format each row represents a gene set.

The GMX format uses tabs to separate the fields, and the file layout is:

  1. (gene set name 1) (TAB) (gene set name 2) ... (TAB) (gene set name N)
  2. (description 1) (TAB) (description 2) ... (TAB) (description N)
  3. (gene 1 of each gene set) ...

The member genes are read row by row from the third line, an empty cell in a column means that the current gene set has no more member gene at this row.

Note that the description line is a required part of the file format: if it is missing then the member genes would be read as the description data, and the parsed result will contains no gene set at all(numberOfSets is zero).
