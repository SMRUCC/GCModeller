MatrixViewer

Description

the abstract viewer model of the in-memory matrix object and the huge binary matrix file

这里定义了"矩阵视图"的最小契约：既可以被内存之中的 Matrix 实现 （HTSMatrixViewer），也可以被磁盘上的超大型二进制文件实现 （HTSMatrixReader），上层算法只依赖本抽象即可在"全内存"与 "按需读取"之间自由切换。

新增的 MatrixViewer.GetRow()、MatrixViewer.GetRows()、 MatrixViewer.Rows()、MatrixViewer.GetSample() 都以可覆盖的默认实现提供 （默认实现退化为逐基因查询），因此既有的子类不会被破坏， 而随机访问型的实现可以覆盖它们拿到 O(1) 或 O(块) 的性能。
