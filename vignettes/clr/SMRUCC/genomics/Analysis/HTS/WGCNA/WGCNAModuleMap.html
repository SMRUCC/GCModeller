WGCNAModuleMap {SMRUCC.genomics.Analysis.HTS.WGCNA} .NET clr documentation

WGCNAModuleMap

Description

WGCNA 模块映射的持久化缓存（边车文件）

bicor 相关矩阵存储（CorrelationMatrixStore）缓存了原始的 N×N 带符号 相关矩阵之后，先验调控网络构建（如 CellPhenote 的 ExpressionGRNBuilder 存储驱动重载）从 WGCNA 结果中只消费 Result.modules 模块映射表—— hub 截断用连接度现算、跨模块边不构建，因此 TOM（N=5 万时约 10GB）与 network 图等大对象不需要、也不应该被缓存。

缓存的正确性依据：blockwise 预聚类的 randomSeed 默认固定（12345）， 同一份数据 + 同一套 WGCNA 配置 = 确定性的模块划分。 WGCNAModuleMap.fingerprint 携带基因 ID 行序与 WGCNA 关键配置的哈希， WGCNAModuleMap.Validate() 不匹配时调用方应放弃缓存并重新计算。

文件格式：Brotli 压缩的 JSON，原子写入（临时文件 + File.Replace()）。 推荐命名约定：与 bicor 相关矩阵存储配套，即 {storeFile}.modules； 或在 R# write_bicor(repo) 约定下为 {repo}/modules.dat。

Declare

            
# namespace SMRUCC.genomics.Analysis.HTS.WGCNA
export class WGCNAModuleMap {
   # 缓存创建时间
   createdAt: DateTime;
   # 缓存指纹（基因 ID 行序 + WGCNA 配置的哈希）
   fingerprint: string;
   # 基因 ID 表（行序与 bicor 相关矩阵存储的行序一致，指纹校验的依据之一）
   genes: string;
   # WGCNA 模块划分结果：模块名（颜色）→ 基因 ID 列表
   modules: list;
}
