CorrelationKind

Description

相关矩阵存储中保存的相关系数类型。

类型不写入存储格式（索引中没有该字段），而是由数据文件名判别： bicor.dat → CorrelationKind.Bicor，pearson.dat → CorrelationKind.Pearson， 索引文件统一为 index.dat（见 CorrelationStoreFiles）。

   Bicor: CorrelationKind = 0;

   # 经典 Pearson 相关系数
   Pearson: CorrelationKind = 1;

}
