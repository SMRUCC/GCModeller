FusionMethods

Description

组学加权融合策略（method.md 步骤4）。

所有权重都是逐通路计算的：每条通路只使用在该通路中有分数的组学层， 因此不同通路可以有不同的组学权重组合。

Declare

            
# namespace SMRUCC.genomics.Analysis.HTS.GSVA.Fusion
export class FusionMethods extends Enum {
   # 等权融合 w_k = 1/K（Baseline 1）
   Equal: FusionMethods = 0;

   # 方差倒数加权 w_k ∝ 1/Var(ES_k)（抑制噪声大的组学）
   Variance: FusionMethods = 1;

   # 信息熵加权 w_k ∝ H(ES_k)（偏好区分度高的组学）
   Entropy: FusionMethods = 2;

   # 互信息一致性加权 w_k ∝ mean_k' I(k, k')（偏好与其他组学一致的组学）
   MutualInformation: FusionMethods = 3;

   # 组学特征数平衡 w_k ∝ 1/log2(2+|S_k|)（抑制成员多的组学）
   Balanced: FusionMethods = 4;

}
