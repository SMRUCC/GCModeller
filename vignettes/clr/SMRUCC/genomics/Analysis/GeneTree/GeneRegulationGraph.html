GeneRegulationGraph

Description

ARACNE 网络拓扑在 GeneTree 中的表示：靶基因 → 调控因子集合。

与 AracneNetwork 的区别在于：

  • 不保存互信息矩阵与表达向量，内存占用只与边数有关；
  • 可以直接从 aracne.zip 的 genes.tsv / tfs.txt / edges.csv 三个条目重建， 因此不需要读取 4.5GB 的 expression.bin；
  • 每个靶基因的调控因子已经按照互信息降序裁剪到 top-K，可以直接作为回归特征。

特征顺序（GeneRegulationGraph.RegulatorsOf() 返回的顺序）一旦确定就会被训练器、预测器与存档共同沿用， 任何一处顺序不一致都会造成静默的数值错位，因此不要在下游重新排序。

Declare

            
# namespace SMRUCC.genomics.Analysis.GeneTree
export class GeneRegulationGraph {
   # 裁剪之后保留下来的调控边数量
   EdgeCount: integer;
   # 拓扑中出现的全部基因（顺序与 ARACNE 的 genes.tsv 一致）
   Genes: string;
   # 本次构建时使用的 top-K 裁剪上限（0 表示未裁剪）
   MaxRegulators: integer;
   # 靶基因数量
   TargetCount: integer;
   # 拥有至少一个调控因子的靶基因列表（按调控者数量降序）
   Targets: string;
   # 每一个基因是否为转录因子（下标与 GeneRegulationGraph.Genes 一致）
   TfFlags: boolean;
}
