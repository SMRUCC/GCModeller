XGBoostGRN

Description

基于 XGBoost 的非线性基因调控网络虚拟扰动实验（门面类）。

把 readme 中的三段流程串起来：

  1. 拓扑：由 aracne.zip 得到 GeneRegulationGraph（靶基因 → 调控因子）；
  2. 拟合：用原始表达矩阵训练 N 个梯度提升树模型 f_i(X_Reg(i))；
  3. 扰动：阻尼定点迭代求解扰动之后的新稳态，返回 InterventionResult。

典型用法：

 Dim grn = XGBoostGRN.Open("./aracne.zip", "./GRN_expression_matrix.csv")
 
 Call grn.Fit()
 
 Dim ko = grn.KnockoutGene("TP53")
 Dim oe = grn.OverexpressGene("MYC")

本类实现了 InsilicoPerturbationExperiment 接口， 因此可以与 GEARS、BNLearn 之中已有的虚拟扰动实现互换使用。

数值尺度：训练与扰动的数值一律来自传入的表达矩阵（原始表达量，而不是 ARACNE 存档之中 rank 变换之后的秩值），因为树模型的外推裁剪区间与“敲除到 0”的语义都依赖于原始表达量。

野生型基线：XGBoostGRN.WildtypeMeans / XGBoostGRN.WildtypeSDs 由参与迭代的细胞种群 （XGBoostGRN.PopulationSize 个细胞）估计，这样没有被任何模型预测的源节点在扰动前后的变化量恰好为 0； 代价是基线本身带有抽样噪声，需要更高精度时应该增大 GeneTreeConfig.PopulationSize。

控制漂移：树模型的稳态并不严格等于观测到的表达谱，因此即使不做任何扰动，迭代也会让部分基因发生位移。 XGBoostGRN.ControlSteadyState 给出了“不施加任何干预”时的稳态均值，可用于对扰动结果做基线校正与诊断。

表达状态上下文：XGBoostGRN.SetContext() 可以把模型从 “训练时的野生型基线”切换到任意给定的表达状态（例如某个疾病态、处理态或者外部扰动实验的对照态）， 之后的 XGBoostGRN.Predict() / XGBoostGRN.KnockoutGene() / XGBoostGRN.OverexpressGene() / XGBoostGRN.KnockDownGene() 都会以这个状态作为迭代起点与差异分析的基线。

Declare

            
# namespace SMRUCC.genomics.Analysis.GeneTree
export class XGBoostGRN {
   # 训练与求解参数
   Config: GeneTreeConfig;
   # 当前生效的表达状态上下文（基因名 → 表达值）。
   # 
   # 没有被 XGBoostGRN.SetContext() 设置过的时候为Nothing。
   Context: IReadOnlyDictionary`2;
   # 应用状态上下文时是否执行过分位对齐
   ContextAligned: boolean;
   # 上下文之中真正被钳制的基因数量（钳制被自动降级时为 0）
   ContextClampGenes: integer;
   # 上下文之中的基因是否在迭代过程中被钳制（固定不变）
   ContextFix: boolean;
   # 上下文注入过程的诊断信息（对齐、钳制降级等），没有需要提示的信息时为Nothing
   ContextNote: string;
   # 不施加任何干预时的网络稳态均值（模拟表达谱自身的“吸引子”）
   ControlSteadyState: double;
   # 模型之中由结构发现阶段新增的调控边数量
   DiscoveredEdgesCount: integer;
   # 结构发现的汇总结果（未开启发现或者模型尚未训练时为 Nothing）
   Discovery: DiscoveryReport;
   # 用于训练的表达矩阵（从存档加载的模型为 Nothing）
   Expression: Matrix;
   # 基因名称（顺序与 InterventionResult.GeneNames 一致）
   GeneNames: string;
   # 调控网络拓扑
   Graph: GeneRegulationGraph;
   # 是否已经设置了表达状态上下文
   HasContext: boolean;
   # 是否已经完成了拟合（或者已经从存档加载了模型）
   IsFitted: boolean;
   # 最近一次扰动求解的详细结果（收敛轮数、轨迹等）
   LastSolve: SolveResult;
   # 逐基因模型（下标与 XGBoostGRN.GeneNames 一致）
   Models: GeneModel[];
   # 参与迭代求解的细胞数量
   PopulationSize: integer;
   # 转录因子名称列表
   TFNames: string;
   # 训练报告（从存档加载时为存档之中保存的那一份）
   TrainingReport: TrainingReport;
   # 上下文之中无法映射到模型基因集的名字（用于提示 ID 空间不匹配）
   UnknownContextGenes: string;
   # 野生型（对照）表达均值
   WildtypeMeans: double;
   # 野生型（对照）表达标准差
   WildtypeSDs: double;
}
