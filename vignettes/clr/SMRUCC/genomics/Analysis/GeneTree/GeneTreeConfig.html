GeneTreeConfig

Description

GeneTree（XGBoost 非线性基因调控网络）的全量超参数配置。

配置分成四组：

  • 网络拓扑：GeneTreeConfig.MaxRegulators、GeneTreeConfig.IncludeUndirectedEdges、GeneTreeConfig.MaxGenes
  • 训练抽样：GeneTreeConfig.MaxSamplesPerModel、GeneTreeConfig.ValidationRatio、GeneTreeConfig.MinSamples
  • 梯度提升树：GeneTreeConfig.NumBoostRound、GeneTreeConfig.MaxDepth、GeneTreeConfig.LearningRate 等
  • 虚拟扰动求解：GeneTreeConfig.DampingAlpha、GeneTreeConfig.MaxIterations、GeneTreeConfig.PopulationSize 等

所有以“0”表示“不限制/使用全部”的字段都会在 GeneTreeConfig.Validate() 之后由使用方自行解释， 例如 GeneTreeConfig.MaxRegulators=0 表示保留 ARACNE 给出的全部调控者， GeneTreeConfig.MaxSamplesPerModel=0 表示使用表达矩阵中的全部细胞。

   MaxIterations: integer;

   MaxIterationsHardCap: integer;

   MaxRegulators: integer;

   # 训练一个基因模型所需的最小细胞数量，低于该数量时退化为常数模型。
   MinSamples: integer;

   # 允许在判定收敛时仍然“抖动”的基因比例，默认 0.001（千分之一）。

   # 显著性判定所用的 Z-score 阈值，默认 2。
   SignificanceZScore: double;
   # 单个基因模型在 TGBoost 内部使用的线程数。
   ThreadsPerModel: integer;
   # 留出验证集的比例，用于早停与 R²/RMSE 评估。取值 [0.05, 0.5]。
   ValidationRatio: double;
   # 是否输出进度与统计信息到控制台。
   Verbose: boolean;
}
