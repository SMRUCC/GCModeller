GeneModel

Description

网络中单个靶基因的非线性调控函数 f_i(X_Reg(i))。

模型的三种状态：

  • GeneModel.Booster 非空：由 TGBoost 训练得到的梯度提升树；
  • GeneModel.Booster 为空且 GeneModel.IsFittedModel 为 True：训练失败/样本不足时的常数模型；
  • 模型对象本身为 Nothing：该基因没有任何调控者（源节点），在迭代之中保持初始值不变。

Declare

            
# namespace SMRUCC.genomics.Analysis.GeneTree
export class GeneModel {
   # 梯度提升树模型。赋值为 Nothing 时模型退化为常数模型。
   Booster: GBM;
   # 常数模型的输出值（训练标签均值）；只有 GeneModel.Booster 为空时才会被使用
   Constant: double;
   # 靶基因编号
   Gene: string;
   # 该基因是否拥有一个（可能退化了的）模型对象。False 表示它是没有调控者的源节点。
   IsFittedModel: boolean;
   # 模型种类：xgboost 或 constant
   Kind: string;
   # 训练标签的取值范围上界（外推裁剪用）
   MaxValue: double;
   # 训练标签的取值范围下界（外推裁剪用）
   MinValue: double;
   # 拟合评价与特征重要性
   Performance: ModelPerformance;
   # 调控因子在表达矩阵之中的行下标（与 GeneModel.Regulators 一一对应）
   RegulatorIndex: integer;
   # 特征（调控因子）的编号顺序。训练、预测与存档三处必须完全一致。
   Regulators: string;
   # 树的数量
   TreeCount: integer;
}
