RegulationEdgeModel

Description

由神经模糊模型读出的带符号调控边。

RegulationEdgeModel.Weight 是靶基因模型在训练状态上对某个调控因子的平均局部灵敏度 ∂x̂_target / ∂x_regulator，由结论系数按规则触发强度加权得到： 正值表示激活，负值表示抑制，绝对值即调控强度。

RegulationEdgeModel.Confidence 在该边来自先验网络时取先验置信度，否则取表达相关性 |Pearson|；RegulationEdgeModel.IsPrior 标记这条边是否被先验网络支持， 便于把「数据支持 + 先验支持」与「纯数据推断」分开汇报。

# namespace SMRUCC.genomics.Analysis.FuzzyGene.Data
export class RegulationEdgeModel {
   # 置信度：先验置信度，或数据相关性的绝对值。
   Confidence: double;
   # 等价的布尔语义：True 表示激活。
   IsActivation: boolean;
   # 该边是否被先验调控网络支持。
   IsPrior: boolean;
   # 调控因子（上游）。
   Source: string;
   # 靶基因（下游）。
   Target: string;
   # 平均局部灵敏度：正为激活、负为抑制。
   Weight: double;
}
