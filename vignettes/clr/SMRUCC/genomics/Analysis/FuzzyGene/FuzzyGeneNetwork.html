FuzzyGeneNetwork

Description

由逐靶基因神经模糊模型拼成的基因调控网络（纯推理对象）。

每一行是一个基因，FuzzyGeneNetwork.Models 的第 g 项是该基因作为靶基因时训练出的 TSK 模型 （没有可用调控因子的基因为 Nothing，其状态在传播中保持不变）。

静态与滞后两条路线的对外语义完全一致：都是「下一状态 = F(当前状态)」。 静态路线下 F 学的是 x_g = f(regulators)，迭代就是求不动点； 滞后路线下 F 学的是 x_g(t+1) = f(regulators(t))，迭代就是时间推进。 因此稳态求解、钳制扰动与多步级联共用同一套阻尼迭代器。

内部一律在 z 空间迭代（与训练一致），对外接口收发原始表达量。

# namespace SMRUCC.genomics.Analysis.FuzzyGene
export class FuzzyGeneNetwork {
   # 稳态迭代的起始状态（原始尺度）。
   BaselineRaw: double;
   # 建模配置（决定传播步数、阻尼、限幅等默认行为）。
   Config: FuzzyGeneConfig;
   # 带符号调控边（由各靶基因模型的解析灵敏度汇总）。
   Edges: RegulationEdgeModel[];
   # 参与建模的基因（顺序即 FuzzyGeneNetwork.Models 的索引顺序）。
   GeneNames: string;
   # 是否为滞后（时序）路线。
   IsLagged: boolean;
   # 逐基因原始表达均值。
   Means: double;
   # 实际采用的拟合路线。
   Mode: FuzzyTargetMode;
   # 逐基因模型，未建模的位置为 Nothing。
   Models: GeneRegulationModel[];
   # 基因数量。
   NGene: integer;
   # 参与建模（有模型）的基因数量。
   NModelled: integer;
   # 逐基因原始表达标准差。
   SDs: double;
   # 模型是否在 z 空间训练。
   Standardized: boolean;
   # 逐基因训练支持域上界（z 空间）。
   SupportMax: double;
   # 逐基因训练支持域下界（z 空间）。
   SupportMin: double;
}
