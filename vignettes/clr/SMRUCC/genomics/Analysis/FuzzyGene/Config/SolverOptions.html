SolverOptions

Description

稳态求解器配置。

全部参数都只影响「怎么解」，不影响「解什么」：F 由逐靶基因模型决定， 因此换求解器不会改变模型语义，只会改变同一组方程被求解得稳不稳、快不快。

SolverOptions.ClampInputToSupport 与 SolverOptions.ClampOutputToSupport 是外推防线： 虚拟敲除会把输入推到训练支持域之外，此时高斯前件几乎全部失活、 结论项退化成最外侧规则的无界线性外推。输入侧夹断保证「模型只在见过的工作区间里被询问」。

   CycleWindow: integer;

   DivergenceFactor: double;

   KrylovMaxIterations: integer;

   Lambda0: double;

   MaxNewtonIterations: integer;

   Mode: SolverMode;
   # 谱半径幂迭代的最大次数。
   SpectralPowerIterations: integer;
