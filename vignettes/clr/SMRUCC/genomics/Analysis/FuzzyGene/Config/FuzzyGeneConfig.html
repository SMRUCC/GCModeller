FuzzyGeneConfig {SMRUCC.genomics.Analysis.FuzzyGene.Config} .NET clr documentation

FuzzyGeneConfig

Description

神经模糊基因调控网络（ANFIS/TSK）的建模配置。

网络的结构参数（隶属函数类型与个数、规则启用掩膜、规模上限、分块行数）与 训练参数（学习率、优化器、早停、岭项……）全部继承自 AnfisOptions， 这里只补充调控网络建模专属的选项：候选调控因子规模、筛选策略、拟合路线、 稳态传播参数与虚拟扰动的默认行为。

构造函数把 TskStructureOptions.MaxRules 与 TskStructureOptions.MaxConsequentParams 从 ANFIS 的通用默认值（1024/4096） 下调到 128/512：GRN 是「逐靶基因一个小网络」的批量场景，512 个结论参数对应的 A'A 约 2 MB，上千个基因并行训练时内存才可控。确实需要更大子网时可显式调高。

VB 不支持协变返回类型，因此链式校验方法命名为 FuzzyGeneConfig.ValidateGene()， 克隆方法用 Shadows 隐藏基类的 AnfisOptions.Clone() 并返回本类型。
