SolverMode

Description

稳态求解策略。

之所以要区分「求根」与「时间推进」：静态路线学到的是 x_g = F(regulators) 的回归面， 它的正确提法是解 r(z) = F(z) - z = 0（求根），而不是把它当时间步反复施加； 滞后路线学到的是 x(t+1) = F(x(t))，那才是一个离散动力系统，只能推进并观察吸引子。 把两者混在同一个「阻尼迭代 + maxDelta」里，是此前收敛判据无法自洽的根源之一。

默认 SolverMode.Auto：静态路线走 SolverMode.Newton， 滞后路线走 SolverMode.Advance。

# namespace SMRUCC.genomics.Analysis.FuzzyGene.Config
export class SolverMode extends Enum {
   # 按网络路线自动选择：静态 → Newton，滞后 → Advance。
   Auto: SolverMode = 0;

   # 带解析 Jacobian 的 Levenberg–Marquardt / 牛顿求根。
   Newton: SolverMode = 1;

   # Anderson 加速的阻尼迭代（无法建立 Jacobian 时的次优选择）。
   AndersonDamped: SolverMode = 2;

   # 旧行为：逐帧阻尼迭代 + 脏位优化（保留用于回归对照）。
   LegacyDamped: SolverMode = 3;

   # 时间推进：只产出轨迹与吸引子，不承诺不动点。
   Advance: SolverMode = 4;

}
