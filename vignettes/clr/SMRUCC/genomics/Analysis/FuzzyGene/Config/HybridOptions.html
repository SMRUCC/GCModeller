HybridOptions

Description

神经模糊网络与 PBN / FCM 融合的配置。

三层各司其职：PBN 提供定性（哪条边真的存在、多大把握）， TSK 提供定量（局部线性斜率、连续剂量响应）， FCM 提供有界粗粒度骨架（保证有界、给求根一个接近不动点的初值）。 因此这里的默认值全部取向「不改变原有数值结论」： 正则关闭、FCM 热启动关闭、集成为 0 次采样。

规模约束是硬门槛：HybridOptions.PbnMaxGenes 与 HybridOptions.PbnMaxParents 决定了 PBN 候选父集枚举的成本（每基因 C(PbnCandidateSize, k≤PbnMaxParents) 次真值表拟合）， 全基因组两两枚举是不可行的，超限时由 HybridOptions.Validate() 直接拒绝并给出可操作提示。

# namespace SMRUCC.genomics.Analysis.FuzzyGene.Config
export class HybridOptions {
   # 布尔化阈值（按该基因 [-1, 1] 归一化后的分位数）。
   BinarizeQuantile: double;
   # 全局增益校准方式；默认关闭。
   Calibration: StabilityCalibrationMode;
   # 校准目标：ρ(J) ≤ 1 - Epsilon；取 0.05 留出 5% 的收敛余量。
   CalibrationEpsilon: double;
   # 校准后仍超限时的逐行再缩放下限（防止把某一行压成 0）。
   CalibrationMinScale: double;
   # PBN 规则采样的次数；0 表示不做集成（沿用确定性单点结果）。
   EnsembleSamples: integer;
   # FCM 的 sigmoid 斜率。
   FcmAlpha: double;
   # 求根失败时，是否用 FCM 吸引子的周期均值作为代理结论。
   FcmFallbackAsSurrogate: boolean;
   # FCM 传播的最大步数。
   FcmMaxSteps: integer;
   # FCM 的模块个数（概念数）；实际值会被 N/50 与 2 夹断。
   FcmModuleCount: integer;
   # FCM 收敛容差。
   FcmTolerance: double;
   # 是否用模块级 FCM 的稳态作为逐基因求根的热启动初值。
   FcmWarmStart: boolean;
   # 调控因子筛选的共线性上限：已选中的调控因子两两 |Pearson| 超过该值就不再选。
   MaxRegulatorCollinearity: double;
   # 把布尔采样得到的模式作为软约束注入连续求解的权重；0 表示只统计、不改变数值结论。
   ModeBiasWeight: double;
   # 每个靶基因进入 PBN 候选父集的基因个数上限。
   PbnCandidateSize: integer;
   # 启用 PBN 的最大基因数（超过则只对先验 TF 与高方差基因做）。
   PbnMaxGenes: integer;
   # PBN 父集的组合上限；2 表示只枚举单基因与两基因父集（每基因 ≤ 21 个子集）。
   PbnMaxParents: integer;
   # PBN 候选父集的最小 CoD；低于该值的父集不参与拟合。
   PbnMinCod: double;
   # PBN 对 TSK 调控因子的作用方式。
   PbnRegularization: PbnRegularizationMode;
   # 软加权模式下 CoD 折算成相关性打分的权重（0 = 不影响排序）。
   PbnWeight: double;
}
