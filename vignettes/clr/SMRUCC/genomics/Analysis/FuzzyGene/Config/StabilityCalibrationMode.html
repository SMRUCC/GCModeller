StabilityCalibrationMode

Description

拟合完成后的全局增益校准方式。

逐靶基因独立拟合无法保证整张网络的 Jacobian 谱半径 < 1； 只要 ρ(J) ≥ 1，阻尼迭代就不收缩（λ≈1 时甚至是中立方向）。 校准就是把 J 的斜率整体缩放 γ = (1-ε)/ρ，把拟合网络标定成压缩映射： 符号、规则结构、相对强弱都不变，只有幅度被压进收敛域。
