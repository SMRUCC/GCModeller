PbnRegulatorPrior

Description

用概率布尔网络给 TSK 的调控因子候选提供定性证据（CoD）。

纯表达相关的候选筛选有一个结构性缺陷：它只看「谁和靶基因更相关」， 于是会把下游基因选成上游调控因子（A→B 时 B 与 A 的相关性同样高）， 拟合出 A = f(B) 这种反函数。这种边在稳态迭代里是近单位增益的环， 既破坏可解释性，也是谱半径超限的来源之一。

布尔网络的一致性（CoD）给出的是完全不同的证据：它问「给定父节点取值， 靶基因的取值是否被确定」。反函数在布尔化之后依然能拟合得很好， 但多父集上的 CoD 增长会揭示「这条边是否真的携带方向信息」： 只与 A 相关而与 A 的父集无关的基因，其 CoD 在多父集下不会增长。 因此把 CoD 作为权重/门槛，能显著抑制纯相关边。

规模闸门：InferenceHelper.Combinations 会枚举全部组合， 全基因组两两枚举是不可能的（C(18532,3)）。这里只对 「先验 TF ∪ 方差最高的 HybridOptions.PbnMaxGenes 个基因」建网， 每个靶基因只在「先验调控因子 + top-P 相关基因」这个小子集里枚举 k ≤ PbnMaxParents 的父集（默认每基因 ≤ 21 个子集）。

训练行也会被等间隔抽样到 PbnRegulatorPrior.MaxRows：真值表拟合的成本是 行数 × 子集数，几万行对布尔一致性没有额外信息。
