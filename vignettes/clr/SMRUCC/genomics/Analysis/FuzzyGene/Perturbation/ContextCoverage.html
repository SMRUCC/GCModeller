ContextCoverage

Description

上下文注入（SetContext / LoadContext）的诊断结果。

上下文替换的是「扰动分析的对照基线」，语义上相当于把实验体系放进另一个转录组背景： 对照（野生型）态与突变体态都从该初始条件出发各自迭代到稳态， 因此 InterventionResult.FoldChanges 变成「同一 context 下的突变体 vs 野生型」。

报告里必须能看出三件事，否则结果无法解释： 模型里的哪些基因真的被上下文覆盖了（ContextCoverage.Matched）、 哪些还在沿用训练数据的均值（ContextCoverage.MissingGenes）、 以及哪些取值落在训练支持域之外（ContextCoverage.OutsideSupport，迭代时会被限幅， 等于这部分输入被“剪平”了）。

Declare

            
# namespace SMRUCC.genomics.Analysis.FuzzyGene.Perturbation
export class ContextCoverage {
   # 覆盖率 = ContextCoverage.Matched / ContextCoverage.NGene。
   Coverage: double;
   # 上下文实际使用的基因名列（LoadContext 在多列中自动挑选）。
   GeneColumn: string;
   # 因为取值不是有限数（NaN / ±Inf / 空）而被跳过的条目数。
   InvalidValues: integer;
   # 上下文是否至少覆盖了一个基因（否则不会被应用）。
   IsApplied: boolean;
   # 命中模型基因的条目数。
   Matched: integer;
   # 模型中未被上下文覆盖、继续沿用训练基线的基因名。
   MissingGenes: string;
   # 模型基因总数。
   NGene: integer;
   # 命中模型、但取值落在训练支持域之外的基因数（迭代时会被限幅到边界）。
   OutsideSupport: integer;
   # 上下文中提供的有效条目数（同名基因以最后一次出现的为准）。
   Provided: integer;
}
