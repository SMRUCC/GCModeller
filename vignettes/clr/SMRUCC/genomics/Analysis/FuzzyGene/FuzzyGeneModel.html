FuzzyGeneModel

Description

神经模糊（ANFIS/TSK）基因调控网络模型的门面。

一个实例封装「表达矩阵 + 可选先验网络 → 逐靶基因模糊模型 → 虚拟扰动」的全流程， 并实现 InsilicoPerturbationExperiment，因此可以与 BNLearn 的贝叶斯网络实现、 GEARS / GPS 的实现互换使用——bnlearn 包里的 knockouts / knockdown / overexpress 可以直接作用在本对象上。

典型用法：

 Dim model As New FuzzyGeneModel(expression, prior, config)
 Dim report = model.Train()
 Dim ko As InterventionResult = model.KnockoutGene("geneA")

规模提示：这是模块/子网尺度的建模方法。逐靶基因的规则数随输入维数指数增长， 请通过 FuzzyGeneConfig.MaxRegulators（默认 4）与 FuzzyGeneConfig.MaxGenes（默认 2000）控制规模； 全基因组两两建模既不必要、也不可辨识。

Declare

            
# namespace SMRUCC.genomics.Analysis.FuzzyGene
export class FuzzyGeneModel {
   # 建模配置（恢复的模型同样携带原始配置）。
   Config: FuzzyGeneConfig;
   # 当前注入的上下文（原始表达量，长度 = 基因数）；未注入时为 Nothing。
   Context: double;
   # 带符号调控边（未训练时为空数组）。
   Edges: RegulationEdgeModel[];
   # 训练用的表达矩阵；从包文件恢复时为 Nothing。
   Expression: GeneExpressionData;
   # 是否已注入上下文（注入后对照基线被整体替换）。
   IsContextSet: boolean;
   # 是否已完成训练（或已从包恢复）。
   IsTrained: boolean;
   # 最近一次上下文注入的覆盖率诊断；未注入时为 Nothing。
   LastContextCoverage: ContextCoverage;
   # 最近一次训练的汇总诊断。
   LastTrainingResult: FuzzyGeneTrainingResult;
   # 拟合出的调控网络；未训练时为 Nothing。
   Network: FuzzyGeneNetwork;
   # 先验调控网络（可能为 Nothing）。
   Prior: PriorNetwork;
   # 严格模式：目标基因不在模型里时抛 MissingMemberException； 为 False 时返回 InterventionResult.Undefined = True 的野生型降级结果。
   Strict: boolean;
}
