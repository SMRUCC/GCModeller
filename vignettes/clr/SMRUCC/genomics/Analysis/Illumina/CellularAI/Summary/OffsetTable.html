OffsetTable

Description

一条训练摘要的"逐基因中心化表"与"响应方差表"。

上游把"每条记录的逐基因中心"（effect_center、signed_score_center）与 "该记录的噪声水平"（response_variance）单独存成一份 .npz， 池化时先减中心再合并。中心值缺失（NaN）表示该基因没有估计值，此时不做事 （直接透传原值），而不是把原值清零。

OffsetTable.EffectCount 是该基因上做过估计的扰动数量，用于诊断"这个中心是否可信"。

Declare

            
# namespace SMRUCC.genomics.Analysis.Illumina.CellularAI.Summary
export class OffsetTable {
   # 细胞系（训练行）名称。
   CellLine: string;
   # 基因数。
   Count: integer;
   # log2FC 的逐基因中心。
   EffectCenter: double;
   # 中心估计所用的扰动数量（逐基因）。
   EffectCount: double;
   # 本表的基因轴。
   Genes: string;
   # 响应方差（逐基因），用作逆方差权重。
   ResponseVariance: double;
   # 带符号正态分数（Liptak 分数）的逐基因中心。
   SignedScoreCenter: double;
   # 视图名称（与摘要行的 view 一致）。
   View: string;
}
