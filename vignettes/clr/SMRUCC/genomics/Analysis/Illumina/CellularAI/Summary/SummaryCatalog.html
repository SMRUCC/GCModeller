SummaryCatalog

Description

训练摘要的目录：按固定顺序排列的全部摘要行，以及主视图与文件顺序记录。

池化的累加顺序就是 SummaryCatalog.Rows 的顺序（浮点加法不可交换）， 因此这里不允许在算法内部重排；需要"按视图取子集"时用 SummaryCatalog.ByView()， 它保持原有相对顺序。

# namespace SMRUCC.genomics.Analysis.Illumina.CellularAI.Summary
export class SummaryCatalog {
   # 行数。
   Count: integer;
   # 显式记录的文件顺序（键如 effect_files / control_files）， 由上游装配时填入；为空时退化为 SummaryCatalog.Rows 顺序。
   Orders: list;
   # 主视图名称（用于基因并集、相似度与控制剖面），默认 view_0。
   PrimaryView: string;
   # 全部摘要行（顺序即池化顺序）。
   Rows: SummaryRow[];
}
