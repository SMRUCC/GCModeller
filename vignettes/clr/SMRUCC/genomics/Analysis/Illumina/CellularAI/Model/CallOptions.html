CallOptions

Description

响应调用（哪些基因算作"被扰动影响"）的参数：对应参考配置 model.calls 段。

CallOptions.EligibleCpm 是表达资格门槛（对照平均 CPM > 5 才可能被调用）； CallOptions.MinLfc 是计划基因必须达到的最小 log2 效应； CallOptions.Gamma 把扰动强度映射成调用数量的指数系数。

CallOptions.StrengthK / CallOptions.StrengthC / CallOptions.StrengthPhi 是"检测功效"模型的参数： p = Φ(k·|lfc| / √(1/μ + φ) − c)，其中 μ 是该基因在该深度下的期望计数。

# namespace SMRUCC.genomics.Analysis.Illumina.CellularAI.Model
export class CallOptions {
   # 表达资格门槛（对照平均 CPM），默认 5。
   EligibleCpm: double;
   # 调用数量对扰动强度的指数系数，默认 2.5。
   Gamma: double;
   # 计划基因的最小 |log2FC|，默认 0.02。
   MinLfc: double;
   # 每个扰动的最多调用数，默认 6000。
   NMax: integer;
   # 每个扰动的最少调用数，默认 5。
   NMin: integer;
   # 检测功效模型里的过度离散项 φ，默认 0.1。
   Phi: double;
   # 强度计算里功效的偏移 c，默认 4.0。
   StrengthC: double;
   # 强度计算里功效的斜率 k，默认 111.2。
   StrengthK: double;
   # 强度计算里的深度过度离散项，默认 0.05。
   StrengthPhi: double;
   # 强度计算里"显著 z"的门槛，默认 3.0。
   StrengthZ: double;
   # 功效得分在综合排序里的权重，默认 1.0。
   WPow: double;
}
