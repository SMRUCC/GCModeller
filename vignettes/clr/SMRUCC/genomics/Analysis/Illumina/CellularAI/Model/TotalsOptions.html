TotalsOptions {SMRUCC.genomics.Analysis.Illumina.CellularAI.Model} .NET clr documentation

TotalsOptions

Description

总量设计（每个扰动每个基因的整数总量）的参数：对应参考配置 model.totals 段。

信用（credit）：用对照细胞的留一法矩（delete-one jackknife）抽样， 得到"n 个细胞能承载多大的表达离散度"，作为设计目标的上界； TotalsOptions.CreditDraws 是抽样次数，TotalsOptions.CreditSeed 是固定种子。

TotalsOptions.AmpShare 决定初始幅度设计取信用的多少；随后 ProfileSpread 把设计边距解到"合成后的离散度命中信用目标"，最多迭代 TotalsOptions.FixedSteps 轮。

TotalsOptions.ResidualRank / TotalsOptions.ResidualRidge / TotalsOptions.ResidualMinMeasured / TotalsOptions.ResidualGlobal 是残差校正层的参数（低秩基的秩、岭惩罚、最少实测记录数、全局主成分数）。
