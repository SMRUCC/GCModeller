PlanOptions

Description

响应计划（每个扰动调用多少基因、怎么排序）的参数：对应参考配置 model.plan 段。

PlanOptions.CurveSlope 把"训练数据里该扰动的响应广度"映射成调用数量 （n = exp(slope·(x − median))，再整体缩放到中位数等于 median_degs）。

PlanOptions.SimTau / PlanOptions.SimNtop / PlanOptions.SimCap 控制"训练细胞系与新上下文的相似度权重"： 先对相关系数做 z 标准化，再取 exp(z/τ)，最后用上限水位法把单项权重压到 cap 以下。

PlanOptions.PowerK 系列是"期望可检测基因数"的功效模型；PlanOptions.ShrinkQuantile / PlanOptions.ShrinkFactor 把得分最低的一部分扰动的调用数量按比例收缩，把省下来的调用 分配给得分高的扰动（保证总调用量守恒）。

# namespace SMRUCC.genomics.Analysis.Illumina.CellularAI.Model
export class PlanOptions {
   # 广度→调用数量的曲线斜率，默认 3.0。
   CurveSlope: double;
   # 计划 z 中"均匀权重"的混合比例，默认 0.5。
   PlanZUniform: double;
   # 功效模型的偏移 c，默认 3.0。
   PowerC: double;
   # 功效模型使用的参考深度，默认 20000。
   PowerDepth: double;
   # 功效模型的斜率 k，默认 111.0。
   PowerK: double;
   # 功效模型的过度离散项，默认 0.05。
   PowerPhi: double;
   # 功效的软截断参数（|z| 小于该值时逐步降权），默认 2.0。
   PowerSoftZ: double;
   # 宽带显著基因数在综合得分里的惩罚系数，默认 0.5。
   PowerTPen: double;
   # "宽带显著性"的门槛 |z|，默认 2.0。
   PowerZN2: double;
   # 收缩后保留的比例，默认 0.1。
   ShrinkFactor: double;
   # 需要收缩的得分分位，默认 0.2（最低的 20%）。
   ShrinkQuantile: double;
   # 单项相似度权重的上限，默认 0.3。
   SimCap: double;
   # 计算相似度时取的高变基因数，默认 3000。
   SimNtop: integer;
   # 相似度 softmax 的温度 τ，默认 1.0。
   SimTau: double;
   # 广度加权允许的最大抬升倍数，默认 2.0。
   XsimCapFactor: double;
   # 广度加权允许的最大总量倍数，默认 1.2。
   XsimMaxTotal: double;
   # 广度加权只作用于上半分位（0.5 表示中位以上），默认 0.5。
   XsimStrength: double;
   # 广度加权时的温度 τ，默认 0.5。
   XsimTau: double;
}
