CellularAiModel

Description

CellularAI 模型的全部超参数：七个参数对象的聚合根。

默认值逐项对应参考配置 configs/example.yaml 的 model 段。 这些值定义的是"已发布的方法"，正常使用不应修改；测试与调参时用 CellularAiModel.Clone() 派生。

本类型只是数据容器，不含算法；算法入口接收它并保持只读语义。

   Totals: TotalsOptions;
