GeneRegulatoryNetwork {SMRUCC.genomics.Model.Network.Regulons.LinearRegression} .NET clr documentation

GeneRegulatoryNetwork

Description

基于线性拟合的基因表达调控网络推断

对于表达矩阵之中的每一个基因 g，都会建立如下的线性模型：

 expr(g) = const + beta_1 * expr(r1) + beta_2 * expr(r2) + ...

其中 r1, r2, ... 为候选调控因子(默认从与 g 相关性最高的若干个基因之中选出， 并且总是排除 g 自身)。把所有基因的模型汇总之后，就得到了一个 调控因子 -> 目标基因 的有向加权网络：边的权重即为回归系数。

需要注意前置条件：参与拟合的自变量个数(候选调控因子数量 + 截距项)必须显著小于样本数量。

  • 对于 FittingMethod.MultipleLinear，DataFittings 底层使用 QR 分解， 秩不足的时候会直接抛出 Matrix is rank deficient 异常；
  • 对于 FittingMethod.Lasso，DataFittings 的 LassoFitGenerator 在初始化内部观测数组的时候使用了错误的维度上限，自变量个数大于样本数量的时候会越界。

因此这里会通过 GrnFittingOptions.maxCandidates 与 GrnFittingOptions.candidateSampleRatio 强制限制候选因子的数量。 基因数量远大于样本数量的时候(转录组数据的常态)，请先进行表达量过滤、 差异基因筛选或者PCA/模块降维。
