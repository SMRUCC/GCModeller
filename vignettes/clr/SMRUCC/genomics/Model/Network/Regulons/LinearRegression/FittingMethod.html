FittingMethod {SMRUCC.genomics.Model.Network.Regulons.LinearRegression} .NET clr documentation

FittingMethod

Description

用于建立基因调控网络的线性拟合求解方法。

模型的形式统一为：

 target = const + beta_1 * regulator_1 + beta_2 * regulator_2 + ...

其中每一个基因都会轮流作为目标基因(target)被拟合一次。

Declare

            
# namespace SMRUCC.genomics.Model.Network.Regulons.LinearRegression
export class FittingMethod extends Enum {
   # 普通最小二乘(OLS)，即多元线性回归，底层通过 QR 分解求解正规方程 beta = inv(X' * X) * X' * y。
   MultipleLinear: FittingMethod = 0;

   # LASSO 回归(L1 正则化)，在拟合的同时把不重要的调控因子权重收缩为零， 从而直接得到稀疏的调控网络。
   Lasso: FittingMethod = 1;

   # 弹性网络(L1 + L2 正则化)，兼具 LASSO 的稀疏性与 Ridge 的稳定性。
   ElasticNet: FittingMethod = 2;

}
