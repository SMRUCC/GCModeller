RegulationEdge {SMRUCC.genomics.Model.Network.Regulons.LinearRegression} .NET clr documentation

RegulationEdge

Description

一条基因表达调控关系：regulator -> target，边的权重为线性模型的回归系数。

这个类同时实现了 IInteraction 与 INetworkEdge 接口， 因此可以直接被生成为网络图数据。

Declare

            
# namespace SMRUCC.genomics.Model.Network.Regulons.LinearRegression
export class RegulationEdge {
   # 回归系数的绝对值
   absWeight: double;
   # 产生这条边的弹性网络模型所使用的总正则化强度， 非弹性网络的求解方法之下这个数值为零。
   alpha: double;
   # 调控关系的类型描述，一般为求解方法的名称。
   interaction: string;
   # 产生这条边的模型之中的常数项
   intercept: double;
   # 产生这条边的弹性网络模型所使用的 L1 混合比例， 非弹性网络的求解方法之下这个数值为零。
   l1Ratio: double;
   # 回归系数的显著性 p 值，LASSO 模型之下恒为 1。
   pvalue: double;
   # 目标基因的模型解释度(R^2)
   r2: double;
   # 调控因子基因编号(上游基因)
   regulator: string;
   # 被调控的目标基因编号(下游基因)
   target: string;
   # 边的唯一编号，形如 regulator->target
   UID: string;
   # 线性模型之中调控因子对目标基因的回归系数， 正数表示激活型的调控关系，负数表示抑制型的调控关系。
   weight: double;
}
