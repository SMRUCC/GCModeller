PriorProtectionMode {SMRUCC.genomics.Model.Network.Regulons.ARACNE} .NET clr documentation

PriorProtectionMode

Description

curated 先验边在 DPI 判定之中所受保护的分级方式。

三种模式都只影响“保护强度”，先验边的阈值放宽 (AracneOptions.priorThresholdFactor)与 top-K 保护是独立的。

Declare

            
# namespace SMRUCC.genomics.Model.Network.Regulons.ARACNE
export class PriorProtectionMode extends Enum {
   # 不做 DPI 保护：先验边与普通边一样，只按容差 epsilon 判定。
   Off: PriorProtectionMode = 0;

   # 置信度分级保护(默认，确定性、可复现)。
   # 
   # 置信度 c 的先验边获得的 DPI 容差为
   # 
   # 
   # 
 eps_c = eps + (1 - eps) * priorProtectionStrength * c

   # 
   # 
   # 也就是置信度越高，允许它“比另外两条边弱”的幅度越大： High 的边很难被 DPI 删掉，Medium 次之，Low 只在证据几乎持平的时候才被保护。 由于没有随机性，同一份数据多次运行的结果完全一致。
   Graded: PriorProtectionMode = 1;

   # 按置信度做概率保护：每条先验边以 p = c 的概率获得完全保护 (被抽中的边永远不被 DPI 删除)，以 1 - p 的概率按标准容差判定。
   # 
   # 即：High(0.95) 几乎总被保护、Medium(0.70) 约七成概率被保护、 Low(0.45) 只有不到一半的概率被保护。
   # 
   # 抽样使用 AracneOptions.randomSeed 驱动的伪随机数， 因此结果可复现，而不是每次运行都不同。
   Sampled: PriorProtectionMode = 2;

}
