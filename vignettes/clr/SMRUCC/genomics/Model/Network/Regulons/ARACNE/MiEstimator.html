MiEstimator {SMRUCC.genomics.Model.Network.Regulons.ARACNE} .NET clr documentation

MiEstimator

Description

互信息(Mutual Information)的估计方法。

不同的估计方法在“估计精度 / 计算开销”这条轴上面处于不同的位置， 依据表达矩阵的规模选择合适的方法即可。

Declare

            
# namespace SMRUCC.genomics.Model.Network.Regulons.ARACNE
export class MiEstimator extends Enum {
   # 高斯 copula 估计器(默认)：假设 (X, Y) 服从二元正态分布， 先对表达量做中心化与标准化(或者秩转换)，再计算 pearson 相关系数 r， 则
   # 
   # 
   # 
 MI(X, Y) = -0.5 * log2(1 - r^2)

   # 
   # 
   # 这是 readme 之中推荐的快速估计方法：任意一个基因对的互信息都退化为一次 长度为样本数的向量内积 O(n)，配合 SIMD 与多核可以轻松处理 10^6 ~ 10^7 数量级的基因对，因此它是大样本单细胞数据的默认路径。
   GaussianCopula: MiEstimator = 0;

   # 自适应分区估计器(ARACNE 原论文 Algorithm 1)。
   # 
   # 从整个散点图开始，反复把“点数最多的 bin”沿着极差更大的那个轴 在中位数处分半，直到 bin 的数量达到上限或者每个 bin 内部的点数 低于下限；最后用联合/边缘计数计算
   # 
   # 
   # 
 MI(X, Y) = sum_ij p_ij * log2(p_ij / (p_i * p_j))

   # 
   # 
   # 由于分区的过程与表达量的具体尺度无关，这个估计器可以捕捉到 线性的 copula 估计器所无法捕捉的非线性依赖关系， 是真正意义上的 ARACNE 互信息估计器，代价是每个基因对需要 O(n log n) 级别的计算量。
   AdaptivePartitioning: MiEstimator = 1;

   # 分位数等频直方图估计器：把两个变量分别按照分位数切成相同数量的 等频 bin，再用联合/边缘计数计算互信息，并且做 Miller-Madow 偏差校正。
   # 
   # 这是 readme 伪代码第二步之中“按分位数离散化”的最直接实现， 计算量介于 MiEstimator.AdaptivePartitioning 与 MiEstimator.GaussianCopula 之间。
   EqualFrequencyHistogram: MiEstimator = 2;

   # 高斯核密度估计器：使用高斯核分别估计联合密度与两个边缘密度， 再用 MI = (1/n) * sum log2(f(x,y) / (f(x)f(y))) 计算互信息 (带宽使用 Silverman 经验公式，并且采用留一法避免样本自身的偏置)。
   # 
   # 它的精度最高，但是每个基因对的计算量是 O(n^2)， 因此只有当样本数量不超过 AracneOptions.kernelMaxSamples 的时候才会被真正使用，否则会退回 MiEstimator.GaussianCopula 并且给出警告信息。
   KernelDensity: MiEstimator = 3;

}
