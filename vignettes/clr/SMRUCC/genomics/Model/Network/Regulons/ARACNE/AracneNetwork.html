AracneNetwork

Description

ARACNE(Algorithm for the Reconstruction of Accurate Cellular Networks) 基因表达调控网络的推断。

整体的执行流程与 readme 之中的伪代码一一对应：

 1. 预处理      : log2 变换 / 标准化 / 秩转换 / 零表达与零方差基因过滤
 2. 互信息矩阵  : 高斯 copula(默认) / 自适应分区 / 等频分箱 / 核密度
 3. 显著性阈值  : 置换零分布的分位数(默认 95%) 或者固定阈值
 4. DPI 过滤    : 剔除三元组之中明显最弱的间接边
 5. 方向赋予    : TF 指向靶基因 / TF 与 TF 的双向关系 / 非 TF 的无向候选边

提供转录因子列表的时候，计算空间会由 N x N 缩减为 T x N (只计算 TF-TF 与 TF-Target 的互信息)，这正是 readme 第四章所推荐的 “结合 TF 先验知识”的工程化流程，可以把计算量降低几个数量级。

这个类型只负责编排，具体的数值计算分别在 MutualInformation、PermutationThreshold、 DpiFilter 之中实现。

Declare

            
# namespace SMRUCC.genomics.Model.Network.Regulons.ARACNE
export class AracneNetwork {
   # 赋予方向之后的调控边
   Edges: AracneEdge[];
   # 输入的基因表达矩阵(行=基因、列=样本)，构造与推断的过程都不会修改它
   Expression: Matrix;
   # 预处理之后保留下来的基因编号(顺序与内部的表达向量一一对应)
   Genes: string;
   # DPI 过滤之后的互信息矩阵(无向)
   MiMatrix: MiMatrix;
   # 阈值过滤以及 top-K 剪枝之后、DPI 之前的互信息矩阵
   MiMatrixBeforeDpi: MiMatrix;
   # 本次推断所使用的参数配置
   Options: AracneOptions;
   # 基因(节点)的数量
   Size: integer;
   # 推断过程的统计信息(尚未执行 AracneNetwork.Fit() 的时候为Nothing)
   Statistics: AracneStatistics;
   # 每一个基因是否为转录因子(下标与 AracneNetwork.Genes 一致)
   TfFlags: boolean;
   # 匹配到的转录因子编号
   TFs: string;
   # 互信息的显著性阈值
   Threshold: MiThreshold;
   # 预处理之后的基因表达向量(下标与 AracneNetwork.Genes 一致)
   Vectors: Double[][];
}
