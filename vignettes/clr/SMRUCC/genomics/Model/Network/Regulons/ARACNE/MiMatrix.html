MiMatrix {SMRUCC.genomics.Model.Network.Regulons.ARACNE} .NET clr documentation

MiMatrix

Description

稀疏的互信息矩阵。

ARACNE 的第一步需要计算所有候选基因对的互信息，但是对于 N = 20000 的基因 表达矩阵而言，稠密的 N x N 矩阵需要 3.2 GB 内存，而且其中的绝大部分元素 在阈值过滤之后都会变成零。因此这里采用“边列表 + CSR 邻接表”的稀疏结构：

  • 构建阶段：MiMatrix.SetValue() 把边追加到边列表之中；
  • 首次读取的时候自动 MiMatrix.Freeze() 成压缩稀疏行(CSR)的对称邻接表， 邻居按照节点下标升序排列，因此 MiMatrix.Neighbors() 的结果可以直接 用于两个集合求交(DPI 的共同邻居枚举)；
  • MiMatrix.Prune() / MiMatrix.PruneTopK() 返回一个新的矩阵， 原始数据不被修改。

# namespace SMRUCC.genomics.Model.Network.Regulons.ARACNE
export class MiMatrix {
   # 当前矩阵之中边的数量
   Count: integer;
   # 是否已经建立好 CSR 邻接表的索引
   IsFrozen: boolean;
   # 全部边之中的最大互信息，没有边的时候返回零
   MaxMi: double;
   # 全部边的平均互信息
   MeanMi: double;
   # 节点(基因)的编号，下标与邻接表的节点下标一一对应
   names: string;
   # 至少拥有一条边的节点数量
   NodeCount: integer;
   # 节点(基因)的数量
   Size: integer;
}
