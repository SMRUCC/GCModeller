Atom {SMRUCC.genomics.Molecule.SMILES.Graph} .NET clr documentation

Atom

Description

分子图中的一个原子。同时携带 2D 与 3D 坐标，坐标由 MoleculeGraph.Layout2D() / MoleculeGraph.Embed3D() 写入。

实现 PointF3D 的目的是让视图层可以直接把原子 集合交给 Drawing3D 的点云/相机 API（Extensions.LoadVector3D）， 避免在渲染层再写一遍坐标搬运代码。

# namespace SMRUCC.genomics.Molecule.SMILES.Graph
export class Atom {
   # SMILES 中的原子类别（:n 记号），0 表示未指定。
   AtomClass: integer;
   # 形式电荷（电子数差值，如 +1、-2）。
   Charge: integer;
   # 元素符号（标准大小写，如 C、Cl、Na）。
   Element: string;
   # 结构式记号中显式声明的氢原子个数（SMILES 方括号原子、InChI 的氢层）。 注意这与"作为独立原子出现在图中的氢"是两种不同的表示，统计总数请使用 MoleculeGraph.TotalH()。
   ExplicitH: integer;
   # 原子在分子图中的 0 基下标，与 MoleculeGraph.Atoms 的位置一致。
   Index: integer;
   # 该原子是否参与芳香体系（在 SMILES 中以小写字母书写，或由 InChI 推断）。
   IsAromatic: boolean;
   # 是否为氢（或氘/氚）。
   IsH: boolean;
   # 该原子是否由 MoleculeGraph.AddHydrogens() 生成的氢原子。 绘图时可以据此决定是否隐藏。
   IsHydrogen: boolean;
   # 同位素质量数；0 表示按天然丰度处理。
   Isotope: integer;
   # 该原子的元素符号在显示时是否需要连同氢数/电荷一起标注（即非碳原子）。
   NeedsLabel: boolean;
   # 该原子是否来自"氢数被显式固定"的记号（SMILES 的 [...]、InChI 的全部原子）。 为 True 时不再按价态补隐式氢。
   NoImplicitH: boolean;
   # 四面体手性标记。
   Stereo: AtomStereo;
   # 结构式中出现的邻接原子顺序（用于按 SMILES 约定还原四面体构型）。 缺少第 4 个取代基时以 -1 表示隐式氢。
   StereoNeighbors: integer;
   # 手性记号的原始文本（如 @@、@TH1），便于原样回写与诊断。
   StereoText: string;
   # 2D 平面坐标的 X 分量（布局完成后键长被归一化为 1）。
   X: double;
   # 2D 平面坐标的 Y 分量（化学坐标系，Y 轴向上；渲染时再翻转为屏幕坐标）。
   Y: double;
   # 3D 坐标的 Z 分量，单位为埃（Å）。
   Z: double;
}
