MoleculeGraph

Description

统一的分子图对象：SMILES 与 InChI 两种结构式字符串解析之后都汇入此类型。

  • 原子以 0 基下标标识， 与键表 共同构成分子；
  • 氢以"记号声明的氢"（）与"按价态反推的隐式氢"

（）两段表示，二者之和由 给出；

  • 芳香性同时以 / 与

Kekulé 化之后的 1/2/3 键级两种形式保留，供化学计算与结构绘图各取所需；

  • 坐标只有一份，写入 /（2D）与

（3D），由 / 生成。

化学上无法判定的情形不会抛异常，而是追加到 MoleculeGraph.Warnings。

# namespace SMRUCC.genomics.Molecule.SMILES.Graph
export class MoleculeGraph {
   # 原子总数。
   AtomCount: integer;
   # 分子内的全部原子，下标即 Atom.Index。
   Atoms: iterates(Atom);
   # 化学键总数。
   BondCount: integer;
   # 分子内的全部化学键。
   Bonds: iterates(Bond);
   # 结构式字符串的原始格式。
   Format: MoleculeFormat;
   # 是否不含任何原子。
   IsEmpty: boolean;
   # 解析时所使用的原始字符串。
   SourceText: string;
   # 解析或坐标重建过程中的非致命问题（芳香性无法 Kekulé 化、价态无法满足等）。
   Warnings: iterates(String);
}
