Bond

Description

分子图中的一条化学键：由两个原子下标与键级构成。

键级使用 Double 而不是整数，是为了在同一字段内同时表达 "Kekulé 化之后的 1/2/3" 与 "尚未 Kekulé 化的 1.5 芳香键"。 解析器完成 Kekulé 化之后，Bond.order 会归一到 1/2/3， 而 Bond.IsAromatic 继续保留芳香性信息供绘图使用。 实现 IndexEdge 使分子图可以直接接入 sciBASIC 的图论算法。

# namespace SMRUCC.genomics.Molecule.SMILES.Graph
export class Bond {
   # 键一端的原子下标。
   a: integer;
   # 键另一端的原子下标。
   b: integer;
   # 该键是否属于芳香体系。
   IsAromatic: boolean;
   # 该键是否位于某个环上（由 MoleculeGraph.Rings() 计算后回填）。
   IsRing: boolean;
   # 是否被立体记号标记为未知的双键构型（/?）。
   IsStereoUnknown: boolean;
   # 键级：1 单键、2 双键、3 叁键；芳香键在 Kekulé 化之前为 1.5。
   order: double;
   # 键级取整（用于绘图时选择单/双/叁键画法）。
   OrderInt: integer;
   # 立体标记（实楔形 / 虚楔形 / 双键顺反）。
   Stereo: BondStereo;
}
