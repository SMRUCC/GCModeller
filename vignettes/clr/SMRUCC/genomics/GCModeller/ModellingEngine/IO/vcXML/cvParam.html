cvParam {SMRUCC.genomics.GCModeller.ModellingEngine.IO.vcXML} .NET clr documentation

cvParam

Description

受控词条参数（对应 mzML 的 cvParam）。

unitCvRef / unitAccession / unitName 三者同时出现时表示该值带单位。

Declare

            
# namespace SMRUCC.genomics.GCModeller.ModellingEngine.IO.vcXML
export class cvParam {
   # 词条 accession，例如 VC:0000011 或者 UO:0000031
   accession: string;
   # 词条名称，便于人读与缺失本体时降级
   name: string;
   # 单位 accession，例如 UO:0000031
   unitAccession: string;
   # 单位所属词表（例如 UO）
   unitCvRef: string;
   # 单位名称，例如 minute
   unitName: string;
   # 取值；纯标记型词条留空
   value: string;
}
