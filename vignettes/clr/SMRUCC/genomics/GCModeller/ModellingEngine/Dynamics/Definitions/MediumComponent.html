MediumComponent

Description

培养基配方之中的一个组分。

该对象把「培养基的角色」与「某个数据库之中的化合物编号」以及「默认浓度」绑定在一起， 从而让同一个配方可以跨数据库(MetaCyc / BioCyc / KEGG)复用：

role 是稳定的语义键(例如 glucose / ammonium / phosphate)， id 才是具体数据库之中的编号(例如 GLC / C00031)。

Declare

            
# namespace SMRUCC.genomics.GCModeller.ModellingEngine.Dynamics.Definitions
export class MediumComponent {
   # 默认浓度(mM)。小于等于 0 的组分不会出现在默认培养基之中
   concentration: double;
   # 该组分在目标数据库之中的化合物编号
   id: string;
   # 组分在培养基之中所扮演的角色，例如 glucose、ammonium、phosphate
   role: string;
}
