ContextAlignmentDiagnostics

Description

上下文对齐过程的统一诊断信息。

这个类型取代了各项目自带的零散诊断（FuzzyGene 的 ContextCoverage、 GeneTree 的 ContextNote / ContextClampGenes / UnknownContextGenes）， 保证「上下文到底覆盖了什么、有没有被裁剪」在任何项目上都用同一套口径回答。

# namespace SMRUCC.genomics.BioSystem.Intervention
export class ContextAlignmentDiagnostics {
   # 是否真的执行了对齐（ContextAlignmentMode.None 时为 False）。
   Aligned: boolean;
   # 因为越界策略而被实际钳制到边界的基因数。
   ClampedGenes: integer;
   # 覆盖率 = ContextAlignmentDiagnostics.Matched / ContextAlignmentDiagnostics.NGene。
   Coverage: double;
   # 因为取值不是有限数（NaN / ±Inf）而被跳过的条目数。
   InvalidValues: integer;
   # 上下文是否至少覆盖了一个基因（否则不会被应用）。
   IsApplied: boolean;
   # 命中模型基因、并参与对齐的条目数。
   Matched: integer;
   # 模型里未被上下文覆盖、继续沿用训练基线的基因名。
   MissingGenes: string;
   # 本次使用的对齐模式。
   Mode: ContextAlignmentMode;
   # 模型基因总数。
   NGene: integer;
   # 对齐过程的文字说明（降级、单基因、常量基因等）。
   Notes: iterates(String);
   # 对齐之后仍落在训练支持域之外的基因数（会被限幅“剪平”的部分）。
   OutsideSupport: integer;
   # 调用方提供的有效条目数（同名基因以最后一次出现的为准）。
   Provided: integer;
   # 对齐前后（仅命中基因）的 Spearman 秩相关系数。
   SpearmanBeforeAfter: double;
   # 无法映射到模型基因的名字（通常意味着基因 ID 空间不一致）。
   UnknownGenes: string;
}
