pfam.embedding {metaTraits} R Documentation

构建 Pfam 结构域的嵌入配置（词表 + 编码方式）

Description

Usage

pfam.embedding(pfams,
    minGenomes = 1,
    encoding = "normalized");

Arguments

pfams

可以是 R# 函数 read.pfam_proteomes 的输出，也可以直接是 一个包含各微生物基因组 Pfam.csv 的目录路径

minGenomes

词表剪枝阈值：Pfam 结构域至少要在这么多个基因组之中出现才会被保留，默认为 1（不剪枝）. [as integer]

encoding

编码方式：normalized 表示按基因组内的最大出现次数做归一化（默认）， binary 表示退化为 0/1 的 one-hot 编码. [as string]
