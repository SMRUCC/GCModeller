fuzzygene_solver_report {FuzzyGene} R Documentation

Solver diagnostics of one virtual perturbation (exit reason, residuals, saturation).

Description

Usage

fuzzygene_solver_report(fuzzygene, gene,
    mode = "knockout",
    steps = 0);

Arguments

fuzzygene

a trained (or restored) model. [as FuzzyGeneModel]

gene

the target gene of the virtual perturbation. [as string]

mode

knockout (default), knockdown or overexpression. [as string]

steps

maximum iteration steps; 0 uses the model configuration. [as integer]

env

the R# runtime environment used to report errors. [as Environment]

Details

One row with both the mutant and the wildtype run: exit_reason / iterations / free_residual / clamp_residual / out_of_support / pinned / attractor_period / omega / tolerance / lagged / elapsed_ms, plus the same fields prefixed with control_.

Read exit_reason first. Only Converged means the flat tail of the curve is a real steady state; MaxIterations is a truncated plateau, LimitCycle means the system oscillates (the period mean is the honest answer), SupportSaturated means the support clamp, not the model, produced the numbers, and Diverged means there is no answer. clamp_residual is a diagnostic only: the clamped gene is by construction not at a fixed point of the map, so it never goes to zero and must not be used as a convergence test.
