fuzzygene_sensitivity {FuzzyGene} R Documentation

Model self-check: omega invariance, step invariance and lag ordering robustness.

Description

Usage

fuzzygene_sensitivity(fuzzygene, gene,
    mode = "knockout",
    omegas = NULL,
    stepsList = NULL,
    sweepSteps = 50,
    referenceOmega = NaN,
    tolerance = 0.001,
    lagRatio = 0.1);

Arguments

fuzzygene

a trained (or restored) model. [as FuzzyGeneModel]

gene

the target gene of the virtual perturbation. [as string]

mode

knockout (default), knockdown or overexpression. [as string]

omegas

relaxation values to sweep, e.g. c(0.2, 0.5, 0.8, 1.0). [as double]

stepsList

iteration budgets to sweep, e.g. c(50, 200, 500). [as double]

sweepSteps

fixed iteration budget used by the omega sweep and the lag analysis. [as integer]

referenceOmega

omega used as the comparison baseline; NaN picks the value closest to 0.5. [as double]

tolerance

relative deviation threshold of the invariant flags. [as double]

lagRatio

relative trigger threshold of the lag definition. [as double]

env

the R# runtime environment used to report errors. [as Environment]

Details

Returns a named list:

  • omega: data.frame value / converged / iterations /

last_max_delta / max_abs_deviation / max_relative_deviation; the deviation columns are measured against reference_omega (see summary);

  • steps: the same shape for the iteration budget sweep, measured

against the largest step count;

  • lag: wide table gene + one column per omega, each cell is the

frame index at which that gene first reaches 10% (lagRatio) of its own final change;

  • spearman: wide table of pairwise Spearman rho between the omega runs,

computed on the genes that respond under every omega;

  • summary: one row data.frame with the two invariant flags, the

reference values, the responding gene count, the mean rho and the run count.

Read summary$omega_invariant first. FALSE means the end state still depends on the damping factor, i.e. the iteration has not converged and the trajectory is not a steady state. That is a property of the model, not a bug of this function.

Cost: about 2 x (length(omegas) + length(stepsList) + length(omegas)) solves. With the default grids on an 18k gene model this takes roughly one minute.
