save_fuzzygene {FuzzyGene} R Documentation

Save a trained model into a ``*.fuzzygene.zip`` package.

Description

Usage

save_fuzzygene(fuzzygene, file);

Arguments

fuzzygene

a trained model. [as FuzzyGeneModel]

file

the output package path. [as string]

env

the R# runtime environment used to report errors. [as Environment]

Details

writeBin is the generic R# way to do the same thing on a connection; this api is a convenience wrapper for scripts that already have a file path.

Authors

biosystem

Value

True when the package has been written
