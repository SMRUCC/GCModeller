fuzzygene_rank_perturbations {FuzzyGene} R Documentation

Rank candidate perturbations by their predicted response strength.

Description

Usage

fuzzygene_rank_perturbations(fuzzygene,
    candidates = 24,
    mode = "knockout");

Arguments

fuzzygene

a trained (or restored) model. [as FuzzyGeneModel]

candidates

number of candidate genes to evaluate; 0 means all modelled genes. [as integer]

mode

knockout (default), knockdown or overexpression. [as string]

env

the R# runtime environment used to report errors. [as Environment]

Details

Running a perturbation for every gene of a genome scale model takes hours, so only candidates genes (an evenly spaced sample of the modelled genes, no random numbers involved) are evaluated.

The score is the largest |Z| among the genes that were not clamped: the Z score of the target itself is the imposed shift, not a model prediction. Note that with clampToSupport enabled the largest |Z| often saturates at the same value for many candidates; the affected column (number of significant genes) is the tie breaker, and is a better ranking criterion in that case.
