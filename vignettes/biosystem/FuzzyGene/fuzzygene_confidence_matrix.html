fuzzygene_confidence_matrix {FuzzyGene} R Documentation

Export the confidence matrix of a trained model (same shape as the weight matrix).

Description

Usage

fuzzygene_confidence_matrix(fuzzygene,
    layout = "square",
    minConfidence = 0,
    genes = NULL);

Arguments

fuzzygene

a trained model. [as FuzzyGeneModel]

layout

square (default), regulators or compact. [as string]

minConfidence

edges with a smaller confidence are exported as zero; 0 keeps all. [as double]

genes

restrict the exported rows to these target genes; empty means all. [as string]

env

the R# runtime environment used to report errors. [as Environment]

Details

Rows and columns are exactly the same as in fuzzygene_regulation_matrix (same layout, same order), only the element value changes: W[i, j] becomes the confidence of the edge j -> i, that is the prior confidence when the edge is supported by the prior network and the absolute expression correlation |Pearson| otherwise.

Weight and confidence answer two different questions ("how strong / which direction" vs "how trustworthy"), so exporting both matrices and using weight for the edge width and confidence for the edge opacity or a cutoff is the usual combination:

 let w = fuzzygene::fuzzygene_regulation_matrix(model, layout = "compact");
 let c = fuzzygene::fuzzygene_confidence_matrix(model, layout = "compact");
 geneExpression::write.expr_matrix(w, file = "/path/weight.csv", id = "geneID");
 geneExpression::write.expr_matrix(c, file = "/path/confidence.csv", id = "geneID");
