fuzzygene_pbn {FuzzyGene} R Documentation

The qualitative (probabilistic boolean) layer of a trained model: CoD table and rules.

Description

Usage

fuzzygene_pbn(fuzzygene);

Arguments

fuzzygene

a trained model that was built with pbnRegularization != "none". [as FuzzyGeneModel]

env

the R# runtime environment used to report errors. [as Environment]

Details

Returns a named list:

  • cod: one row per (target, regulator) pair, columns target / regulator /

cod / rank; cod is the coefficient of determination of that parent set on the binarized matrix, i.e. how much of the boolean state of the target the regulator set explains;

  • rules: target / parents / n_parents / cod, the selected rule of each

target gene (parents joined by +);

  • targets: target / rules / best_cod, one row per analysed gene;
  • summary: one row with has_pbn / targets_analysed / skipped / genes /

warnings.

CoD is a consistency measure after binarization, not causal evidence: a rule can have a high CoD simply because the target and the parent are both driven by a third gene. Use it to suppress pure correlation edges and to report structure uncertainty, not as a substitute for perturbation data.
