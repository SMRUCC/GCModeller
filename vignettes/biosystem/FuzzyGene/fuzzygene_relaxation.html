fuzzygene_relaxation {FuzzyGene} R Documentation

Set the damping factor, the iteration budget and the tolerance used by the steady-state solver.

Description

Usage

fuzzygene_relaxation(fuzzygene,
    omega = 0.5,
    steps = 50,
    tolerance = 1E-06);

Arguments

fuzzygene

a trained (or restored) model. [as FuzzyGeneModel]

omega

damping factor in (0, 1]; 0.5 is the recommended value. [as double]

steps

maximum iteration steps, must be positive. [as integer]

tolerance

convergence threshold on the per step max change, must be positive. [as double]

env

the R# runtime environment used to report errors. [as Environment]

Details

These three values belong to the damped fallback path (z <- z + omega * (F(z) - z)). The default solver is a Levenberg-Marquardt root finder for F(z) - z = 0, and it is used whenever it can reduce the residual; the damping factor only matters when it falls back (or when solver = "legacy" / "anderson" is selected through fuzzygene_hybrid_config). With omega = 1 the fallback is the plain repeated application of F, which on a genome scale model often keeps oscillating instead of converging; omega = 0.5 is the usual compromise.

Always rerun the trajectory after changing these values, and check summary$exit_reason: only Converged means the flat tail is a real steady state; MaxIterations is a truncated plateau and LimitCycle means the system oscillates.

 model = FuzzyGene::fuzzygene_relaxation(model, omega = 0.5, steps = 80);
 let t = FuzzyGene::fuzzygene_trace_perturbation(model, "TPPP3");
 print(t$summary);
