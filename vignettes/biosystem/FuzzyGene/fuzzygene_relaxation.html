fuzzygene_relaxation {FuzzyGene} R Documentation

Set the damping factor, the iteration budget and the tolerance used by the steady-state solver.

Description

Usage

fuzzygene_relaxation(fuzzygene,
    omega = 0.5,
    steps = 50,
    tolerance = 1E-06);

Arguments

fuzzygene

a trained (or restored) model. [as FuzzyGeneModel]

omega

damping factor in (0, 1]; 0.5 is the recommended value. [as double]

steps

maximum iteration steps, must be positive. [as integer]

tolerance

convergence threshold on the per step max change, must be positive. [as double]

env

the R# runtime environment used to report errors. [as Environment]

Details

The trajectory produced by fuzzygene_trace_perturbation is the damped fixed-point iteration z <- z + omega * (F(z) - z). With omega = 1 (no damping) the iteration is the plain repeated application of F, and on a genome scale model that often keeps oscillating instead of converging; omega = 0.5 is the usual compromise between stability and speed.

Always rerun the trajectory after changing these values, and check summary$converged: a non converged run means the flat tail of the curve is a truncated plateau.

 model = FuzzyGene::fuzzygene_relaxation(model, omega = 0.5, steps = 80);
 let t = FuzzyGene::fuzzygene_trace_perturbation(model, "TPPP3");
 print(t$summary);
