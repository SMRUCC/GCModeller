fuzzygene_modules {FuzzyGene} R Documentation

The coarse grained module layer (FCM): module assignment, bounded steady state and warm start.

Description

Usage

fuzzygene_modules(fuzzygene);

Arguments

fuzzygene

a trained model built with fcmWarmStart = TRUE. [as FuzzyGeneModel]

env

the R# runtime environment used to report errors. [as Environment]

Details

Returns a named list:

  • table: gene / module / baseline, the module assignment

computed at fit time (only present when fcmWarmStart = TRUE);

  • modules: module / n_genes / activation, the bounded

activation of the module level fuzzy cognitive map on the training baseline;

  • initial: gene / warm_start / surrogate, the per gene

initial state derived from the module state (this is what the root finder starts from).

  • summary: available / module_count / converged /

steps / period / notes.

The module layer is bounded by construction, so it always terminates with either a fixed point or a detected limit cycle. It is a rough skeleton: the module average erases the individual genes, which is why the default is off and the surrogate must never replace the per gene prediction.
