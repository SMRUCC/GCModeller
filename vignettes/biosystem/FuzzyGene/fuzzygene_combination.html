fuzzygene_combination {FuzzyGene} R Documentation

Non-additive (synergy / antagonism) analysis of a two gene combination.

Description

Usage

fuzzygene_combination(fuzzygene, geneA, geneB,
    mode = "knockout",
    steps = 60,
    top = 50);

Arguments

fuzzygene

a trained (or restored) model. [as FuzzyGeneModel]

geneA

the first target gene. [as string]

geneB

the second target gene; must differ from geneA. [as string]

mode

knockout (default), knockdown or overexpression. [as string]

steps

iteration budget of each solve. [as integer]

top

number of genes kept in top and trajectory. [as integer]

env

the R# runtime environment used to report errors. [as Environment]

Details

Additive expectation is control + (A - control) + (B - control); the non additive effect is joint - additive. Positive means synergy, negative means antagonism.

Returns a named list:

  • summary: one row with the two genes and max_abs_non_additive;
  • table: the full 18k gene table gene / single_a / single_b /

joint / additive / non_additive;

  • top: the top genes ranked by |non_additive|;
  • trajectory: the frame level version iteration / gene /

additive / joint / non_additive, which shows whether the deviation appears together with the single perturbations or only later.
