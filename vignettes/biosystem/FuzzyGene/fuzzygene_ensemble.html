fuzzygene_ensemble {FuzzyGene} R Documentation

Ensemble (resampled boolean structure) prediction of virtual perturbations.

Description

Usage

fuzzygene_ensemble(fuzzygene, genes,
    mode = "knockout",
    samples = 16);

Arguments

fuzzygene

a trained model built with pbnRegularization != "none". [as FuzzyGeneModel]

genes

the genes to perturb. [as string]

mode

knockout (default), knockdown or overexpression. [as string]

samples

how many PBN resamples; <= 0 falls back to the configured value. [as integer]

env

the R# runtime environment used to report errors. [as Environment]

Details

Each sample rebuilds the network by drawing one rule per target gene from the probabilistic boolean network according to its CoD derived probability, and then solves the continuous perturbation again. The spread of the resulting states therefore measures structural uncertainty (which regulatory logic the data supports), not numerical noise.

Returns a named list:

  • table: one row per (perturbation, gene) with mean / sd /

lower (5%) / upper (95%) / sign_agreement / high_fraction / reference;

  • summary: one row per perturbation with samples /

converged_fraction / degenerate / notes;

  • attractors: the boolean attractor period distribution

(perturbation / period / count), zero rows when no cycle was detected.

sign_agreement is the single most useful column: about 0.5 means the direction of that gene's response is decided by the model noise, so it must not be reported as a finding.
