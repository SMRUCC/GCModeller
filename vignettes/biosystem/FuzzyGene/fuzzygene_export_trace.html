fuzzygene_export_trace {FuzzyGene} R Documentation

Export the two trajectory matrices of one virtual perturbation to a folder.

Description

Usage

fuzzygene_export_trace(fuzzygene, gene, dir,
    mode = "knockout",
    steps = 0,
    dt = 1);

Arguments

fuzzygene

a trained (or restored) model. [as FuzzyGeneModel]

gene

the target gene of the virtual perturbation. [as string]

dir

the output folder (created when missing). [as string]

mode

knockout (default), knockdown or overexpression. [as string]

steps

maximum iteration steps; 0 uses the model configuration. [as integer]

dt

time unit of one iteration frame, used by the sidecar only. [as double]

env

the R# runtime environment used to report errors. [as Environment]

Details

Writes, into dir:

  • trace.mutant.csv / trace.wildtype.csv: gene x iteration matrices;
  • *.sampleinfo.json: one SampleInfo row per column (time / iteration

/ omega / converged / perturbed_genes ...), ready for the ExperimentDesigner pipeline;

  • trace.perturbation.json: the run summary plus the whole max_delta sequence.

dt only affects metadata$time of the sidecar (time = iteration * dt); it does not change the matrix. Leave it at 1 unless the model is a lagged (time series) model and the sampling interval is known.

 let files = FuzzyGene::fuzzygene_export_trace(model, "TPPP3", "/path/trace", mode = "knockout");
 print(files);
