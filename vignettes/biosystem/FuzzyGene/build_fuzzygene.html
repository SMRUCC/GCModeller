build_fuzzygene {FuzzyGene} R Documentation

Build an untrained neuro-fuzzy gene regulatory network model.

Description

Usage

build_fuzzygene(x,
    prior = NULL,
    config = NULL);

Arguments

x

the gene expression matrix (rows = genes, columns = samples). [as GeneExpressionData]

prior

an optional prior regulatory network created by the bnlearn package (prior_edges); when omitted the candidate regulators are selected by correlation only. [as PriorNetwork]

config

the configuration created by fuzzygene::fuzzygene_config; Nothing uses the defaults. [as FuzzyGeneConfig]

env

the R# runtime environment (unused). [as Environment]

Details

The expression matrix provides the training data: when it carries TimePoints with at least three distinct values the model learns the lagged map x(t+1) = F(x(t)), otherwise it learns the static map x_g = F(regulators). The prior network supplies TF-to-target edges that are used to order (not to force) the candidate inputs.
