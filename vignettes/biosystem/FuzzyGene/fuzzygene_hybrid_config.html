fuzzygene_hybrid_config {FuzzyGene} R Documentation

Chainable mutator of the solver and hybrid layer options.

Description

Usage

fuzzygene_hybrid_config(config,
    solver = "newton",
    maxNewtonIterations = 20,
    andersonDepth = 5,
    calibration = "none",
    calibrationEpsilon = 0.05,
    calibrationMinScale = 0.05,
    clampInputToSupport = TRUE,
    clampOutputToSupport = TRUE,
    maxRegulatorCollinearity = 1,
    pbnRegularization = "none",
    pbnMinCod = 0.05,
    pbnWeight = 1,
    pbnMaxParents = 2,
    pbnMaxGenes = 2000,
    pbnCandidateSize = 5,
    ensembleSamples = 0,
    modeBiasWeight = 0,
    fcmWarmStart = FALSE,
    fcmModules = 48,
    fcmAlpha = 1,
    fcmMaxSteps = 200);

Arguments

config

the configuration created by fuzzygene_config. [as FuzzyGeneConfig]

solver

newton (default), anderson, legacy (the old damped iteration) or advance (lagged/time series only: plain time stepping, no steady state claim). [as string]

calibration

none (default), spectral (scale the cyclic part until the spectral radius of the assembled Jacobian is below 1 - epsilon) or row-l1 (the conservative row norm bound). [as string]

calibrationEpsilon

target margin 1 - epsilon of the spectral radius. Default 0.05. [as double]

calibrationMinScale

lower bound of one calibration pass, keeps the model from collapsing. Default 0.05. [as double]

clampInputToSupport

clamp the antecedent inputs to the training domain of each regulator. Turning this off re-enables the unbounded extrapolation of the outermost rules. Default TRUE. [as boolean]

clampOutputToSupport

clamp the predicted expression to the training support. Default TRUE. [as boolean]

maxRegulatorCollinearity

upper bound of the pairwise |Pearson| between the selected regulators; 1 disables the constraint (default). Lowering it to 0.95 improves the conditioning of the least squares step at the price of selecting fewer data driven regulators. [as double]

pbnRegularization

none (default), filter (drop correlation candidates whose CoD is too low) or weighted (order the candidates by CoD). Enabling it also makes fuzzygene_ensemble available. [as string]

pbnMinCod

minimum CoD for a candidate parent set. Default 0.05. [as double]

pbnWeight

weight of the CoD term when pbnRegularization = "weighted". Default 1. [as double]

pbnMaxParents

maximum parents enumerated per target gene. Default 2. [as integer]

pbnMaxGenes

gene limit of the qualitative layer; above it the PBN layer is skipped. Default 2000. [as integer]

pbnCandidateSize

candidate pool size per target gene (prior TFs plus the top correlated genes). Default 5. [as integer]

ensembleSamples

default sample count of fuzzygene_ensemble: how many times the PBN rules are resampled. 0 (default) keeps the deterministic single solve. [as integer]

modeBiasWeight

how strongly a sampled boolean mode pulls the continuous solve; 0 (default) only reports the boolean consistency without changing the numerical result. [as double]

fcmWarmStart

enable the module level fuzzy cognitive map: it provides a bounded warm start for the per gene root finding and a surrogate answer when the solver detects a limit cycle. Default FALSE. [as boolean]

fcmModules

number of modules of the coarse grained layer. Default 48. [as integer]

fcmAlpha

slope of the sigmoid activation. Default 1. [as double]

fcmMaxSteps

propagation budget of the module layer. Default 200. [as integer]

env

the R# runtime environment used to report errors. [as Environment]

Details

The existing fuzzygene_config already carries 30 optional arguments; adding the solver / PBN / FCM knobs there would make it unusable and would break every script that relies on positional arguments. This function mutates a configuration object in place instead, so the whole thing stays readable:

 let opts = FuzzyGene::fuzzygene_config(maxRegulators = 6, mfCount = 3);
 opts = FuzzyGene::fuzzygene_hybrid_config(opts,
     solver = "newton", pbnRegularization = "weighted", ensembleSamples = 16);

Defaults are chosen so that calling this function with only config changes nothing important: the Newton root finder is already the default solver, and the stability calibration stays off (the root finder does not need a contractive map, while calibrating a strongly cyclic fit can drop R2 from 0.86 to 0.014 — that has to be an explicit choice).
