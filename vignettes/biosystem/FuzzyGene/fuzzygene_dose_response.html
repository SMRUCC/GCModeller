fuzzygene_dose_response {FuzzyGene} R Documentation

Dose-response curve of one virtual perturbation.

Description

Usage

fuzzygene_dose_response(fuzzygene, gene,
    doses = NULL,
    steps = 60,
    top = 50);

Arguments

fuzzygene

a trained (or restored) model. [as FuzzyGeneModel]

gene

the target gene of the virtual perturbation. [as string]

doses

dose points in [0, 1]; NULL uses 5 evenly spaced points. [as double]

steps

iteration budget of each solve. [as integer]

top

number of genes to return; 0 means all. [as integer]

env

the R# runtime environment used to report errors. [as Environment]

Details

Dose d runs from 0 (pin the gene at its baseline) to 1 (full knockout); the clamped value is baseline x (1 - d). Note that d = 0 is not the same as "no perturbation": the gene is held fixed while the wildtype trajectory drifts away from the baseline, which is why its own fold change is 0 at d = 0 but other genes can still move.

Only the top genes are returned (ranked by |z| at the largest dose) to keep the data.frame small; pass top = 0 for all 18k genes.

 let r = FuzzyGene::fuzzygene_dose_response(model, "TPPP3", doses = c(0, 0.5, 1));
 print(r);
