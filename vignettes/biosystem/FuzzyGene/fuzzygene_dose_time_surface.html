fuzzygene_dose_time_surface {FuzzyGene} R Documentation

Dose x iteration response surface of one virtual perturbation.

Description

Usage

fuzzygene_dose_time_surface(fuzzygene, gene,
    doses = NULL,
    steps = 60,
    top = 20);

Arguments

fuzzygene

a trained (or restored) model. [as FuzzyGeneModel]

gene

the target gene of the virtual perturbation. [as string]

doses

dose points in [0, 1]; NULL uses 5 evenly spaced points. [as double]

steps

iteration budget of each solve. [as integer]

top

number of genes to keep. [as integer]

env

the R# runtime environment used to report errors. [as Environment]

Details

Every cell is mutant(t) - control(t) at the same frame, i.e. the drift of the system itself has already been subtracted. Only the top genes (ranked by |z| at the largest dose) are kept, so the cube stays small enough to plot as a contour or a 3D surface.
