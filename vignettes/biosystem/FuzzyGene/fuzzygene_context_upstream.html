fuzzygene_context_upstream {FuzzyGene} R Documentation

Inject the result of an **upstream perturbation** as the control baseline (iterative perturbation).

Description

Usage

fuzzygene_context_upstream(fuzzygene, upstream,
    useMutant = TRUE,
    minCoverage = 0);

Arguments

fuzzygene

a trained model. [as FuzzyGeneModel]

upstream

an InterventionResult, e.g. one element of knockouts(...). [as InterventionResult]

useMutant

take the mutant (perturbed) state instead of the wildtype one. Default TRUE. [as boolean]

minCoverage

minimum fraction (0-1) of model genes the upstream result must cover; 0 disables the check. [as double]

env

the R# runtime environment used to report errors. [as Environment]

Details

After this call the mutant state of the upstream experiment becomes the reference state of the model, so the next perturbation reports "effect of B given that A is already knocked out" instead of "effect of B from the original baseline".

 let round1 = model |> knockouts(c("A"));           # A 失活
 print(fuzzygene::fuzzygene_context_upstream(model, round1[[1]]));
 let round2 = model |> knockouts(c("B"));           # 在 A 失活的背景上敲 B

useMutant = TRUE (default) takes MutantMeans; FALSE takes WildtypeMeans, which restores the reference frame of the upstream round. An upstream result flagged as Undefined (the target gene was not modelled) is rejected instead of being silently applied.

biosystem

Value

a multi line coverage summary, or an R# error object when the context is rejected
