fuzzygene_trace_perturbation {FuzzyGene} R Documentation

Record the whole-genome steady-state trajectory of one virtual perturbation.

Description

Usage

fuzzygene_trace_perturbation(fuzzygene, gene,
    mode = "knockout",
    steps = 0);

Arguments

fuzzygene

a trained (or restored) model. [as FuzzyGeneModel]

gene

the target gene of the virtual perturbation. [as string]

mode

knockout (default), knockdown or overexpression. [as string]

steps

maximum iteration steps; 0 uses the model configuration. [as integer]

env

the R# runtime environment used to report errors. [as Environment]

Details

Returns a named list:

  • mutant: a Matrix (rows = all genes, columns = iteration frames mut_t000...);
  • wildtype: the same shape for the unperturbed baseline;
  • convergence: a data.frame iteration / max_delta of the mutant run;
  • control_convergence: the same for the wildtype run;
  • changes: a data.frame gene / fold_change / percent_change / z_score /

significant of the final state;

  • summary: a one row data.frame with the perturbation definition and the solver diagnostics.

mutant and wildtype are .NET HTS.DataFrame.Matrix objects (rows = genes, columns = frames), not R matrices, so dim() returns 1 on them. Pass them straight to a downstream consumer instead:

 let trace = FuzzyGene::fuzzygene_trace_perturbation(model, "TPPP3");
 geneExpression::write.expr_matrix(trace$mutant, file = "/path/mutant.csv", id = "geneID");

The column index is a solver iteration, not biological time. The default solver finds the constrained fixed point of F(z) - z = 0 (Levenberg-Marquardt, see fuzzygene_hybrid_config(solver = ...)), so the frames are Newton steps and the number of frames is small (single digit for a well posed network). Only when the solver falls back to the damped iteration does omega shape the curve (fuzzygene_relaxation), and only a lagged (time series) model in advance mode makes one frame equal to one sampling interval.

Read convergence / summary$converged before interpreting the curve: a flat tail produced by running out of steps is a truncated plateau, not a steady state.

wildtype is the control run: it starts from the same baseline and is iterated to its own fixed point, so foldchange is now "mutant fixed point minus wildtype fixed point" instead of "mutant minus the training mean". The training mean is generally not a fixed point of a nonlinear fuzzy map, so the previous definition mixed the perturbation effect with the model's own drift; the wildtype trajectory still exposes that drift, which is worth checking (a large drift means the fit is inconsistent with its own steady state).
