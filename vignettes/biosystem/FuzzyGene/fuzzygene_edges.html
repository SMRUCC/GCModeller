fuzzygene_edges {FuzzyGene} R Documentation

Export the signed regulatory edge table of a trained model.

Description

Usage

fuzzygene_edges(fuzzygene);

Arguments

fuzzygene

a trained model. [as FuzzyGeneModel]

env

the R# runtime environment used to report errors. [as Environment]

Details

The edge weight is the average analytic partial derivative ∂x_target/∂x_regulator over the training support: positive means activation, negative means repression. confidence is the prior confidence when the edge is supported by the prior network, otherwise the absolute expression correlation.

Authors

biosystem

Value

a data.frame with columns source, target, weight, regulation, confidence and prior
