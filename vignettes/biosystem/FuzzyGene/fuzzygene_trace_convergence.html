fuzzygene_trace_convergence {FuzzyGene} R Documentation

Solver diagnostics of one virtual perturbation, without building the two large matrices.

Description

Usage

fuzzygene_trace_convergence(fuzzygene, gene,
    mode = "knockout",
    steps = 0);

Arguments

fuzzygene

a trained (or restored) model. [as FuzzyGeneModel]

gene

the target gene of the virtual perturbation. [as string]

mode

knockout (default), knockdown or overexpression. [as string]

steps

maximum iteration steps; 0 uses the model configuration. [as integer]

env

the R# runtime environment used to report errors. [as Environment]

Details

Same solve as fuzzygene_trace_perturbation but only the convergence / control_convergence / summary elements are returned. Use it when all you need is the log10(max_delta) versus iteration plot: constructing the 18k x 250 matrices is the expensive part.

Authors

biosystem

Value

a named list with convergence, control_convergence and summary
