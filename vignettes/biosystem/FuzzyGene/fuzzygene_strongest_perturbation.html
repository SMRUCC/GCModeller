fuzzygene_strongest_perturbation {FuzzyGene} R Documentation

The single gene whose perturbation produces the strongest predicted response.

Description

Usage

fuzzygene_strongest_perturbation(fuzzygene,
    candidates = 24,
    mode = "knockout");

Arguments

fuzzygene

a trained (or restored) model. [as FuzzyGeneModel]

candidates

number of candidate genes to evaluate; 0 means all modelled genes. [as integer]

mode

knockout (default), knockdown or overexpression. [as string]

env

the R# runtime environment used to report errors. [as Environment]

Details

Authors

biosystem

Value

the gene name, or an R# error object when nothing could be evaluated
