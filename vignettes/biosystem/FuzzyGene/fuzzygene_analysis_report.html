fuzzygene_analysis_report {FuzzyGene} R Documentation

Run every analysis once and write the tables to a folder.

Description

Usage

fuzzygene_analysis_report(fuzzygene, gene,
    geneA = NULL,
    geneB = NULL,
    dir = NULL,
    mode = "knockout",
    omegas = NULL,
    stepsList = NULL,
    doses = NULL,
    sweepSteps = 50,
    doseSteps = 60,
    combinationSteps = 60,
    top = 50,
    surfaceTop = 20,
    lagRatio = 0.1,
    tolerance = 0.001);

Arguments

fuzzygene

a trained (or restored) model. [as FuzzyGeneModel]

gene

the target gene of the single perturbation analyses. [as string]

geneA

the first gene of the combination analysis; empty skips that part. [as string]

geneB

the second gene of the combination analysis; empty skips that part. [as string]

dir

the output folder (created when missing). [as string]

mode

knockout (default), knockdown or overexpression. [as string]

omegas

relaxation grid; NULL uses c(0.2, 0.5, 0.8, 1.0). [as double]

stepsList

step grid of the invariance check; NULL uses c(50, 200, 500). [as double]

doses

dose grid; NULL uses 5 evenly spaced points. [as double]

sweepSteps

fixed iteration budget of the omega / lag analyses. [as integer]

doseSteps

iteration budget of the dose analyses. [as integer]

combinationSteps

iteration budget of the combination analysis. [as integer]

top

number of genes kept in the dose and combination tables. [as integer]

surfaceTop

number of genes kept in the dose-time surface. [as integer]

lagRatio

relative trigger threshold of the lag definition. [as double]

tolerance

relative deviation threshold of the invariant flags. [as double]

env

the R# runtime environment used to report errors. [as Environment]

Details

Writes into the folder: analysis.sensitivity.csv (omega + step sweeps), analysis.lag.csv, analysis.spearman.csv, analysis.dose_response.csv, analysis.dose_time_surface.csv, analysis.combination.csv (when both genes are given) and analysis.report.json (grid definition, invariant flags, run count, elapsed time).

This is the cheap way to get everything: calling the four analysis apis separately would repeat the dose sweep twice. Expect one to two minutes on an 18k gene model with the default grids.

 let files = FuzzyGene::fuzzygene_analysis_report(
     model, "TPPP3", geneA = "HSD17B3", geneB = "TPPP3", dir = "/path/analysis");
 print(files);
