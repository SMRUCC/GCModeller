make_profile {geneTree} R Documentation

Create the training/solving configuration profile of the GeneTree model.

Description

Usage

make_profile(
    profile = Fast,
    population = 100,
    iterations = 60,
    cells = 0,
    max.genes = 0,
    max.regulators = -1,
    include.undirected = TRUE);

Arguments

profile

the performance profile: fast (at most 1000 cells per model, top 10 regulators, 40 boosting rounds), balanced (3000 cells, top 20 regulators, 100 rounds) or full (all of the cells and all of the regulators). [as GeneTreeProfile]

population

the number of cells that are used as the independent initial states of the damped fixed point iteration, more cells give a more reliable population level statistic but cost more time. [as integer]

iterations

the maximum iteration rounds of the fixed point solving. [as integer]

cells

the maximum number of cells that is used by each gene model, 0 keeps the value of the selected profile. [as integer]

max.genes

only the first n target genes(ordered by the regulator count in descending order) are trained, 0 means all of the target genes. [as integer]

max.regulators

the number of the regulators that is kept for each target gene(the top n regulator ordered by the mutual information in descending order), a negative value keeps the value of the selected profile, 0 keeps all of them. [as integer]
