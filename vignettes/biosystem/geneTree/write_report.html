write_report {geneTree} R Documentation

Export the training report as two readable table files.

Description

Usage

write_report(report, folder);

Arguments

report

the TrainingReport object returned by the fit_tree api. [as TrainingReport]

folder

the output directory: the report.tsv(fitting quality of each gene model) and the importance.tsv(split importance of each regulator) files are written into this directory, it will be created if it is not exists. [as string]

Details

Authors

biosystem

Value

TRUE when the table files have been written.

clr value class

  • boolean
