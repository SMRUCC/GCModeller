perturb_combined {geneTree} R Documentation

Run a combined in silico intervention on a set of genes at the same time.

Description

Usage

perturb_combined(tree, genes,
    mode = Knockout);

Arguments

tree

the trained XGBoostGRN model object. [as XGBoostGRN]

genes

a character vector of the gene id that are perturbed together.

mode

the intervention mode of all of the target genes: Knockout, Knockdown, Overexpression or Custom. [as InterventionMode]

env

the R# runtime environment object. [as Environment]

Details

the Spec property of the result object is a synthetic intervention specification whose gene name is the + joined id list.

Authors

biosystem

Value

one InterventionResult object of the combined intervention, the non additive synergy/antagonism effect of the gene combination is kept; an R# error message object is returned when the prediction fails.

clr value class

  • InterventionResult
