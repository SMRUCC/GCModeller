load_expression {geneTree} R Documentation

Attach the gene expression matrix to the regulation graph, the created model is

Description

not trained yet.

Usage

load_expression(graph, expr,
    config = NULL);

Arguments

graph

the regulation graph object that is created by the load_topology api. [as GeneRegulationGraph]

expr

the gene expression matrix object(rows are genes, columns are samples), which could be loaded from a csv table file via the geneExpression::load.expr api. the numeric values of the model training and the perturbation are all taken from this matrix(the ARACNE model archive stores the rank transformed vectors instead of the raw expression values). [as Matrix]

config

the configuration object created by the make_profile api. [as GeneTreeConfig]
