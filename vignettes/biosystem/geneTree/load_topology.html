load_topology {geneTree} R Documentation

Build the regulation graph model from the ARACNE inferred network.

Description

Usage

load_topology(aracne,
    config = NULL);

Arguments

aracne

the ARACNE network object, which could be created by the aracne package module or loaded from the model zip archive via readBin. [as AracneNetwork]

config

the configuration object created by the make_profile api; the max_regulators and include_undirected_edges options determine the structure of the graph. [as GeneTreeConfig]

Details

Authors

biosystem

Value

the GeneRegulationGraph object: target gene -> regulators.
