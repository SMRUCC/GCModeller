solver_history {geneTree} R Documentation

Get the diagnostics of the last fixed point solving.

Description

Usage

solver_history(tree);

Arguments

tree

the trained XGBoostGRN model object. [as XGBoostGRN]

env

the R# runtime environment object. [as Environment]

Details

Authors

biosystem

Value

a list with the slots iterations, converged, converged_cells, max_change, population and history(the maximum relative change of each iteration); an R# error message object is returned when no perturbation experiment has been run yet.
