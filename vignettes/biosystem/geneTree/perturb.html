perturb {geneTree} R Documentation

Set the expression value of a set of genes to the given values, i.e. run a

Description

Custom mode in silico intervention.

Usage

perturb(tree, genes, expression);

Arguments

tree

the trained XGBoostGRN model object. [as XGBoostGRN]

genes

a character vector of the target gene id.

expression

a numeric vector of the expected expression value of each target gene, in the same order as genes; the genes are set to these values and are clamped during the whole iteration.

env

the R# runtime environment object. [as Environment]

Details

Authors

biosystem

Value

the InterventionResult object of the intervention, which could be exported via the make_exports api of the bnlearn package module; an R# error message object is returned when the sizes of the two vectors do not match or the prediction fails.

clr value class

  • InterventionResult
