fit_tree {geneTree} R Documentation

Train the gradient boosting tree models of each target gene.

Description

Usage

fit_tree(tree);

Arguments

tree

the untrained XGBoostGRN model object. [as XGBoostGRN]

env

the R# runtime environment object. [as Environment]

Details

the training is parallel over the target genes, the training progress is written to the console when the verbose option of the configuration is on.

Authors

biosystem

Value

the TrainingReport object: the R²/RMSE of each gene model, the comparison against the mean baseline and the split importance of each regulator; an R# error message object is returned when the training fails.
