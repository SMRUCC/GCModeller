discovered_edges {geneTree} R Documentation

Get the candidate edges that were examined by the residual two-stage structure discovery.

Description

Usage

discovered_edges(tree,
    top.n = 50,
    accepted.only = TRUE);

Arguments

tree

the trained XGBoostGRN model object. [as XGBoostGRN]

top.n

the number of the records that are ordered by the R² gain in descending order, 0 returns all of them. [as integer]

accepted.only

when TRUE only the accepted new edges are returned. [as boolean]

env

the R# runtime environment object. [as Environment]

Details

the delta_r2 of an accepted edge is the validation R² gain that the edge brought to its target gene model, the correlation column is the pearson correlation between the target gene residual and the candidate gene expression.

Authors

biosystem

Value

a dataframe whose columns are gene, regulator, status, correlation, delta_r2, r2_before, r2_after, splits, sensitivity and reason; an R# error message object is returned when the model does not contain any discovery result.

clr value class

  • dataframe
