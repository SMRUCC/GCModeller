feature_importance {geneTree} R Documentation

Get the split importance of the regulators, this table is the data driven

Description

"sign and weight" of the ARACNE network edges.

Usage

feature_importance(tree,
    top.n = 20);

Arguments

tree

the trained XGBoostGRN model object. [as XGBoostGRN]

top.n

the number of the regulator records that are ordered by the sensitivity in descending order, 0 returns all of them. [as integer]

env

the R# runtime environment object. [as Environment]

Details

Authors

biosystem

Value

a dataframe whose columns are gene, regulator, rank, mi, correlation, splits and sensitivity.

clr value class

  • dataframe
