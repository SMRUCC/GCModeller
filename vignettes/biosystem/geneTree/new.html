new {geneTree} R Documentation

Create the GeneTree model from the ARACNE network and the gene expression matrix.

Description

Usage

new(aracne, expr,
    config = NULL);

Arguments

aracne

the ARACNE inferred network object. [as AracneNetwork]

expr

the gene expression matrix object(rows are genes, columns are samples). [as Matrix]

config

the configuration object created by the make_profile api. [as GeneTreeConfig]

env

the R# runtime environment object. [as Environment]

Details

this function is the combination of the load_topology and the load_expression api, the model should be trained by the fit_tree api before any virtual perturbation experiment.

Authors

biosystem

Value

the untrained XGBoostGRN model object; an R# error message object is returned when the network or the expression matrix is invalid.

clr value class

  • XGBoostGRN
