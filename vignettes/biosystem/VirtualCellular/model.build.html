model.build {VirtualCellular} R Documentation

由加载好的表达数据装配虚拟细胞模型（纯计算，不写任何文件）。

Description

Usage

model.build(exp,
    opt = NULL,
    seed = 0);

Arguments

exp

由 load_expr 得到的表达数据（含对照矩阵与细胞元数据）. [as ExpressionStream]

opt

CellularAI 参数；NULL 使用默认值. [as CellularAiModel]

seed

随机种子（写入模型清单，供后续扰动复现）. [as integer]

Authors
