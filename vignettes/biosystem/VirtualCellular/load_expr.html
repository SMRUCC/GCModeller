load_expr {VirtualCellular} R Documentation

Description

Usage

load_expr(expr, meta,
    stages = NULL,
    limit = 0);

Arguments

stages

只保留这些期别的细胞；NULL 表示全量. [as string]

limit

每个期别最多保留的细胞数；0 表示不限制. [as integer]

expr

表达矩阵 CSV（行=基因，列=细胞）. [as string]

meta

细胞元数据 CSV（需含 ID / patient_id / stage / type 列）. [as string]

Details

Value

this function returns data object of type ExpressionStream.
