as_perturbation {VirtualCellular} R Documentation

把模型包装成虚拟扰动实验对象（纯计算，不做任何 IO）。

Description

Usage

as_perturbation(model,
    cells = 400,
    seed = 0);

Arguments

model

由 model.build 或 model.open 得到的模型. [as VirtualCellModel]

cells

默认合成细胞数；intervention 包的 api 未显式指定时使用. [as integer]

seed

随机种子. [as integer]
