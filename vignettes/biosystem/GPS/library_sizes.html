library_sizes {GPS} R Documentation

Get the raw library size of every training sample (the denominator of the CPM normalization).

Description

Usage

library_sizes(gps);

Arguments

gps

the trained model object. [as GPSModel]

Details

Authors

biosystem

Value

a numeric vector of the library sizes, one value per training sample; it is exported so that the caller can reason about the count scale of the model output.

clr value class

  • double
