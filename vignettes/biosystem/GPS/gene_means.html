gene_means {GPS} R Documentation

Get the per gene mean of the preprocessed expression data (log-CPM scale).

Description

Usage

gene_means(gps);

Arguments

gps

the trained model object. [as GPSModel]

Details

Together with GPS::gene_sds this vector defines the z-score normalization of the model: z = (log2(cpm + 1) - mean) / sd. External context profiles must be normalized with exactly these two vectors before they are injected via GPS::set_context.

Authors

biosystem

Value

a numeric vector, one value per modelled gene.
