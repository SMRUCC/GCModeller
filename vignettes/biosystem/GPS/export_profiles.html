export_profiles {GPS} R Documentation

Write the mutant (and the control) expression profiles of a set of in silico perturbation

Description

results as csv matrix files.

Usage

export_profiles(results, file,
    controlFile = NULL);

Arguments

results

a collection of the InterventionResult object, for example the value returned by the knockouts / knockdown / overexpress api of the bnlearn package.

file

the output file path of the mutant matrix (mutant_means_matrix.csv), rows are genes and columns are the intervention conditions. [as string]

controlFile

the output file path of the control matrix; when it is nothing the file wildtype_means_matrix.csv is written next to file. [as string]

env

the R# runtime environment. [as Environment]

Details

The generated csv files use exactly the same layout as the ones produced by the make_exports api (four comment lines followed by a Gene,<condition>... header), but only the two matrices that are needed by the downstream submission builder are written; make_exports writes about eight tables per run which is several gigabytes for a few hundred conditions.

Authors

biosystem

Value

TRUE when both matrix files have been written; an R# error message object is returned when the input can not be treated as a collection of InterventionResult.

clr value class

  • any kind
