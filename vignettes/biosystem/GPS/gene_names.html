gene_names {GPS} R Documentation

Get the gene ids of the trained GPS model, in the modelling order.

Description

Usage

gene_names(gps);

Arguments

gps

the trained model object created by GPS::build_gps or restored by readBin. [as GPSModel]

Details

The gene order of the model is not necessarily the same as the order of the input expression matrix, so any external profile must be aligned against this vector instead of against the raw input file.

Authors

biosystem

Value

a character vector of the gene id (Ensembl gene id for the human model), the order of this vector is the row order of every expression profile produced by the model.

clr value class

  • string
