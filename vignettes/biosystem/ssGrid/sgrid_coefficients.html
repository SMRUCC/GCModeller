sgrid_coefficients {ssGrid} R Documentation

get the coefficient matrix of the fitted S-system model

Description

Usage

sgrid_coefficients(network,
    type = "net",
    original = TRUE);

Arguments

network

[as SSystemNetwork]

type

the matrix type: net(default, the net elasticity g - h), g(the kinetic order of the synthesis term) or h(the kinetic order of the degradation term). [as string]

original

use the original gene symbol instead of the sanitized gene id? default is TRUE. [as boolean]

Details

Authors

biosystem

Value

a wide dataframe: the rows are the target genes and the columns are the regulators. the matrix element is the fitted coefficient.

clr value class

  • dataframe

Examples

 let net = sgrid_coefficients(network);
 let g = sgrid_coefficients(network, type = "g");
