perturb_export {ssGrid} R Documentation

save the virtual perturbation screening result as csv files

Description

Usage

perturb_export(screening, dir);

Arguments

screening

the output of the perturb api. [as ScreeningResult]

dir

the output directory. [as string]

Details

this function writes the control.csv and the perturb_records.csv; the trajectory of each perturbation design is not kept in the screening result object, so please use the export parameter of the perturb api if the trajectory files are required.

Authors

biosystem

Value

the number of the files that has been written.

clr value class

  • integer

Examples

 perturb_export(resp, "/tmp/ko");
