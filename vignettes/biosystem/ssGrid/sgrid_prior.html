sgrid_prior {ssGrid} R Documentation

read the prior knowledge regulatory network from a csv table or a data.frame

Description

Usage

sgrid_prior(data);

Arguments

data

a csv file path, or a data.frame object which contains the columns of tf,target,type,confidence,evidence(the column name is case insensitive, and the confidence column could be a numeric score or the High/Medium/Low label).

env

[as Environment]

Details

Authors

biosystem

Value

a PriorNetwork object, or a R# error message object.

clr value class

  • PriorNetwork

Examples

 let prior = sgrid_prior("/data/TF_target_prior_curated.csv");
 let prior = sgrid_prior(data.frame(tf = ..., target = ..., type = ..., confidence = ...));
