sgrid_simulate {ssGrid} R Documentation

integrate the fitted S-system model and return the trajectory

Description

Usage

sgrid_simulate(network,
    final.time = 0,
    context = NULL,
    genes = NULL);

Arguments

network

[as SSystemNetwork]

final.time

the final time of the integration, zero means the end of the fitted time axis. [as double]

context

the optional initial state of the ODE integration, this value should be in the model state space(see also: ssGrid.sgridContext()), the first sample point of the fitted time series will be used if this parameter is not provided. [as list]

genes

the optional gene list that returns in the trajectory table.

env

[as Environment]

Details

Authors

biosystem

Value

a dataframe, the first column #Time is the time axis.

clr value class

  • dataframe

Examples

 let baseline = sgrid_simulate(network, context = sgrid_context(network, counts));
