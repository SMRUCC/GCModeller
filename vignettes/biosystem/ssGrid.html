The S-system based gene regulatory network inference toolkit (基于 S-system 动力学系统的基因表达调控网络拟合工具)

This R# package module exposes the SGrid pipeline as a set of R functions:

  • sfit_options: create the fitting configuration object(FittingOptions);
  • sfit: infer the S-system gene regulatory network from a gene expression matrix(rows are genes and the columns are the time points), the optional prior knowledge network(PriorNetwork) is used as a soft constraint of the network structure;
  • network_edges, sgrid_parameters, sgrid_coefficients and sgrid_r2: query the fitted model, these functions return data.frame objects;
  • sgrid_simulate: integrate the fitted S-system model and return the trajectory as a data.frame;
  • sgrid_context: map a pseudobulk context(the raw counts) onto the model state space, so that it can be used as the ODE initial state;
  • perturb: run the in silico knockdown/knockout/overexpression experiment, optionally under a given sample context;
  • perturb_export: save the perturbation screening result as csv files;
  • sgrid_prior: read the prior knowledge regulatory network from a csv table(or a data.frame);
  • sgrid_save: export all of the model tables and the .plas model script;

and the binary serialization support of the fitted model: writeBin(model, con = file("network.zip")) and readBin(file("network.zip"), what = "ssgrid_network").
