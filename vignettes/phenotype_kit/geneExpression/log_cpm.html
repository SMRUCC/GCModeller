log_cpm {geneExpression} R Documentation

normalize data by sample column

Description

Usage

log_cpm(mat,
    scale = 1000000,
    prior = 1,
    base = 2);

Arguments

matrix

a gene expression matrix

scale

the total sum scale of each sample column after the normalization, by default is 10000. [as double]

mat

A raw hits count expression matrix object. [as Matrix]

scale

The CPM scale factor, default is 1e6. [as double]

prior

The pseudo count that added to the CPM value before the log transform, default is 1. [as double]

base

The logarithm base, default is 2. [as double]

Details

apply for the metabolomics data usually

Authors

phenotype_kit

Value

a new expression matrix object which is normalized by the total sum value of each sample column: each expression value in a sample column is divided by the sum of the sample column and then multiplied by the given scale value.

clr value class

  • Matrix

Examples

 ```r
 let logcpm = geneExpression::log_cpm(total);
 let scores = GSVA::gsva(logcpm, background, kcdf = "Gaussian");
 ```
