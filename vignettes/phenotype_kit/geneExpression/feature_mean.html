feature_mean {geneExpression} R Documentation

Calculate the mean value of one feature row over the given samples.

Description

Usage

feature_mean(expr, featureId,
    samples = NULL);

Arguments

expr

A gene expression matrix object(the feature could be a gene or a pathway id). [as Matrix]

featureId

The row id of the target feature. [as string]

samples

A character vector of the sample id for make the column subset of the mean calculation, or nothing for using all of the samples in the matrix.

Details

Authors

phenotype_kit

Value

The mean value of the given feature over the selected samples, or NaN when the feature id is not found in the given matrix.

clr value class

  • double

Examples

 ```r
 let scores = GSVA::gsva(expr, background);
 let ykb = geneExpression::project(scores, c("YKB_WT_WT_R1", "YKB_WT_WT_R2", "YKB_WT_WT_R3"));
 let mean = geneExpression::feature_mean(ykb, "map00791");
 ```
