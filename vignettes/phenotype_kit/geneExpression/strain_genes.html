strain_genes {geneExpression} R Documentation

Get the gene id list of one strain from the genome gene table.

Description

Usage

strain_genes(genomes, strain);

Arguments

genomes

The genome gene table: a dataframe with the strain/gene_id columns, or a tuple list in the format of list(strain_id = c(gene_id, ...)).

strain

The target strain genome id. [as string]

env

The R# runtime environment. [as Environment]

Details

The per-strain matrix that generated by decompose_community keeps all of the gene rows of the union matrix for the row alignment, so this api is usually used with the filter api for extract the genes of one strain before the downstream analysis(example as the GSVA pathway scoring):

 let genes = geneExpression::strain_genes(genomes, "Comamonas sp. Y1");
 let y1 = geneExpression::filter(decomposed$"Comamonas sp. Y1", geneId = genes);

Authors

phenotype_kit

Value

A character vector of the gene id that belongs to the given strain, or an empty vector when the strain is not found in the genome table.
