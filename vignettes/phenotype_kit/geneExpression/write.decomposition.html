write.decomposition {geneExpression} R Documentation

Write the per-strain expression matrices of the community decomposition result to CSV files.

Description

Usage

write.decomposition(result, dir);

Arguments

result

The decomposition result that generated by the decompose_community api. [as list]

dir

The output directory, it will be created automatically when it is not exists. [as string]

env

The R# runtime environment. [as Environment]

Details

Authors

phenotype_kit

Value

A character vector of the file path of the exported matrix files. besides the per-strain matrix files, an abundance.csv and a summary.csv table will also be generated in the same directory.

clr value class

  • string

Examples

 ```r
 let files = geneExpression::write.decomposition(result, "/path/to/decomposed");
 ```
