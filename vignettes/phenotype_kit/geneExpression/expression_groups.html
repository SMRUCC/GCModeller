expression_groups {geneExpression} R Documentation

从表达矩阵之中按照表达值的分布特征拆分出每一个品种的基因组基因集合

Description

Usage

expression_groups(x, sampleinfo,
    group = NULL,
    raw.count = NULL,
    presence.quantile = 0.5,
    kMAD = 3,
    logBase = 2,
    minAbsentFraction = 0.01,
    minGap = 1.5,
    absFloor = 0,
    verbose = TRUE);

Arguments

x

基因在行，样本在列的表达矩阵. [as Matrix]

sampleinfo

样本的元数据信息

group

用于进行样本分组的元数据键名，例如"line". [as string]

raw.count

输入的数据模式：TRUE表示原始count矩阵，FALSE表示已经归一化之后的矩阵， 默认为空值，即自动检测。

presence.quantile

品种内部的生物学重复的汇总分位数，默认取中位数；0为最严格(所有的重复都要检出)， 1为最宽松(只要有一个重复检出即可)。. [as double]

kMAD

判定阈值相对于低表达本底的MAD的倍数. [as double]

logBase

表达值分布变换所使用的对数底数. [as double]

minAbsentFraction

双峰检验之中的最小缺失组分占比. [as double]

minGap

双峰检验之中的最小峰间分离度. [as double]

absFloor

判定为存在所要求的原始表达量下限. [as double]

verbose

是否输出阈值诊断信息？. [as boolean]

env

[as Environment]

Details

Authors

phenotype_kit

a key-value tuple list of key name is the group or SampleGroup.sample_info and the value is the geneset of the corresponding group.
