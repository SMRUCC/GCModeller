read_prior {ARACNE} R Documentation

Load the curated ``TF -> target`` prior network from a csv table.

Description

Usage

read_prior(file,
    min.confidence = 0.45);

Arguments

file

the file path of the curated prior table, the header must contain the TF and the TargetGene columns; the optional Confidence column (High/ Medium/Low or a numeric value) and the optional RegulationType column (Activator/Inhibitor) are recognized as well. [as string]

min.confidence

the eligibility threshold of the prior confidence, default 0.45. [as double]

env

the R# runtime environment object. [as Environment]

Details

Authors

TRNtoolkit

Value

a RegulatoryEdge vector that can be passed to the prior argument of aracne

clr value class

  • RegulatoryEdge

Examples

 let prior = ARACNE::read_prior("G:/vcc2026/data/TF_target_prior_curated.csv", min_confidence = 0.9);
