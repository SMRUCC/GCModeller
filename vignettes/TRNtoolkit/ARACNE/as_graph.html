as_graph {ARACNE} R Documentation

Convert the inferred network into a graph model, so that it can be exported as a

Description

network file or be visualized by the igraph package.

Usage

as_graph(net);

Arguments

net

the network that is created via the aracne api. [as AracneNetwork]

Details

Authors

TRNtoolkit

Value

a NetworkGraph object: the nodes are the genes of the network, the edges carry the interaction_type (directed/mutual/undirected), the prior flag and the regulation type (activator/inhibitor) metadata.

clr value class
