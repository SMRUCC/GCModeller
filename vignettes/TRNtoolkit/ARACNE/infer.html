infer {ARACNE} R Documentation

Run the inference with a pre-built [AracneOptions](cref:T:SMRUCC.genomics.Model.Network.Regulons.ARACNE.AracneOptions) object.

Description

Usage

infer(x,
    opts = NULL);

Arguments

x

the gene expression matrix, rows are the genes and columns are the samples. [as Matrix]

opts

the options object that is created via the aracne_options api. [as AracneOptions]

Details

Authors

TRNtoolkit

Value

the fitted ARACNETools.aracneNetwork() object

clr value class

  • AracneNetwork

Examples

 let opts = ARACNE::aracne_options(estimator = "adaptive", max_neighbors = 200);
 let net = ARACNE::infer(hsa, opts);
