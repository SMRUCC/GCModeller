read_tf {ARACNE} R Documentation

Load the transcription factor gene symbols from a TF annotation table

Description

(for example the Homo_sapiens_TF.txt of the AnimalTFDB style).

Usage

read_tf(file,
    column = "Symbol");

Arguments

file

the file path of the TF annotation table: a tab/csv separated table whose header contains the column name, or a plain text file with one gene symbol per line. The empty/NA symbols are skipped and the result is unique in case insensitive. [as string]

column

the column name of the gene symbol, default Symbol. [as string]

env

the R# runtime environment object. [as Environment]

Details

Authors

TRNtoolkit

Value

a character vector of the TF symbols

clr value class

  • string

Examples

 let TF = ARACNE::read_tf("G:/vcc2026/data/Homo_sapiens_TF.txt");
