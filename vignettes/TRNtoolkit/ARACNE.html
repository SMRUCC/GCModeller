ARACNE (Algorithm for the Reconstruction of Accurate Cellular Networks) gene regulatory network inference.

The pipeline is: mi -> threshold -> DPI -> direction, and the transcription factor (TF) prior knowledge is used in four places:

  • the computation space is reduced from N x N to TF x N;
  • the TF -> target direction is assigned from the TF list;
  • the curated TF -> target evidence relaxes the MI threshold and protects the supported edges from the top-K pruning;
  • the curated evidence also protects the supported edges from the DPI filtering, and the protection strength is graded by the prior confidence.

The api groups:

  • read_tf / read_prior: load the prior knowledge (the TF annotation table and the curated TF -> target table) directly from the data files;
  • aracne: run the whole inference from an expression matrix;
  • aracne_options / infer: build the options object, then run the inference in two steps (useful when the same options are reused for several matrices);
  • edges / regulons / summary / threshold / dpi_stats / mi_matrix / as_graph / write_edges: inspect and export the network.

.NET clr type export
aracne.options: AracneOptions

ARACNE 网络推断的参数配置。

所有的参数都带有合理的默认值，无参构造即可跑通完整的流程：

 MI(高斯 copula) -> 置换阈值(tau) -> DPI 去间接边 -> TF 定向
aracne_network: AracneNetwork

ARACNE(Algorithm for the Reconstruction of Accurate Cellular Networks) 基因表达调控网络的推断。

整体的执行流程与 readme 之中的伪代码一一对应：

 1. 预处理      : log2 变换 / 标准化 / 秩转换 / 零表达与零方差基因过滤
 2. 互信息矩阵  : 高斯 copula(默认) / 自适应分区 / 等频分箱 / 核密度
 3. 显著性阈值  : 置换零分布的分位数(默认 95%) 或者固定阈值
 4. DPI 过滤    : 剔除三元组之中明显最弱的间接边
 5. 方向赋予    : TF 指向靶基因 / TF 与 TF 的双向关系 / 非 TF 的无向候选边

提供转录因子列表的时候，计算空间会由 N x N 缩减为 T x N (只计算 TF-TF 与 TF-Target 的互信息)，这正是 readme 第四章所推荐的 “结合 TF 先验知识”的工程化流程，可以把计算量降低几个数量级。


.NET clr function exports
aracne_options

Create an AracneOptions object from the scalar arguments.
aracne

Infer the ARACNE gene regulatory network from the expression matrix.
infer

Run the inference with a pre-built AracneOptions object.
edges

Get the regulation edges of the inferred network as a data frame.
regulons

Get the regulons (the target gene count of each regulator) of the network.
gene_names

Get the gene ids of the network, in the row order of the internal expression vectors.
tf_ids

Get the transcription factors that are matched by the network (the regulators).
mi_matrix

Get the mutual information matrix of the inferred network.
coef

Get the mutual information matrix of the inferred network (the alias of mi_matrix).
summary

Get the inference statistics of the network.
threshold

Get the significance threshold (tau) information of the network.
dpi_stats

Get the DPI (data processing inequality) filtering statistics of the network.
as_graph

Convert the inferred network into a graph model, so that it can be exported as a network file or be visualized by the igraph package.
write_edges

Export the regulation edges of the network into a csv file.
read_tf

Load the transcription factor gene symbols from a TF annotation table (for example the Homo_sapiens_TF.txt of the AnimalTFDB style).
read_prior

Load the curated TF -> target prior network from a csv table.
