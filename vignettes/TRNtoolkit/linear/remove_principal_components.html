remove_principal_components {linear} R Documentation

去掉表达矩阵的前若干个主成分(比"减去跨基因均值"更强的去全局因子)。

Description

<br /> 做法：在基因抽样的子矩阵上用块幂迭代求出前 components 个<br /> 右奇异向量(样本空间的全局方向)，然后把每个基因的表达向量投影到这些方向上<br /> 并减掉。等于把"细胞组成 / 测序质量 / 全局调控程序"这类共同因子从数据里移除。<br /> <br /> 与只减跨基因均值相比，这一步能真正削弱残留的全局共表达，<br /> 从而让网络里出现更多负相关(抑制型)的边。

Usage

remove_principal_components(x,
    components = 3,
    maxGenes = 2000);

Arguments

x

表达矩阵(行 = 基因、列 = 样本). [as Matrix]

components

要移除的主成分个数，默认 3；小于等于 0 时原样返回. [as integer]

maxGenes

估计主成分时使用的基因抽样上限，默认 2000. [as integer]
