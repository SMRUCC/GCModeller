set_baseline {linear} R Documentation

Set the wildtype baseline (the cell context) of the perturbation engine.

Description

Usage

set_baseline(model, genes, values);

Arguments

model

the perturbation engine that is created via elastic_model. [as ElasticNet]

genes

the gene ids of the given expression profile, the matching against the model is case insensitive and the genes that are not modelled are ignored.

values

the baseline expression values, they must be in the model space (i.e. the same transformation that was used to fit the network, for example log2(CPM + 1)).

env

the R# runtime environment object. [as Environment]

Details

Authors

TRNtoolkit

Value

the number of the genes that have been matched and written
