top_variable_genes {linear} R Documentation

按 MAD(中位数绝对偏差)降序挑选变异最大的若干个基因。

Description

<br /> 用于扩充候选调控因子池：TF ∪ 扰动靶基因 之外，再补上一批"在样本之间<br /> 波动最大"的基因，让每个目标基因的模型有机会用上真正与它共变的调控因子，<br /> 而不是被迫只能用 TF 和 300 个扰动靶基因去解释。<br /> <br /> 使用 MAD 而不是标准差，是因为 MAD 对离群样本(双细胞、线粒体爆表)不敏感，<br /> 不会像 SD 那样把少数极端样本的基因顶到榜首。

Usage

top_variable_genes(x,
    topN = 3000,
    robust = TRUE,
    excludeGlobal = TRUE);

Arguments

x

对数空间的表达矩阵(行 = 基因、列 = 样本). [as Matrix]

topN

返回的基因数量. [as integer]

robust

True = MAD；False = 标准差(更快，但对离群值敏感). [as boolean]

excludeGlobal

是否在排名时排除线粒体/核糖体基因(MT-、MTRNR、RPL、RPS)。 这些基因几乎总是 MAD 最高的，但它们代表的是细胞状态而不是特异调控； 把它们放进候选池会让所有基因的模型都挂到同一个全局程序上。. [as boolean]
