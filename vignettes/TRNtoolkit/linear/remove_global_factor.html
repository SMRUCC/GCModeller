remove_global_factor {linear} R Documentation

去掉样本级的全局表达程序(每个样本减去跨基因均值)。

Description

<br /> 对样本 s: x'(g, s) = x(g, s) - mean_g(x(g, s))。<br /> <br /> 横截面共表达数据里，所有基因都被同一个"全局程序"绑定(细胞状态、线粒体含量、<br /> 测序质量等)，导致任意两个基因的相关系数都被抬高、且几乎全为正。把这个样本级<br /> 常数移除之后，剩下的相关更接近"特异性共表达"，负相关才会出现：<br /> 这一步直接改善敲降之后"全部基因一起下调、极少上调"的现象。

Usage

remove_global_factor(x);

Arguments

x

表达矩阵(行 = 基因、列 = 样本)，通常已经过 log2(CPM+1) 变换. [as Matrix]
