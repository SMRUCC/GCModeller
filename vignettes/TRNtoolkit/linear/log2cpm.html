log2cpm {linear} R Documentation

把原始 counts 矩阵变换成 ``log2(CPM + 1)``。

Description

<br /> 逐样本按总计数归一化到 scale（默认 1e6，即 CPM），<br /> 再取 log2(x + pseudo)。这个变换消除了样本之间测序深度的差异：<br /> 未取对数的 counts 矩阵上，任意两个基因的相关系数都会被共同的深度因子<br /> 拉到 0.6 以上且彼此接近，弹性网络的 L1 路径因此不存在稀疏的中间解，<br /> 拟合出来的模型会退化成 r2 ~ 0 的常数模型。

Usage

log2cpm(x,
    pseudo = 1,
    scale = 1000000);

Arguments

x

原始表达矩阵（行 = 基因、列 = 样本）. [as Matrix]

pseudo

伪计数偏移，默认 1，即 log2(CPM + 1). [as double]

scale

每个样本的归一化目标总量，默认 1e6（CPM）. [as double]
