wildtype_means {linear} R Documentation

Get the currently effective wildtype (baseline) expression vector of the model.

Description

Usage

wildtype_means(model);

Arguments

model

the perturbation engine that is created via elastic_model. [as ElasticNet]

Details

Authors

TRNtoolkit

Value

a numeric vector, one value per gene, in the same order as gene_names. Before set_baseline is called this is the sample mean of the training matrix.

clr value class

  • double
