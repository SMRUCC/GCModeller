intervene {linear} R Documentation

Run one in silico perturbation experiment and return the raw result object.

Description

Usage

intervene(model, gene,
    mode = "knockout",
    value = 0);

Arguments

model

the perturbation engine that is created via elastic_model. [as ElasticNet]

gene

the target gene id. [as string]

mode

knockout, knockdown, overexpress or custom. [as string]

value

the absolute expression value in the model space, only used by the custom mode. [as double]

env

the R# runtime environment object. [as Environment]

Details

Authors

TRNtoolkit

Value

an InterventionResult object; use as.list to access the fields (the $ indexing is not supported on this object).

clr value class
