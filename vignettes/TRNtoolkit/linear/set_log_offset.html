set_log_offset {linear} R Documentation

设置模型空间的整体对数偏移量(去全局因子之后的 context 需要)。

Description

<br /> 拟合矩阵做过"逐样本减去跨基因均值"之后，模型空间是<br /> x' = log2(CPM + 1) - offset；扰动幅度必须先在 x' + offset 上计算，<br /> 再换算回来，否则负基线会被压成 0，敲降变成"敲到底"甚至反号。

Usage

set_log_offset(model, offset);

Arguments

model

由 elastic_model 创建的扰动引擎. [as ElasticNet]

offset

偏移量，即该 context 的跨基因均值减去中位数校准量. [as double]
