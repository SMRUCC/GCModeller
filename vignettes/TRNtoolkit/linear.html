The linear (elastic net) gene regulatory network builder and the in silico perturbation toolkit that runs on top of the fitted linear models.

This package provides two groups of the R# api:

  • elastic_net / coef: fit a regulator -> target linear regulatory network from a gene expression matrix, and export the coefficient matrix;
  • elastic_model / set_baseline / intervene / profiles_matrix: build an in silico perturbation engine from the fitted network, condition it on a given cell context, and run the RNAi style knockdown experiments.

The perturbation engine implements the InsilicoPerturbationExperiment interface, so the knockouts / overexpress / knockdown api of the bnlearn package can be used on the object that is created by elastic_model directly.

.NET clr type export
elastic_net.options: ElasticNetPerturbationOptions

基于弹性网络线性调控网络的虚拟扰动参数。
linear_grn: GeneRegulatoryNetwork

基于线性拟合的基因表达调控网络推断

对于表达矩阵之中的每一个基因 g，都会建立如下的线性模型：

 expr(g) = const + beta_1 * expr(r1) + beta_2 * expr(r2) + ...

其中 r1, r2, ... 为候选调控因子(默认从与 g 相关性最高的若干个基因之中选出， 并且总是排除 g 自身)。把所有基因的模型汇总之后，就得到了一个 调控因子 -> 目标基因 的有向加权网络：边的权重即为回归系数。
