cai_bias_dataset {sigma_difference} R Documentation

Compile the codon usage table of every species gene collection.

Description

The reference set of each species is its own gene collection<br /> (for a real high-expression reference set use<br /> ToolsAPI.BuildCAIReference() with the ribosomal protein genes).

Usage

cai_bias_dataset(genes);

Arguments

genes

the directory of the *.fasta / *.fsa species gene collections. [as string]

Details

Output layout:

SpeciesID, CAI, CUBIAS_LIST src1 ... src2 ...

Authors

comparative_toolkit

Value

the compiled codon usage csv document

clr value class
