sigma_diff.query {sigma_difference} R Documentation

Compare one query genome against a directory of subject genomes: calculate

Description

the sliding window delta* profile of the query against every subject and<br /> export each profile as a csv file, then compile all of the profiles into one<br /> merged matrix csv document.

Usage

sigma_diff.query(query, sbjDIR, EXPORT,
    windowsSize = 1000);

Arguments

query

the query genome fasta file path. [as string]

sbjDIR

the directory of the subject genome fasta files. [as string]

EXPORT

the csv output directory. [as string]

windowsSize

the sliding window size in bp, default 1kb. [as integer]
