genome.gc_skew {sigma_difference} R Documentation

The ``(C - G) / (C + G)`` sliding window profile of the genome strand

Description

composition asymmetry: the leading strand favors purines (G > C), so the<br /> curve flips its sign at the replication origin oriC.

Usage

genome.gc_skew(genome,
    windowSize = 10000,
    stepSize = 1000);

Arguments

genome

the genome nucleotide sequence. [as FastaSeq]

windowSize

the sliding window size in bp, default 10kb. [as integer]

stepSize

the sampling step in bp, default 1kb. [as integer]

Details

the skew profile rows ordered by the site position
