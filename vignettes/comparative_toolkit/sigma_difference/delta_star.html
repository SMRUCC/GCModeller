delta_star {sigma_difference} R Documentation

The ``delta*`` measure of difference between two sequences f and g (from

Description

different organisms or from different regions of the same genome): the<br /> average absolute dinucleotide relative abundance difference<br /><br /><br /> delta*(f, g) = (1/16) SUM |rho*XY(f) - rho*XY(g)|<br /> <br /><br /> where the sum extends over all 16 dinucleotides.

Usage

delta_star(f, g);

Arguments

f

the query sequence. [as FastaSeq]

g

the subject sequence. [as FastaSeq]

Details

Authors

comparative_toolkit

Value

the delta* value with the similarity level description attached as its unit
