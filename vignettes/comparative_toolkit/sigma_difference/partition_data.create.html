partition_data.create {sigma_difference} R Documentation

Create the chromosome partitioning data from the two-way BLAST best hit

Description

data: for every partition tag, locate the corresponding ORFs on every<br /> subject genome and cut the partition nucleotide segments.

Usage

partition_data.create(besthit, partitions, allCDSInfo, faDIR);

Arguments

besthit

the two-way BLAST best hit data of the genome pairs. [as SpeciesBesthit]

partitions

the partition definitions of the query genome. [as iterates(ChromosomePartitioningEntry)]

allCDSInfo

the CDS gene table of all of the genomes. [as iterates(GeneTable)]

faDIR

the directory of the subject genome fasta files. [as string]

Details

Authors

comparative_toolkit

Value

the partition nucleotide segments of every subject genome
