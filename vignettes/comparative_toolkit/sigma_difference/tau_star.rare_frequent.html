tau_star.rare_frequent {sigma_difference} R Documentation

List the rare and the frequent tetranucleotides of the ``tau*`` profile

Description

against the given thresholds (the restriction avoidance candidates).

Usage

tau_star.rare_frequent(nt,
    rareBelow = 0.78,
    frequentAbove = 1.23);

Arguments

nt

the genome nucleotide sequence. [as FastaSeq]

rareBelow

words with tau* below this value are rare. [as double]

frequentAbove

words with tau* above this value are frequent. [as double]
