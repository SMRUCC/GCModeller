measure_homogeneity {sigma_difference} R Documentation

Measure the homogeneity property of the genome partition segments against

Description

the dnaA-gyrB ruler segment of the reference genomes in batch.

Usage

measure_homogeneity(PartitionData, RuleSource);

Arguments

PartitionData

the partition segments of all of the genomes. [as iterates(PartitioningData)]

RuleSource

The original GenBank download data directory which should contains the *.ptt file for parsing the ruler segment between the dnaA and gyrB genes and the *.fna file for parsing the genome nucleotide fasta sequence. [as string]
