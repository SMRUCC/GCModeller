word.rscan {sigma_difference} R Documentation

Run the r-scan significance test on the spatial distribution of one

Description

oligonucleotide word (Dembo-Karlin 1992): detect the clustering, the<br /> overdispersion or the even spacing patterns against the random (Poisson)<br /> spacing expectation.

Usage

word.rscan(genome, word,
    RMax = 5);

Arguments

genome

the genome nucleotide sequence. [as FastaSeq]

word

the oligonucleotide word under study. [as string]

RMax

the maximum r of the left-tail r-scan table; increase this value when the word copy number is large (e.g. the USS / HIP1 elements). [as integer]
