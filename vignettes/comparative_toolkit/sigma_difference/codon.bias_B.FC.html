codon.bias_B.FC {sigma_difference} R Documentation

The ``B(F|C)`` codon usage bias difference between two gene classes (the

Description

paper's formula [1]):<br /><br /><br /> B(F|C) = SUM_a p_a(F) SUM_{(x,y,z)->a} | f(x,y,z) - c(x,y,z) |<br /> <br /><br /> the per-codon absolute difference weighted by the amino acid frequency of<br /> the query class F. Note that this measurement is asymmetric: F is the<br /> query object and C is the reference ruler.

Usage

Arguments

f

the query codon usage profile (gene family F). [as CodonUsageProfile]

c

the reference codon usage profile (class C). [as CodonUsageProfile]
