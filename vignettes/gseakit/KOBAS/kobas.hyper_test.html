kobas.hyper_test {KOBAS} R Documentation

The hypergeometric test (upper tail) of a term.

Description

Usage

kobas.hyper_test(q, m, n, k);

Arguments

q

the observed number of the term members in the foreground list. [as integer]

m

the number of the term members in the background. [as integer]

n

the total number of the genes in the background. [as integer]

k

the size of the foreground gene list. [as integer]
