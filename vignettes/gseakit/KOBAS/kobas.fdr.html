kobas.fdr {KOBAS} R Documentation

Multiple testing correction of the p-values.

Description

Usage

kobas.fdr(pvalue,
    method = "BH");

Arguments

pvalue

the raw p-values. [as double]

method

the correction method: BH (Benjamini and Hochberg, default), BY (Benjamini and Yekutieli), QVALUE (Storey) or None. [as string]

Details

The q-value is estimated with a fixed lambda (0.5) of the Storey's pi0 estimator, the R qvalue package uses a smoothed lambda grid instead, so the result may differ slightly from the R package.

Authors

gseakit

Value

the adjusted p-values in the same order as the input.
