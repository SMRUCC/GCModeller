cast_enrichs {GSEA} R Documentation

Create the GCModeller enrichment analysis result objects from the raw data vectors.

Description

Usage

cast_enrichs(term, name, pvalue,
    geneIDs = NULL,
    desc = NULL,
    score = NULL,
    fdr = NULL,
    cluster = NULL,
    enriched = NULL);

Arguments

term

the term id vector. [as string]

name

the term name vector, its length should be equals to the term vector. [as string]

pvalue

the p-value vector of each term. [as double]

geneIDs

a named list of the member gene id vector of each term, the name of the list slot should be the term id. Default NULL means no member gene id. [as list]

desc

the description vector of each term. Default NULL. [as string]

score

the enrichment score vector of each term. Default NULL. [as double]

fdr

the adjusted p-value (FDR) vector of each term. Default NULL. [as double]

cluster

the cluster size vector of each term. Default NULL. [as integer]

enriched

the enriched gene id vector joined by ; of each term. Default NULL. [as string]

env

the R# runtime environment. [as Environment]

Details

Authors

gseakit

Value

an array of the EnrichmentResult objects.
