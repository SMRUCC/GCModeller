Assemble the multiple omics data layers into a MultiOmicsDataset object for the multi-omics GSVA (moGSVA) analysis.
mogsva_opts

Build a MultiOmicsGsvaOptions configuration object that controls the whole multi-omics GSVA (moGSVA) pipeline: per-omics enrichment scoring, cross-omics weighted fusion with a consistency reward, and a gene-to-pathway permutation test for significance assessment.

Run the multi-omics GSVA (moGSVA) analysis on the given multi-omics dataset.
