mo_layers {GSVA} R Documentation

Assemble the multiple omics data layers into a [MultiOmicsDataset](cref:T:SMRUCC.genomics.Analysis.HTS.GSVA.Omics.MultiOmicsDataset) object

Description

for the multi-omics GSVA (moGSVA) analysis.

Usage

mo_layers(layers,
    verbose = TRUE);

Arguments

layers

the omics layer collection, each element could be an OmicsLayer object or a tuple that could be cast into the omics layer model. Every layer should define its unique omics name and the expression matrix whose rows are the features of that omics.

verbose

prints the progress and the diagnostic message of the layer alignment? Default TRUE. [as boolean]

env

the R# runtime environment. [as Environment]

Details

The samples of all of the omics layers are aligned by the sample name: the intersection of the sample names is used as the final sample axis of the multi-omics dataset.

Authors

gseakit

Value

a MultiOmicsDataset object which contains the sample aligned omics layers, or an error message when the layer collection could not be assembled.

clr value class

  • MultiOmicsDataset
