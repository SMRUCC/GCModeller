read_gmx {background} R Documentation

Read the gene set matrix (``gmx``) file.

Description

Usage

read_gmx(file);

Arguments

file

the gmx file path. [as string]

Details

The gmx format is the transposed version of the gmt format: the first column of each row is the gene id and the rest columns are the member gene set ids.

Authors

gseakit

Value

the parsed Gmx gene set matrix object.
