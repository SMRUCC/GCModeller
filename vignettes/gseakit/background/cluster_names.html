cluster_names {background} R Documentation

Get the cluster name of each gene id from the given background model.

Description

Usage

cluster_names(background, idset);

Arguments

background

the GSEA background model object. [as Background]

idset

a character vector of the gene ids, the first cluster that contains the target gene will be used for query the cluster name.

Details

This function returns only the first matched cluster name when a gene is annotated in multiple clusters, use geneSet.intersects with get_clusterID=TRUE for getting all of the cluster ids of the gene.

Authors

gseakit

Value

a character vector of the cluster name of each input gene id, a NULL value will be returned for the gene id that is not annotated in any cluster.

clr value class

  • string

Examples

 let kb = read.background("hsa.xml");
 print(cluster_names(kb, c("7157", "1956")));
