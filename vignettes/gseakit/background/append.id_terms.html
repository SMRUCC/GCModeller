append.id_terms {background} R Documentation

Append id terms to a given gsea background

Description

Usage

append.id_terms(background, term.name, terms);

Arguments

background

the GSEA background model object, this model will be modified in place. [as Background]

term.name

the term name that will be written into the name field of the :class:BackgroundGene.term_id. [as string]

terms

a named list of the term id vector, the name of each slot is the gene id and the value is the term id vector of that gene. [as list]

env

the R# runtime environment. [as Environment]

Details

Authors

gseakit

Value

the given background model with the new term id information appended.
