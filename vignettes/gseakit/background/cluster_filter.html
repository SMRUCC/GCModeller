cluster_filter {background} R Documentation

Remove the clusters from the given background model by the cluster id.

Description

Usage

cluster_filter(background, id.removes);

Arguments

background

the GSEA background model object. [as Background]

id.removes

a character vector of the cluster ids that will be removed from the background model.

env

the R# runtime environment. [as Environment]

Details

Authors

gseakit

Value

a new Background model that does not contains the removed clusters, the size of the result model is re-evaluated from the remaining clusters.

clr value class

  • any kind
