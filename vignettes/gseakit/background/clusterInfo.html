clusterInfo {background} R Documentation

Get the cluster information data table of a specific cluster.

Description

Usage

clusterInfo(background, clusterId);

Arguments

background

the GSEA background model object. [as Background]

clusterId

the cluster id (or the pathway id) that will be query from the background model. [as string]

Details

Authors

gseakit

Value

a dataframe of the cluster member genes, the row names are the gene ids and the columns are clusterId, clusterName, name, locus_tag, description and terms. An empty dataframe will be returned when the cluster id is not found.

clr value class

  • dataframe
