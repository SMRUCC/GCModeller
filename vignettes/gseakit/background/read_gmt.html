read_gmt {background} R Documentation

Read the gene set matrix (``gmt``) file.

Description

Usage

read_gmt(file);

Arguments

file

the gmt file path. [as string]

Details

Each line of the gmt file is a gene set in the format of set_id \t description \t gene1 \t gene2 ....

Authors

gseakit

Value

the parsed Gmt gene set matrix object.
