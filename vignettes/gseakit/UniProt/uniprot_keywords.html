uniprot_keywords {UniProt} R Documentation

Create a gsea background model for uniprot keywords based

Description

on the given uniprot database assembly data

Usage

uniprot_keywords(uniprot,
    db.xref = NULL);

Arguments

uniprot

a collection of the UniProt protein entry data, or a file path of the UniProt database xml file.

db.xref

the database cross reference name that will be used as the gene id of the background members, for example GeneID. Default NULL means using the UniProt accession id. [as string]

env

the R# runtime environment. [as Environment]

Details

Authors

gseakit

Value

a Background model whose clusters are the UniProt keyword terms, or an error message when the input data could not be cast into the UniProt entry collection.

clr value class

  • Background
