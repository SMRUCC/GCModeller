category_labels {profiles} R Documentation

Get the category labels for a given id set.

Description

Usage

category_labels(category, idSet,
    level = 1);

Arguments

category

the KEGG category class model that is created by the kegg_category function. [as ClassProfiles]

idSet

a character vector of the target id set. [as string]

level

the category level that will be returns: 1 (default) for the level 1 class, 2 for the level 2 category. [as integer]

env

the R# runtime environment. [as Environment]

Details

Authors

gseakit

Value

a character vector of the category label of each input id, a NULL value will be returned for the id that is not found in the category model.

clr value class

  • any kind
