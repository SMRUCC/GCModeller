no_catagory_profile {profiles} R Documentation

Create a catalog profiles object that does not contains the category information,

Description

that means all of the enrichment terms are placed into a single catalog.

Usage

no_catagory_profile(enrichments, name,
    top = 30);

Arguments

enrichments

the enrichment analysis result set, both of the EnrichmentTerm and the EnrichmentResult array are accepted. [as Array]

name

the catalog name that will be used for the result object. [as string]

top

the number of the most significant terms that will be kept. Default 30. [as integer]

env

the R# runtime environment. [as Environment]

Details

Authors

gseakit

Value

a CatalogProfiles object that contains only one catalog which is named by the name parameter, or an error message when the input data type is not supported.

clr value class

  • CatalogProfiles
