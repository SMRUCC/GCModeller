sort_profiles {profiles} R Documentation

Keep only the top n terms of each catalog of the given catalog profiles.

Description

Usage

sort_profiles(profile,
    top = 10);

Arguments

profile

the catalog profiles object, for example the result of the KEGG.enrichment.profile function. [as CatalogProfiles]

top

the number of the terms that will be kept in each catalog. Default 10. [as integer]

Details

Authors

gseakit

Value

a new CatalogProfiles object that only contains the top n terms of each catalog.

clr value class

  • CatalogProfiles
