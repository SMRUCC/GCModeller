dag_enrichment_profile {profiles} R Documentation

Create the catalog profiles data of the GO enrichment result by the GO DAG term

Description

hierarchy, the terms are grouped by the child node of the given root term.

Usage

dag_enrichment_profile(enrichments, obo, root,
    top = 10,
    pvalue.cut = 1,
    sort = TRUE);

Arguments

enrichments

the kobas EnrichmentTerm or gcmodeller EnrichmentResult.

obo

the GO obo database that is used for creating the DAG graph. [as GO_OBO]

root

the root term id. [as string]

top

display the top n enriched GO terms of each catalog. [as integer]

pvalue.cut

the p-value cutoff of the enrichment terms. Default 1 means no filtering. [as double]

sort

sorts the terms of each catalog by the -log10(p) score? Default TRUE. [as boolean]

env

the R# runtime environment. [as Environment]

Details

Authors

gseakit

Value

a CatalogProfiles object, the name of each catalog is the child term of the given root and the value is the enriched GO terms of that branch.

clr value class

  • any kind
