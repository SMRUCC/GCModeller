# Rockhopper：细菌 RNA-seq 综合分析工具
Rockhopper 是由 Wellesley 学院 Brian Tjaden 团队开发的一款专门针对**细菌（原核生物）RNA-seq 数据**的综合分析软件，其核心特色在于整合了从读段比对、转录组组装、表达定量到操纵子预测的一整套流程，尤其擅长识别原核生物特有的转录边界（如 5'/3' UTR、反义转录本、小 RNA）和多基因操纵子结构。它由 Java 编写，有图形界面和命令行两种运行方式，输入支持 FASTQ/QSEQ/FASTA/SAM/BAM 多种格式。
---
## 一、功能与算法概览
| 分析模块 | 核心算法 | 输入/输出 |
|---|---|---|
| 读段比对 | Burrows-Wheeler 变换（BWT/FM-index）+ 种子延伸 + 质量感知动态规划 | FASTQ/FASTA → 比对结果 |
| 转录组组装（参考依赖） | 贝叶斯统计推断转录起始/终止位点 | 比对数据 → 转录组图谱 |
| 转录组组装（*de novo*） | de Bruijn 图遍历 + 二次比对精修 | 无需参考基因组 |
| 表达归一化 | 上四分分位归一化 | 原始计数 → 归一化计数 |
| 表达定量 | 改进的 RPKM（以上四分分位数替代总读段数） | → 表达水平 |
| 差异表达检验 | 负二项分布模型 + 局部回归（lowess）方差估计 + BH 校正 | 多条件 → *q*-值 |
| 操纵子预测 | 基于基因间距与表达相似度的贝叶斯推断 | → 操纵子结构 |
| 结果可视化 | 集成 IGV 基因组浏览器 | → 图形化展示 |
---
## 二、核心算法原理详解
### 1. 读段比对：BWT + 种子延伸
Rockhopper 首先对参考基因组（或多条 replicon，如染色体/质粒）构建基于**全文后缀数组的 Burrows-Wheeler 变换索引**（FM-index），该结构将基因组压缩存储并支持快速查询。比对策略分两步：
- **第一步：精确比对。** 尝试将读段精确匹配到索引中；
- **第二步：非精确比对。** 若精确比对失败，则采用"种子-延伸"策略：先在读段中找到能与基因组精确匹配的种子区域（seed，最小长度可参数化，默认为读长的某个百分比），再利用**优化的动态规划**将种子向两侧延伸，允许错配和缺口。打分函数采用**基于碱基错误概率的质量感知打分**，即测序质量值低的碱基产生错配时惩罚较轻，从而提高灵敏度。
该设计借鉴了 Bowtie2 等现代比对器的思想，但 Rockhopper 在其上做了专门针对细菌高密度基因组的调优。
### 2. 表达归一化与定量：上四分分位策略
不同样本间的测序深度差异必须校正。Rockhopper 采用**上四分分位归一化**：将每个样本中所有基因表达水平排序，取上四分位数作为归一化因子。相比总读段数归一化，该方法对高表达基因（如细菌中含量极高的 rRNA）不敏感，更稳健。
定量方面，Rockhopper 使用**改良的 RPKM**：
$$\text{表达量} = \frac{\text{基因读段数}}{\text{基因长度} \times \text{上四分分位数表达水平}}$$
即以样本的上四分分位数替代传统 RPKM 中的"总读段数"，从而减弱极端高表达基因对整体定量的影响。
### 3. 差异表达检验：负二项分布 + lowess 方差估计
这是 Rockhopper 的统计核心，流程如下：
1. **方差估计。** RNA-seq 数据具有"表达量越高方差越大"的均值-方差依赖关系。Rockhopper 使用**局部回归**对每个基因根据其表达量估计平滑方差，而非简单使用泊松分布假设（泊松假设方差 = 均值，常低估生物学重复间的方差）。
2. **统计检验。** 对每个转录本，在**负二项分布**模型下检验零假设（不同条件下表达量无差异），计算 *p*-值。
3. **多重检验校正。** 使用 **Benjamini-Hochberg (BH) 程序**将 *p*-值转换为 *q*-值，控制错误发现率（FDR）。默认显著性阈值为 *q* < 0.01。
与 DESeq/edgeR 等主流差异分析工具相比，Rockhopper 的方差估计策略更侧重于在小样本量下利用局部回归拟合整体方差趋势，而 DESeq 使用经验贝叶斯压缩、edgeR 使用对数线性模型。
### 4. 转录本组装与边界识别：贝叶斯推断
原核转录本没有内含子，但存在复杂的 5'/3' UTR、反义转录本和小 RNA。Rockhopper 的处理方式：
- **依赖参考基因组时**，结合 GenBank 中的基因注释（起始/终止密码子、rRNA/tRNA 边界），对每个显著表达的基因，利用**贝叶斯方法**根据读段在基因组上的覆盖分布推断转录起始位点和终止位点，从而构建完整的"转录组图谱"。对于与另一基因在同一链上重叠的基因（即两侧无基因间区），Rockhopper 不会单独预测其边界，避免假阳性。
- **发现新转录本**。通过该过程可识别未被注释的反义 RNA 和基因间小 RNA。用户可通过"Minimum expression of UTRs and ncRNAs"参数控制灵敏度/特异度的平衡。
### 5. *de novo* 转录组组装：de Bruijn 图 + 二次精修（Rockhopper 2）
当无参考基因组可用时（Rockhopper 2 引入的功能），组装流程为：
1. **构建 de Bruijn 图。** 将所有读段打断为 *k*-mers，构建 de Bruijn 图（节点为 *k*-1 mers，边为 *k*-mers）。仅当节点对应 *k*-mers 数达到"Min count to seed a transcript"阈值时才作为候选起点，延伸时也要求后续节点达到"Min count to extend a transcript"阈值，从而过滤低频噪声。
2. **图遍历产生候选转录本。** 沿图路径遍历，输出候选转录本序列。
3. **候选精修。** 将候选转录本存储为一个 **Burrows-Wheeler 索引**，再将原始读段比对回候选转录本，通过比对结果淘汰覆盖率不足的候选（通过"Min reads mapping to a transcript"参数控制），得到最终高质量转录本集合。
该设计比传统"仅 de Bruijn 图"组装（如 Velvet/Trinity）多了一步"读段支持度检验"，减少了嵌合转录本和孤立短片段，在 2015 年 *Genome Biology* 论文中显示其优于其他 *de novo* 组装器。
### 6. 操纵子预测：基因距离 + 表达相似度
原核生物中相邻且同链的基因可能被共同转录为一个多顺反子 mRNA。Rockhopper 综合两个特征来估计相邻基因共转录的概率：
- **基因间距离。** 两个基因之间的核苷酸数；
- **表达谱相似性。** 两个基因在所有样本中的表达模式是否一致（若属于同一操纵子，各基因表达应高度同步）。
通过贝叶斯框架将两类信息整合，输出每个相邻基因对属于同一操纵子的概率，从而构建操纵子图谱。这在真核 RNA-seq 工具中没有对应功能。

## 三、典型使用流程
**参考依赖分析**（有基因组时）：
```
1. 选择 replicon（可自动从 GenBank 下载参考基因组与注释）
2. 添加每个实验条件的读段文件（支持生物学重复、双端读段）
3. 运行 → 得到 *_transcripts.txt（含表达量与 q 值）、*_operons.txt（操纵子）
4. 通过 IGV 可视化比对、UTR、新转录本、差异基因
```
**De novo 分析**（无参考基因组时）：
```
1. 点击 DE NOVO 模式
2. 添加读段文件
3. 运行 → 得到 transcripts.txt（含序列、长度、表达量、q 值）
```
---
## 四、输出文件
| 文件 | 内容 |
|---|---|
| `summary.txt` | 比对率、预测的 UTR 数、新转录本数、差异基因数、操纵子数等汇总 |
| `*_transcripts.txt` | 每个基因/新转录本的转录起始/终止位点、表达水平、*q*-值；verbose 模式下还输出原始计数、RPKM、*p*-值 |
| `*_operons.txt` | 预测的多基因操纵子列表 |
| SAM 文件（可选） | 比对结果，供下游工具使用 |
---
## 五、适用范围与局限
**优势：**
- 专为细菌设计，能处理原核特有的 UTR、反义转录本、操纵子问题；
- 同时支持参考依赖与 *de novo* 两种组装模式；
- 自带归一化、差异检验、操纵子预测全流程，无需拼接多个工具；
- 图形界面友好，命令行也支持批处理。
**局限：**
- **不适用于真核生物**：无剪接位点识别、无 isoform 分析、无内含子处理，对有内含子的物种应改用 HISAT2/StringTie/DESeq2 等工具；
- 差异检验在小样本下可能欠稳健，建议至少 2-3 个生物学重复；
- *de novo* 模式依赖足够深度的测序覆盖；
- 差异分析模型与 DESeq2/edgeR 的成熟度相比略有差距，对复杂设计（如多因素、连续变量）支持有限。
**代表性引用：**
- McClure R, Balasubramanian D, Sun Y, et al. *Computational analysis of bacterial RNA-seq data.* **Nucleic Acids Research**, 41(14):e140, 2013.
- Tjaden B. *De novo assembly of bacterial transcriptomes from RNA-seq data.* **Genome Biology**, 16:1, 2015.
总的来说，如果你的研究对象是**细菌或古菌的转录组**，希望一站式完成从比对到操纵子预测的全流程，Rockhopper 依然是该领域最具针对性的工具之一；若研究对象为真核生物，则需选择专为剪接和 isoform 设计的分析管线。
