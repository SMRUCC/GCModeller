## 产品概述

在泛基因组分析 HTML 报告的【分析概述】章节新增一个基因组级别的三维散点图：以「基因存在/缺失均衡度（香农信息熵）」「特有基因占比」「核心基因占比」三个维度刻画每个基因组，用于快速识别「核心保守型」与「高度可塑型」基因组，并在图下给出该熵指标的生物学意义图注。

## 核心功能

- **香农信息熵（维度1）**：基于**完整的 PAV 矩阵**（全部基因家族，非 PCA 的 Top 5000 子集）逐基因组计算。设泛基因组共有 N 个基因家族，某基因组中存在 K 个，则 p = K/N，H = -(p·log p + (1-p)·log(1-p))。采用自然对数，并对 p=0 或 p=1 做边界保护（H=0）。
- **特有基因占比（维度2）**：该基因组「特有基因数 / 基因总数」的比值。
- **核心基因占比（维度3）**：沿用现有统计中的核心基因占比。
- **三维散点图**：在【分析概述】章节新增图表卡片，每个点代表一个基因组；支持鼠标旋转与缩放，悬浮提示展示基因组名、熵值 H、存在与缺失家族数、特有基因占比、核心基因占比、基因总数。
- **图注文本**：在图表下方以图注形式说明该熵指标的公式与生物学意义（基因组可塑性代理指标、极端基因组识别），并说明三轴含义。
- **容错与降级**：家族总数为 0、基因组数为 0、参与家族为 0 或计算异常时，页面显示统一「数据不可用」提示，不影响报告生成与其余图表。
- **既有功能不回归**：现有 10 个图表、3 个固定 800px 热图与全屏热图模态框、统计表搜索与直方图联动、PCA 三维图均保持正常。

## 技术栈选择

- 语言/运行时：VB.NET，`net10.0`（`PanGenome.vbproj`），无需新增任何项目引用或第三方依赖。
- JSON 序列化：复用既有 `Microsoft.VisualBasic.Serialization.JSON.JsonContract.GetJson`，配合 `EscapeJsonForHtml`（`<`→`\u003c`、`>`→`\u003e`、`&`→`\u0026`）。
- 前端：原生 HTML/CSS/JavaScript + ECharts 5.4.3 + **echarts-gl 2.0.9**（head 中均已就绪），不引入前端框架。
- 模板分发：`DefaultTemplate.resx` 通过 `ResXFileRef` 引用根目录 `Report.html`，无需改动 resx。

## 实现方案

### 总体策略

1. **新增具名 DTO**：在 `Report/PanGenomeReportData.vb` 中按现有约定（具名 Public 类、属性名 camelCase 且即前端 JSON 键名）新增 `GenomeEntropyPoint` 与 `GenomeEntropyDataset`。
2. **新增构建器**：在 `Report/PanGenomeReportGenerator.vb` 中新增 `BuildGenomeEntropyData(result, stats)`，复用已在 `GenerateReport` 中提取的局部变量 `genomeStats`（避免重复执行 `CountFamiliesPerGenome`），并填充新占位符 `{$GENOME_ENTROPY_DATA}`。
3. **熵计算的复杂度控制**：`PAVMatrix` 每一行都含全部基因组键（含 0），因此禁止「基因组 × 家族」双重循环。改为遍历 `result.PAVMatrix.Values`（每行即一个家族），仅对 `kvp.Value > 0` 的条目做一次「基因组名 → 下标」哈希查找并累加存在计数；只有真正存在的条目才产生哈希开销。
4. **边界保护与数值安全**：`N = 0`、`genomeNames.Length = 0`、`geneCount = 0`、`p = 0`、`p = 1` 全部短路返回 0，避免 `Log(0)` 产生 `-Infinity`/`NaN`——`NaN` 会让 `DataContractJsonSerializer` 产出非法 JSON，进而破坏整个页面数据。
5. **前端渲染**：head 新增 `genome-entropy-data` 的 `application/json` 脚本标签；第一章「分析概述」的直方图卡片之后新增三维散点图卡片与图注；新增 `initGenomeEntropyScatter3D()` 并加入 `DOMContentLoaded` 的 `charts` 数组以同步 `resize`。

### 关键决策与权衡

- **复用 `initPCAScatter3D()` 的成熟范式**：与本项目已验证可用的 PCA 三维图保持完全一致的实现方式（`grid3D + scatter3D + visualMap`、`viewControl` 旋转缩放、容器 600px）。这是复用既有模式而非引入新模式，可显著降低风险。
- **扩展可用性校验禁止使用 `echarts.gl`**：`echarts-gl` 2.x **不会**定义 `echarts.gl`，用它探测会把扩展误判为未加载（本项目此前踩过该坑）。统一采用「渲染后校验 `chart.getOption().grid3D` 是否生效」这一版本无关的可靠方式，并在 `setOption` 外层加 `try/catch` 兜底 WebGL 不可用的情况。
- **三维维度不做强制降级**：与 PCA 图不同，本次三个维度由用户明确指定，因此**不引入自动换轴逻辑**；若某维度在当前数据上为常量（见下方数据事实），仍按需求照做，由前端的 `min/max` 保护避免 visualMap 退化。着色维度与坐标轴语义在 tooltip 与图注中明确标注。
- **对数底数**：`entropy.md` 中 `log` 未指定底数，实现采用自然对数 `Math.Log`，并在代码注释与坐标轴标题中避免引入易混淆的单位（轴名为「基因存在/缺失均衡度 H」）。若后续需改为以 2 为底（bits），仅需将 `Math.Log` 替换为 `Math.Log(x, 2.0)`。
- **彻底不回归**：不改动 `PanGenomeResult`、归档格式与 `GenerateReport`/`DefaultHtmlReport` 公共签名；旧归档可直接生成含该图表的报告。

### 性能与可靠性

- 熵计算复杂度为 `O(存在的家族条目数)`，即 `O(Σ 每个家族的基因组出现数)`，远优于 `O(基因组数 × 家族数)`；上千基因组量级下无压力。
- 前端数据量仅 `O(基因组数)`（每点 6 个数值），JSON 体积可忽略。
- 全部异常路径（数据为空、计算抛异常）统一返回空数据集并由前端显示 `no-data`，报告生成过程不因此失败。

### 架构设计

```mermaid
flowchart TD
    A[PanGenomeResult.PAVMatrix + GeneFamilies] --> B[逐家族遍历, 统计各基因组存在家族数 K]
    B --> C[计算香农熵 H = -(p.log p + 1-p.log 1-p)]
    D[GenomeStatRow: specificCount / coreRatio] --> E[维度2 特有基因占比]
    D --> F[维度3 核心基因占比]
    C --> G[组装 GenomeEntropyDataset]
    E --> G
    F --> G
    G --> H[JsonContract.GetJson + EscapeJsonForHtml]
    H --> I[Report.html: script type=application/json id=genome-entropy-data]
    I --> J[readJsonData + JSON.parse]
    J --> K[ECharts GL: grid3D + scatter3D + 图注文本]
```

## 实现注意事项

- **熵计算必须按「家族 → 出现的基因组」方向遍历**，只对 `Value > 0` 的条目做哈希查找，禁止写成基因组 × 家族的双循环。
- **数值安全**：`p` 必须夹紧到 `(0, 1)` 开区间之外时短路返回 0；`geneCount = 0` 时 `specificRatio` 取 0；任何分支都不得产生 `NaN`/`Infinity`。
- **维度2 的口径**：明确使用 `GenomeStatRow.specificCount / GenomeStatRow.geneCount`（与现有统计表「特有基因数」列一致），单位为百分比，保留两位小数由前端 `toFixed(2)` 处理。
- **不新增 ANOVA 等依赖**：本功能纯数值计算，不涉及 PCA，无需任何新引用。
- **图注文本内容**需覆盖 `entropy.md` 方法 1 的要点：公式与符号定义（N、K、p、H）；作为基因组可塑性的代理指标（核心基因占绝对多数时 p 通常很高，如 0.8 以上；p 越偏离 0.5 熵越低；通过水平基因转移获得大量附属基因使存在/缺失趋于均衡时熵升高）；识别极端基因组（熵极低者多为生活在高度稳定、封闭环境的内生菌或专性寄生菌，经历大量基因丢失与基因组缩减；熵较高者可能是生活在土壤、肠道等复杂环境、拥有庞大附属基因库的泛化种）；并说明三轴含义与每个点代表一个基因组。
- **前端鲁棒性**：`pcaData` 同级的默认对象需覆盖全部字段，避免 `undefined` 参与运算；`visualMap` 的 `min === max` 时按 `min` 与 `min+1` 处理，避免颜色映射退化。
- **禁止使用 `echarts.gl` 做能力探测**（echarts-gl 2.x 不定义该属性），统一用渲染后 `grid3D` 校验。
- **不回归**：既有 10 个图表、`.heatmap-frame` 固定 800px、全屏热图模态框（关闭按钮/Esc/点击遮罩）、统计表搜索与直方图联动、PCA 三维图必须全部保持正常。
