EnzymeTiers

Description

酶可得性层级（酶可得性评分的代理指标；数值越小代表越容易找到可用酶）。

readme.md §4 中"酶可得性"本应基于反应指纹与序列数据库比对（Selenzyme / BridgIT）， 本库以层级代理简化：酶得分 = mean(1/tier)。
