GEARSTrainer

Description

GEARS 模型训练器

训练流程严格对应 readme §7.2 的伪代码： 构建扰动标记 p（组合扰动为 multi-hot）；构建初始节点特征 h0 = [x̄ ‖ p ‖ e ‖ z_pert]；多层消息传递；解码得到 Δ 预测，损失取 MSE(Δ̂, Δ)；反向传播并用 Adam 更新参数。

归一化约定：输入表达按基因做 Z-score（减 controlMean 除 controlSD）， Δ 标签同样除以 controlSD。预测时把 Δ̂ 乘回 controlSD 即可还原到原始表达尺度。
