psRNATarget

Description

psRNATarget 小RNA靶标预测算法实现。

采用反向互补比对：miRNA 经 RNA 反向互补后作为正向 query 与 mRNA 做 Smith-Waterman 局部比对，再依据位置加权罚分体系计算期望值（Expectation）。 期望值越低代表互补质量越好。 支持 V1（2011）/ V2（2017，默认）两套 Schema。
