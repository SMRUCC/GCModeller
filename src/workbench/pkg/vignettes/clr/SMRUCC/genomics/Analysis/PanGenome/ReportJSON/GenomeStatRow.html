GenomeStatRow

Description

泛基因组报告页面所使用的 JSON 数据模型。

这些类型会通过 JsonContract 被序列化为 内嵌到 HTML 页面之中的 JSON 数据。属性名称即为前端 JavaScript 读取时使用的键名， 因此这里刻意采用 camelCase 命名，以保持与模板脚本中的读取代码一致。

注意：DataContractJsonSerializer 不支持匿名类型， 所以这里必须使用具名的 Public 类型；同时只有 Public 属性(不含字段)会被序列化。

# namespace SMRUCC.genomics.Analysis.PanGenome.ReportJSON
export class GenomeStatRow {
   coreRatio: double;
   geneCount: integer;
   name: string;
   specificCount: integer;
}
