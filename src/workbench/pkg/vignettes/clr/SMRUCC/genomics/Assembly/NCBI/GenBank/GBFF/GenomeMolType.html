GenomeMolType {SMRUCC.genomics.Assembly.NCBI.GenBank.GBFF} .NET clr documentation

GenomeMolType

Description

The molecule type of the target genbank record.(目标genbank记录所描述的分子的类型)

判定策略参考 moltype.md 文档：source 限定符(结构化) > mol_type 语义 > DEFINITION/KEYWORDS 关键词(自由文本兜底) > Unknown。

注意 /mol_type 只区分 DNA/RNA，不区分核基因组/质粒/细胞器：INSDC 明确规定 organelle 与 plasmid DNA 也使用 genomic DNA，所以不能够依赖这个限定符做分子定位的判定。

Declare

            
# namespace SMRUCC.genomics.Assembly.NCBI.GenBank.GBFF
export class GenomeMolType extends Enum {
   # 无法判定目标记录的分子类型，需要人工核查
   Unknown: GenomeMolType = 0;

   # 核基因组：染色体基因组或者WGS组装的基因组序列
   Nuclear: GenomeMolType = 1;

   # 质粒基因组
   Plasmid: GenomeMolType = 2;

   # 线粒体基因组(含kinetoplast)
   Mitochondrion: GenomeMolType = 3;

   # 质体基因组：叶绿体chloroplast / apicoplast / chromatophore / nitroplast等
   Chloroplast: GenomeMolType = 4;

   # 其他的细胞器基因组，例如hydrogenosome / nucleomorph等
   OtherOrganelle: GenomeMolType = 5;

   # 病毒(含噬菌体)基因组
   ViralGenome: GenomeMolType = 6;

   # RNA基因组
   RnaGenomic: GenomeMolType = 7;

   # 转录本或者其他非基因组RNA：mRNA/tRNA/rRNA/ncRNA等
   Transcript: GenomeMolType = 8;

}
