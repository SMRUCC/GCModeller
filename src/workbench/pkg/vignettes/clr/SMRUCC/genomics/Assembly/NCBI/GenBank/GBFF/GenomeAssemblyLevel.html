GenomeAssemblyLevel

Description

The genome assembly level of the target genbank record.(目标genbank记录所对应的基因组组装水平)

判定策略参考 complete_genome.md 文档，按照可靠性从高到低组合： WGS accession 格式 > 草图关键词(contig/scaffold/draft/shotgun) > 完整信号(Genome Representation :: Full / DEFINITION complete / Finishing Goal) > assembly_gap > /chromosome 限定符。

Declare

            
# namespace SMRUCC.genomics.Assembly.NCBI.GenBank.GBFF
export class GenomeAssemblyLevel extends Enum {
   # 无法判定目标记录的组装水平，需要人工核查
   Unknown: GenomeAssemblyLevel = 0;

   # 完整组装：COMMENT 之中声明了 Genome Representation :: Full，或者 DEFINITION 之中 声明了 complete genome / complete sequence
   CompleteGenome: GenomeAssemblyLevel = 1;

   # 染色体级组装：并没有明确的 complete 声明，但是存在有 /chromosome 限定符， 例如ENA风格的 "genome assembly, chromosome: I" 记录
   ChromosomeLevel: GenomeAssemblyLevel = 2;

   # scaffold 级别的草图组装，包含WGS记录与声明了 scaffold/draft/shotgun 的记录
   Scaffold: GenomeAssemblyLevel = 3;

   # contig 级别的草图组装
   Contig: GenomeAssemblyLevel = 4;

}
