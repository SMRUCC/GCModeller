blastn_filter {miRNA} R Documentation

对 blastn 预筛结果做 psRNATarget 风格的打分过滤。

Description

Usage

blastn_filter(blastn,
    evalueCutoff = 1000,
    maxExpectation = 5,
    minHitLength = 17,
    seedStart = 2,
    seedEnd = 13,
    maxSeedMm = 2,
    maxTotalMm = 8,
    maxGu = 7,
    verbose = FALSE);

Arguments

blastn

由 parse_blastn 或 mirna_blastn

evalueCutoff

BLAST e-value 预筛阈值（与 blastn 命令行 -evalue 同量级）。 注意它与 maxExpectation. [as double]

maxExpectation

[as double]

minHitLength

[as integer]
