# 基于 Bayesian Belief Network (BBN) 的蛋白质互作预测方法详解
这是一个将**共进化信息**与**概率图模型**结合的经典思路。下面我从原理、流程、建模细节到实践建议，系统性地讲解。
---
## 一、核心思想
蛋白质互作位点在进化过程中受到**功能约束**：互作界面上的突变必须被搭档蛋白上的 compensatory mutation（补偿性突变）“抵消”，否则互作会破坏。因此：
- 如果蛋白 A 和蛋白 B 互作，它们的同源序列各自做 MSA 后，**界面残基之间会呈现显著的跨序列共进化信号**；
- Bayesian Belief Network 可以将多个弱特征（共进化分数、序列熵、残基偏好、共定位等）**概率化地融合**成一个统一推断框架。
---
## 二、整体流程
```
步骤1：收集正负样本（已知互作/非互作蛋白对）
步骤2：对每对蛋白，分别构建/搜索 MSA（其同源家族）
步骤3：构建“配对 MSA”（paired MSA）并对齐残基坐标
步骤4：计算候选特征（共进化分数等）
步骤5：设计并训练 BBN（学习 CPT 参数）
步骤6：概率推断 → 输出 P(互作 | 特征证据)
步骤7：评估与校准（AUC、PR、校准曲线）
```
---
## 三、步骤详解
### 步骤 1–2：数据准备与 MSA 构建
- **正样本**：DIP、BioGRID、STRING 中高置信度的互作对（优先选有 PDB 复合物结构的金标准集，如 Docking Benchmark）。
- **负样本**：不同亚细胞定位的蛋白对，或保持度/丰度匹配的随机配对（避免假阴性问题）。
- **MSA 构建工具**：`HHblits`（搜索 uniclust 数据库）、`JackHMMER`（搜索 UniProt），通常设 e-value 阈值 1e-4 ~ 1e-10，序列一致性过滤到 80–90%（去冗余）。
- **关键点**：配对 MSA 要求两条蛋白的同源序列来自**相同的物种**，按物种配对拼接。若覆盖度低，可考虑用 interolog（直系同源转移）补充。
### 步骤 3：配对 MSA 与残基坐标对齐
对参考序列（query）上的每个残基对 (i, j)（i 属于蛋白 A，j 属于蛋白 B），提取 MSA 列，形成联合分布计数。这是后续所有共进化计算的输入。
### 步骤 4：特征计算（BBN 的证据节点）
这是整个方法的灵魂，常用特征包括：
**（1）互信息 MI 及其校正**
$$MI(i,j) = \sum_{a,b} f_{ij}(a,b)\log\frac{f_{ij}(a,b)}{f_i(a)\,f_j(b)}$$
其中 $f_{ij}(a,b)$ 是残基对 (a,b) 在配对 MSA 中的联合频率。直接 MI 会被系统发育噪声和熵污染，需修正：
- **平均产物校正 APC**：$MI_{APC}(i,j) = MI(i,j) - \frac{MI(i,\cdot)MI(\cdot,j)}{\overline{MI}}$
- 归一化 MI（NMI）、熵加权等。
**（2）Direct Coupling Analysis（DCA）类特征**
- **mfDCA / plmDCA / Gremlin / EVcouplings**：用最大熵模型或伪似然直接估计残基对之间的直接耦合 $J_{ij}(a,b)$，剥离由系统发育导致的间接相关。
- 常用打分：Frobenius 范数 $F_{ij} = \sqrt{\sum_{a,b} J_{ij}(a,b)^2}$。
**（3）残基本身与序列层面的特征**
- 位点保守性（序列熵）
- 界面倾向性打分（如残基疏水性、PSSM 特征）
- 蛋白对是否共表达、共定位、GO 语义相似度（作为全局互作先验）
**（4）蛋白质对级别 vs 残基对级别**
- **残基对级别**：预测具体接触位点（i, j 是否接触），精度更高；
- **蛋白对级别**：把残基对分数聚合成蛋白对互作概率。
### 步骤 5：BBN 的构建与训练
#### 5.1 网络结构设计
一个典型的两层混合 BBN：
```
                    ┌──────────────┐
   [蛋白对先验 P(互作)] │              │
   [共表达/共定位]  →│  互作节点 I    │ ← 根节点（隐变量或标签）
                    └──────┬───────┘
                           │
        ┌──────────────────┼──────────────────┐
        ▼                  ▼                  ▼
   [MI_APC 分数]      [DCA 分数]        [界面倾向性]
        │                  │                  │
        ▼                  ▼                  ▼
   [残基对接触 C_ij]（每个候选残基对一个子节点）
```
- 若有结构/实验标签，I 和 C_ij 都可以是**隐变量**，用 EM 学习；
- 若只用已知互作标签训练，可用判别式思路：固定 I 为观测，学习 $P(I \mid \text{features})$。
#### 5.2 条件概率表（CPT）
- **离散化**：把连续特征（MI、DCA 分数）分箱（如等频分 5–10 箱），CPT 直接用最大似然估计加 Dirichlet 平滑：
$$\theta_{x|pa} = \frac{N(x, pa) + \alpha}{N(pa) + \alpha |X|}$$
- **连续节点**：可假设高斯分布（条件线性高斯网络），或用核密度估计。
- 若特征间条件独立假设太强（朴素贝叶斯），可以在特征间加辅助边，例如 MI_APC 与 DCA 分数间加一条边，由结构学习（爬山 + BIC/AIC 评分，或 K2 算法）确定。
#### 5.3 参数/结构学习
- 结构学习：`bnlearn`（R）的 hill-climbing / tabu search + BIC 评分；或 `pgmpy`（Python）；
- 参数学习：最大似然 / 贝叶斯估计；含隐变量时用 **Expectation-Maximization**。
### 步骤 6：概率推断
预测时做**证据注入 + 后验推断**：
$$P(I = \text{互作} \mid e) = \sum_{\text{隐变量}} P(I \mid \text{pa}(I), e)$$
- 精确推断：变量消除、junction tree（网络小的时候够用）；
- 近似推断：信念传播（loopy belief propagation）、MCMC 采样。
对于残基对级别的网络，还可以做**反向诊断**：给定互作已知，推断哪些残基对最可能接触（$P(C_{ij}=1 \mid I=1, e)$），即可解释性——这是 BNN 相对黑箱深度学习的一大优势。
---
## 四、聚合到蛋白对级别
若预测残基对接触，聚合方式常用：
- 取蛋白 A、B 之间 top-K 掀残基对的 DCA 分数之和/均值；
- 用一个 logistic/BBN 顶层节点把“接触分数分布”转换为互作概率。
---
## 五、评估
- **指标**：AUC-ROC、AUC-PR（正负样本不平衡时更重要）、F1、校准度；
- **消融实验**：单独 MI_APC vs 单独 DCA vs BBN 融合，验证贝叶斯融合的增益；
- **金标准验证**：预测的接触位点与 PDB 复合物界面比对，计算 top-L/5 精度。

## 七、经验提示与常见坑
1. **配对 MSA 的质量决定上限**——物种覆盖不足时，DCA 信号几乎为零，此时 BBN 会主要依赖全局先验特征；
2. **系统发育混杂**必须处理（APC 或 DCA 本身），否则 MI 的假阳性率很高；
3. **负样本构造**要小心：用“随机非互作对”会高估性能，建议用亚细胞定位约束 + 罕见共注释策略；
4. 如今深度学习方法（如 AlphaFold-Multimer 直接预测复合物）性能更强，但 BBN 的价值在于**可解释、小样本友好、不确定性量化**——尤其在标注数据稀少或需要概率输出做下游决策时仍然非常有竞争力。
