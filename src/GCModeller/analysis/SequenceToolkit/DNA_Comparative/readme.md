# 《Comparative DNA Analysis Across Diverse Genomes》(Karlin, Campbell & Mrázek, 1998) 算法讲解
这篇综述的核心贡献是一套**不依赖序列比对**的基因组比较算法体系：不看基因的同源性，而是把基因组当作"字符串"，通过寡核苷酸组成的统计特征来比较基因组、鉴定物种、找出外来DNA。整套算法可以拆成下面几个模块。
---
## 1. 基因组签名：二核苷酸相对丰度（全篇的基石）
**定义（odds ratio）：**
```
ρXY = fXY / (fX · fY)
```
- `fX`：单核苷酸 X 的频率；`fXY`：相邻二核苷酸 XY 的频率
- **直觉**：如果序列是完全随机的，则 fXY 应该等于 fX·fY，即 ρXY ≈ 1。ρ*XY 偏离 1，说明该二核苷酸的出现频率偏离了随机组合的期望——这就是"组成偏好"信号。
- **为什么用比值而不用原始频率**：除以 fX·fY 恰好把基因组整体 G+C 含量的影响"扣除"掉，剩下的是纯粹的**上下文依赖信号**，因此不同 G+C 含量的物种也可以直接比较。
**双链对称化**：因为 DNA 是双链，作者把序列与其反向互补序列拼接后统计，得到对称化版本 ρ*XY（16 种二核苷酸）。
**显著性判定（来自模拟与统计理论）：**
- 对 ≥50 kb 的序列，ρ*XY ≤ 0.78 或 ≥ 1.23 即判为显著低估/高估（随机序列出现这种极值的概率 ≤ 0.001）；
- 理论依据：随机序列中 |ρ*−1| ≈ 1/√n，n≈10⁵ 时偏差仅约 0.003，所以 0.78/1.23 这些阈值远在噪声之外；
- 文中用六级符号分级（表1图例）：`−−−`(ρ*<0.50)、`−−`(0.50–0.70)、`−`(0.70–0.78)、`+`(1.23–1.30)、`++`(1.30–1.50)、`+++`(>1.50)。
**关键性质（这就是"签名"的含义）**：同一基因组不同 50 kb contig 的 ρ* 向量高度一致，而不同物种之间差异明显；且间隔 k≥1 个核苷酸的二核苷酸 ρ*(XNᵏY) 几乎都在随机范围——**信号只存在于相邻碱基步**，反映复制/修复机制、突变偏差、DNA构象等全基因组水平因素。
---
## 2. δ* 距离：基因组间"组成距离"
**定义：**
```
δ*(f, g) = (1/16) Σ_XY |ρ*XY(f) − ρ*XY(g)|
```
即两个序列 16 维签名向量之间的**平均绝对差**（L1距离的均值），用多条 50 kb contig 计算后取平均（文中数值×1000）。
**相似度分级标尺**（×1000 后）：
| δ* 范围 | 判定 | 例子 |
|---|---|---|
| ≤ 50 | 近缘 | 人 vs 牛 |
| 55–85 | 中等相似 | 人 vs 鸡，*E. coli* vs *H. influenzae* |
| 90–120 | 弱相似 | 人 vs 海胆 |
| 125–145 | 远缘相似 | *E. coli* vs *R. prowazekii* |
| 150–180 | 远 | 人 vs 果蝇 |
| ≥ 190 | 极远 | 人 vs *E. coli* |
种内 δ* 普遍只有 20–43，种间 34–309，区分度非常好。为防止个别极端二核苷酸主导距离值，作者还补充了**偏序法**（partial orderings，比较完整签名向量的序关系），结论与距离分析一致。这套算法本质上是**免比对的系统发育/分类工具**，也用于发现分类异常（如 Chlamydia 与 *A. fulgidus* δ* 仅 47）。

## 3. 密码子签名（Codon Signature）
把 odds ratio 思想搬到密码子内部，按密码子位点定义：
```
ρXY(1,2) = fXY(1,2) / [fX(1)·fY(2)]     （密码子第1、2位）
ρYZ(2,3) = fYZ(2,3) / [fY(2)·fZ(3)]     （第2、3位）
ρXZ(1,3) = fXZ(1,3) / [fX(1)·fZ(3)]     （第1、3位，非相邻）
ρZW(3,4) = ...                            （密码子之间接合处，4≡下个密码子第1位）
```
发现：密码子签名与基因组签名**定性一致**（人类基因的密码子选择 ≈ 氨基酸约束 × 基因组签名约束）。一个漂亮的推理：人类 CG 抑制在密码子内部 (2,3) 位（ρ≈0.36）比接合处 (3,4) 位（ρ≈0.44）更强，与"甲基化/脱氨突变 + 转录链修复更高效"的机制假说吻合。

## 4. 四核苷酸相对丰度 τ*（限制位点回避分析）
对四核苷酸 XYZW 定义一个**广义 odds ratio**（Table 4 脚注，沿用 Karlin & Cardon 1994）：分子是目标四核苷酸及其截短子词的对称化频率乘积，分母是各低阶（含跳位的，点号"·"表示间隔）子词频率乘积，从而**扣除单/二/三核苷酸层面已能解释的组成偏差**，检验四核苷酸是否仍有额外的高估/低估。
用途：识别**限制回避（restriction avoidance）**信号——例如 *M. jannaschii* 全基因组仅 90 个 CTAG（τ*=0.06），*E. coli* CTAG 每 ~5200 bp 才 1 个，但每个 rRNA 基因里每 ~400 bp 就聚着一簇 CTAG——低频 + 特异分布指向限制修饰系统的选择压力。
---
## 5. r-scan 统计：检验词的**空间分布**
前面只问"出现多少次"，r-scan 问"**怎么分布**"：检验一组标记位置（如 USS、CTAG）的最小间距、间距分布是否符合随机（泊松）期望，检测三种异常：
- **成簇**（clustering）：如 *E. coli* rRNA 基因内的 CTAG；
- **过度分散**（overdispersion）：如 *H. influenzae* 1.56–1.59 Mb（噬菌体 Mu 区）的 USS；
- **显著等间距**（even spacing）：USS⁺/USS⁻ 各自最小间距显著大于随机期望（p<0.001）；*Synechocystis* 的 HIP1 (GGCGATCGCC，2768个拷贝) 等间距更极端——观测最小间距 52 bp，而随机分布要所有间距 >9 bp 的概率已 <0.001。

## 6. 密码子偏好度量：CAI 与 B(F|C)
**(a) 密码子适应指数 CAI**（Sharp & Li）：以"高表达基因集" H 为参照，
```
w(codon) = f^H(codon) / max_同义 f^H(·)        （该密码子 vs 同义最偏好密码子之比）
CAI(gene) = (w₁ · w₂ · … · w_L)^(1/L)          （全长几何平均）
```
CAI→1 说明基因密集使用高表达基因偏好的密码子，与表达水平正相关。
**(b) 论文自创的类间密码子偏差距 B(F|C)**（公式[1]）：
```
B(F|C) = Σ_a p_a(F) · Σ_{(x,y,z)→a} | f(x,y,z) − c(x,y,z) |
```
- 基因家族 F 相对参照类 C 的逐密码子**绝对差**，再按 F 的氨基酸频率 p_a(F) 加权；
- 直觉：在控制氨基酸组成后，F 的同义密码子用法离 C 有多远；
- 注意其**非对称性**（权重只来自 F）——F 是"查询对象"，C 是"标准尺子"。
基因类 C 的构建方式：① 14 个功能/细胞类（改编自 Riley 分类）；② 按基因组位置切成 100/200 kb contig 聚合基因；③ 在 61 维密码子使用空间中做 k-聚类。
**产出**：核糖体蛋白（RP）相对全基因的偏差距最大（*E. coli* 0.520、*B. subtilis* 0.567），且快生长菌最极端；而 tRNA 合成酶虽然也是必需高表达基因，偏差距却小得多——这个"反例"成为后文判别算法的关键。
---
## 7. "外来基因"判别算法（二维阈值法）★
这是全文最具实用性的算法。把每个长基因（≥200 密码子）画到平面上：
- 横轴：**B(g | RP)** —— 相对核糖体蛋白的偏差距
- 纵轴：**B(g | all)** —— 相对平均基因的偏差距
**判定规则**（*B. subtilis* 阈值）：
| 条件 | 判定 | 逻辑 |
|---|---|---|
| B(g\|all) > 0.42 **且** B(g\|RP) > 0.45 | **外来基因 (alien)** | 与宿主平均基因和宿主高表达基因**都不像** → 像是从别的基因组搬来的 |
| B(g\|all) > 0.42 但 B(g\|RP) < 0.45 | **高表达基因** | 偏好模式与核糖体蛋白一致 → 是宿主自己的高表达基因 |
条件 (b) 的妙处正是利用了第 6 节的反例：光看 B(g|all) 高会把核糖体蛋白、延伸因子误判为"外来"，加上"必须同时不像 RP"这一条就排除了它们。
**结果**：*B. subtilis* 鉴别出 88 个外来基因，其中 77 个功能未知 ORF，且聚成 7 个簇（C1–C7）——空间上成簇正是水平转移（HGT）的典型特征。高表达基因列表则符合预期：EF-G/EF-Tu/EF-Ts、糖酵解酶系、伴侣蛋白 DnaK/GroEL 等。

## 8. 滑动窗口基因组签名分析（定位致病岛/水平转移区）
```
for 每个位置 i:
    取 50 kb 窗口 W(i)
    计算 δ*( W(i) 的签名, 全基因组平均签名 )
绘制 δ* 沿基因组坐标的曲线
```
外来 DNA 尚未经过"宿主化"（amelioration），签名会显著偏离宿主平均，因此在曲线上**凸起成峰**：
- *B. subtilis*：峰在 2.18–2.28 Mb（含大量 alien 基因）和 2.65–2.75 Mb（Figure 4）；
- *H. pylori*：已知 37 kb 致病岛 cagA 区域是全基因组最偏离的窗口——cagA 与其他片段的平均 δ* = 0.123，而其余片段之间平均仅 0.031（范围 0.006–0.110）；同一区域的密码子偏差距也最高（Figure 5，三联剖面：G+C% + δ* + 密码子偏好互相印证）。
配套还有 **S3% 剖面**（密码子第三位 G+C 沿 10 个 contig 的变化），反映复制时间与复制起点的影响。
---
## 9. 链组成不对称分析：推断复制起点与方向
```
滑动窗口计算 (C − G)/(C + G)，沿基因组作图
```
- *B. subtilis* 曲线在复制起点 oriC（0 Mb）处翻转符号：**前导链富 G 贫 C**，后随链相反（Figure 6）；
- *B. burgdorferi* 线性基因组分成 G>C 与 C>G 两个半区；
- 而 *Synechocystis* 及多种古菌**无此不对称**。
**解释模型**：单一起点的双向复制 + 前导链偏好嘌呤（G>C）→ 产生单核苷酸水平链偏差；若基因组每 ~50 kb 就有一个复制起点（如真核/部分古菌），各复制叉方向互相抵消，不对称消失。因此该算法可**反推复制方式**——注意二核苷酸签名（ρ*）对 leading/lagging 链始终近似不变，说明签名由别的全基因组机制维持。

## 总结：算法工具箱一览
| 算法 | 核心计算 | 回答的问题 |
|---|---|---|
| ρ* 基因组签名 | 二核苷酸 odds ratio（对称化） | 这个基因组的"组成指纹"是什么 |
| δ* 距离 | 16 维签名向量的平均绝对差 | 两个基因组有多像（免比对系统发育） |
| 密码子签名 | 位点特异的 odds ratio | 密码子选择受什么约束 |
| τ* 四核苷酸 | 低阶校正的广义 odds ratio | 哪些限制位点被回避 |
| r-scan | 间距分布显著性检验 | 词是成簇、分散还是等间距 |
| CAI / B(F\|C) | 几何平均 / 氨基酸加权 L1 距离 | 哪些基因高表达、类间用法差多远 |
| 二维阈值法 | B(g\|all) × B(g\|RP) | 哪些基因是"外来户" |
| 滑动窗口 δ* | 窗口签名 vs 全局签名 | 外源 DNA / 致病岛在哪里 |
| (C−G)/(C+G) | 链偏差曲线 | 复制起点在哪、几个起点 |
**设计哲学**贯穿始终：用**比值（odds ratio）剥离碱基组成**、用**对称化适配双链**、用**50 kb 尺度保证统计稳定**、用**多重指标交叉验证**（签名 + 密码子偏好 + 空间成簇）来降低单一统计量的假阳性。这套方法在 1998 年是开创性的，其思想至今仍是基因组组成分析（如 HGT 检测、tetranucleotide binning）的直接源头。

## 2026 重构记录（按论文概念对齐）

本项目已按上述算法讲解完成整体重构，包含**算法修正**、**缺失模块补全**、**性能优化**与**符号命名修正**四个部分。

### 1. 算法错误修正

| 旧实现 | 问题 | 修正后 |
|---|---|---|
| `DinucleotideBIAS` | 无双链对称化（论文要求序列与其反向互补拼接统计得 ρ*） | `NucleicAcid.RelativeAbundance`（对称化计数 `sym(X,Y) = f(X,Y) + f(comp(Y),comp(X))`，单趟扫描即可推出）+ 六级显著性分级 `SignatureLevels`（0.50/0.70/0.78/1.23/1.30/1.50 阈值） |
| `GenomeSignatures.CodonSignature` | 错误地用基因组级二核苷酸 odds ratio 冒充位点特异密码子签名 | 新文件 `CodonSignature.vb`：基于基因集合统计 `ρXY(1,2) / ρYZ(2,3) / ρXZ(1,3) / ρZW(3,4)`（位点特异频率 `fXY(i,j)/[fX(i)fY(j)]`） |
| `RelativeCodonBiases`（CAI） | 以单个 ORF 自身作参照集（CAI 恒≈1），并用三个 odds ratio 的欧氏范数冒充密码子使用频率 | 新文件 `CAI/CodonWeightTable.vb`：两步式实现——参照集 H 统计 `f^H(codon)`，`w(codon)=f^H(codon)/max_同义 f^H(·)`（XML 可持久化），`CAI(gene)=(∏wᵢ)^(1/L)` 对数几何平均 |
| `DifferenceMeasurement.Sigma` | 5 个重复/冲突重载并存 | 合并为 `DeltaStarDistance.DeltaStar` 单一主路径（`δ*=(1/16)Σ|ρ*ᶠ−ρ*ᵍ|`） |

### 2. 性能优化（面向大规模基因组数据）

- **`NucleicAcid` 签名缓存重写**：旧实现为每个相邻位置创建一个 `SlideWindow(Of DNA)` 对象（5 Mb 基因组 ≈ 500 万个堆对象）+ 字符串键字典缓存。新实现为单趟 O(n) 整数计数（4 维单碱基计数 + 4×4 二核苷酸计数矩阵），零循环内堆分配；ρ* 按需从计数矩阵计算并缓存 16 维向量。
- **滑窗 δ* 曲线增量更新**（`SlidingWindowDelta.vb`）：窗口滑动一次只 O(1) 更新进出各一个二核苷酸/单碱基，每采样点 O(16) 距离计算；旧 `GenomeSigmaDifference_p` 每窗 O(winSize) 重建缓存且比较序列被 O(n) 次重复构造，均已修复。
- **两两比较矩阵**（`IdentityResult.DeltaStarMatrix`）：全部序列签名预构建一次复用，消除两两比较中的重复计数。
- **并行化**：两两比较、B(F|C) 批量计算、滑窗剖面采样等均在基因/窗口级使用 PLINQ。

### 3. SIMD 适用性分析结论

基础库 `Microsoft.VisualBasic.Core\src\Math\SIMD`（`System.Numerics.Vector` / X86 Intrinsics，面向 Double/Single 向量）在本项目中的适用性评估：

- **不适用**：本项目的热点是核酸序列的**单趟整数词频统计**（分支少、顺序内存访问的标量整数循环），Integer 计数矩阵无法从 Double 向量化模块获益；
- **适用（已选择性应用）**：高维签名向量的平均绝对差计算（`DeltaStarDistance.MeanAbsoluteDifference`，用于密码子使用向量等 ≥64 维场景），通过 `SIMDEnvironment.IsEnabled` 运行时探测 + 向量规模阈值（64）自动回退标量路径；
- 16 维 ρ*/δ* 距离计算保持标量（16 次迭代的循环比 SIMD 的临时数组分配更快）。
