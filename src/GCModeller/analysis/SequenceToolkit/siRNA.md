psRNATarget、TargetFinder这两款软件的算法核心都是**基于植物小RNA与靶标mRNA之间的近完美反向互补配对进行局部比对，再通过位置加权罚分体系量化互补质量**。psRNATarget在此基础上引入了靶标位点可及性的热力学评估，而TargetFinder则更侧重于严格的位置加权罚分。以下将逐层拆解其算法细节。
---
## 一、psRNATarget 算法细节
psRNATarget的分析流程分为两个核心步骤：**互补配对比对**和**靶标位点可及性评估**。
### 1. 序列比对引擎
psRNATarget后端使用 **`ssearch36`**（FASTA软件包组件），该程序实现了经SSE2加速的 **Smith-Waterman局部比对算法**。相较于BLAST等启发式算法，Smith-Waterman是确定性动态规划算法，能保证找到最优的局部比对，尤其适用于成熟miRNA这类短序列（20–22 nt）与长cDNA序列之间的精确比对。
具体而言，对于给定的miRNA序列 $S = s_1s_2...s_n$ 和候选靶标序列 $T = t_1t_2...t_m$，Smith-Waterman构建一个 $(n+1)\times(m+1)$ 的得分矩阵 $H$，递推公式为：
$$H_{i,j} = \max\begin{cases} H_{i-1,j-1} + \delta(s_i, t_j) \\ H_{i-1,j} - \text{gap\_penalty} \\ H_{i,j-1} - \text{gap\_penalty} \\ 0 \end{cases}$$
其中 $\delta(s_i, t_j)$ 为碱基配对得分。psRNATarget使用**反向互补比对**：miRNA序列先被转换为反向互补链，再与靶标cDNA序列进行正向比对，从而直接找出互补配对区域。
### 2. 位置加权罚分体系
psRNATarget根据植物miRNA–mRNA配对的生物学规律，对miRNA不同位置的错配施加差异化罚分。其核心设计原则源于以下实验观察：
- **核心配对区（约第2–13位）**：错配容忍度极低，罚分最高
- **切割位点（第10–11位）**：RISC复合体剪切mRNA的位置，必须近乎完美配对
- **末端（第1、2、20、21位）及第14–15位**：错配出现频率较高，罚分相对宽松
psRNATarget提供了两套内置评分模式，用户亦可完全自定义：
#### V1 Schema（2011版）
基于早期动物miRNA研究模型，主要参数为：
- Seed区定义为**第2–8位**（源自动物miRNA的"seed区"概念）
- 对seed区错配数量**无硬性限制**
- 默认最大期望值为3.0（兼容性考虑），推荐上限为5.0
#### V2 Schema（2017版，当前默认）
基于实验验证的植物miRNA–靶标配对模式重新设计：
- Seed区扩展至**第2–13位**（涵盖中心配对区和切割位点）
- Seed区内严格限制错配数量：**不允许超过2个错配（不含G:U配对）**
- Gap开放罚分：**2分**（增加，以过滤非经典靶标）
- Gap延伸罚分：**0.5分**（降低，以兼容长bulge/loop）
- 默认最大期望值：**5.0**（可扩展至10.0）
- 靶标可及性评估：**默认关闭**（可选开启）
#### 罚分计算公式
对于miRNA–靶标比对中的每一个位置 $i$，总罚分 $E$ 可表示为：
$$E = \sum_{i=1}^{n} w_i \cdot p_i + N_{\text{gap\_open}} \cdot P_{\text{open}} + N_{\text{gap\_ext}} \cdot P_{\text{ext}}$$
其中：
- $w_i$ 为位置 $i$ 的权重系数（核心区高、末端低）
- $p_i$ 为该位置碱基配对罚分（Watson-Crick配对=0，G:U=中等，错配=高）
- $N_{\text{gap\_open}}$、$N_{\text{gap\_ext}}$ 为gap开放和延伸次数
- $P_{\text{open}}$、$P_{\text{ext}}$ 为对应罚分值
**期望值越低，代表互补质量越好，预测越可信。**
### 3. 靶标位点可及性评估
这是psRNATarget区别于多数其他工具的**独有功能**。该步骤评估小RNA需要消耗多少能量才能打开靶标mRNA局部二级结构以接触并结合靶位点。
具体实现：
- 使用 **RNAup** 程序（Vienna RNA Package）计算靶标位点的解开能
- 评估范围包括靶位点本身及其上下游侧翼序列
- 默认侧翼长度：上游17 nt，下游13 nt（基于Kertesz等人的研究建议）
- 输出值为 **UPE**（Energy to UnPair the target site），单位为kcal/mol
**生物学含义**：UPE值越低，代表靶位点周围的mRNA二级结构越松散，小RNA越容易接触并介导切割。
### 4. 翻译抑制位点判定
psRNATarget还根据Brodersen等人的研究（2008），引入了翻译抑制的判定逻辑：如果互补配对区的**中心区域**（围绕第10–11位切割位点）存在错配，则该靶标更可能被翻译抑制而非mRNA降解。用户可自定义该"中心区域"的具体坐标范围。

## 二、TargetFinder 算法细节
TargetFinder由Carrington实验室开发，是一款轻量级的Perl脚本工具，其算法设计更加直接和透明。
### 1. 序列比对引擎
TargetFinder同样使用Smith-Waterman算法，具体调用的是 **`ssearch35_t`**（FASTA35软件包的多线程版本）。
其FASTA调用参数为：
```bash
ssearch35_t -n -H -Q -f -16 -r +15/-10 -g -10 -w 100 -W 25 -E 100000 -i -U -T <threads>
```
其中关键参数：
- `-f -16`：gap开放罚分为-16
- `-r +15/-10`：匹配奖励+15，错配罚分-10
- `-g -10`：gap延伸罚分为-10
- `-i`：对query（miRNA）进行反向互补转换
- `-U`：使用RNA字母表（AUGC）
这些参数确保比对结果偏向于高度互补的短片段，而非松散的长片段。
### 2. 位置加权评分矩阵
TargetFinder的核心是其**位置依赖的加权评分系统**，直接在Perl脚本中通过哈希表实现。其评分逻辑如下：
#### 碱基配对基础罚分
```perl
# Watson-Crick完美配对（AU, UA, GC, CG）：罚分 0
# G:U wobble配对（GU, UG）：罚分 0.5
# 错配（AC, CA, AG, GA, UC, CU, AA, UU, CC, GG）：罚分 1.0
# Gap（单侧凸起）：罚分 1.0
```
#### 位置权重系数
从miRNA的**5'端开始计数**（TargetFinder代码中通过`pop`操作从比对序列的3'端逐一处理，等效于从miRNA 5'端开始遍历）：
| miRNA位置 | 权重系数 | 生物学含义 |
|-----------|---------|-----------|
| 第1位 | 1× | 5'末端，耐受错配 |
| 第2–13位 | **2×** | 核心配对区，含切割位点（10–11位），**最关键区域** |
| 第14–21位 | 1× | 3'末端区域，耐受错配 |
因此，最终某一位置的加权罚分为：
$$\text{Penalty}_i = w_i \times \text{BasePenalty}_i$$
例如：
- 第5位（权重2）的错配：罚分 = 2 × 1.0 = **2.0**
- 第5位（权重2）的G:U配对：罚分 = 2 × 0.5 = **1.0**
- 第15位（权重1）的错配：罚分 = 1 × 1.0 = **1.0**
### 3. 过滤规则
TargetFinder对每个miRNA–靶标比对施加严格的过滤条件：
```
总错配数（mismatch + G:U配对）≤ 7
严格错配数≤ 4
G:U配对数≤ 4
加权罚分总和≤ 用户设定的cutoff值
```
这些规则确保预测结果不会包含配对质量过低的候选靶标。
### 4. 额外靶位点搜索
TargetFinder包含一个 **`get_additional`** 子程序：当一个转录本被鉴定为靶标后，该程序会将已找到的靶位点区域用"N"掩蔽，然后重新搜索该转录本中是否存在**额外的靶位点**。这基于"two-hits"模型——同一miRNA在单一转录本上的多个结合位点可增强调控效率。
### 5. 输出格式
TargetFinder支持多种输出格式：
- **classic**：经典的文本比对格式，显示靶标序列、同源串和miRNA序列
- **GFF**：基因组注释格式，便于基因组浏览器可视化
- **JSON**：结构化数据格式，便于程序化处理
- **table**：表格格式，便于后续统计分析

## 三、两款软件算法对比
| 特征 | psRNATarget | TargetFinder |
|------|-------------|--------------|
| **比对算法** | Smith-Waterman (ssearch36, SSE2加速) | Smith-Waterman (ssearch35_t, 多线程) |
| **评分方案** | 多种内置Schema（V1/V2）+ 完全自定义 | 固定的位置加权矩阵 |
| **Seed区定义** | V2: 2–13位；V1: 2–8位 | 2–13位（权重2×） |
| **Seed区错配限制** | V2: ≤2个（不含G:U）；V1: 无限制 | 通过总罚分间接控制 |
| **Gap罚分** | V2: open=2, extend=0.5 | open=16, extend=10（由FASTA参数控制） |
| **G:U配对处理** | 可选等同于错配或独立处理 | 固定罚分0.5（权重区内为1.0） |
| **靶标可及性** | ✅ RNAup计算UPE（V2默认关闭） | ❌ 不评估 |
| **翻译抑制判定** | ✅ 基于中心区错配位置 | ❌ 不区分 |
| **多靶位点搜索** | ✅ 报告位点数 | ✅ 掩蔽后重新搜索 |
| **可及性阈值** | 可设置UPE上限（如25） | 无 |
| **默认期望阈值** | V2: 5.0；V1: 3.0 | 用户设定（常用4.0或5.0） |
| **性能** | 精度89%，召回率97%（拟南芥） | 精度89%，召回率97%（拟南芥） |
| **部署方式** | Web服务器 / 命令行 | 仅命令行 |
| **大数据支持** | HTML5分块上传，支持GB级数据 | 本地运行，无限制 |

## 四、参数选择建议与结果验证
### 推荐参数设置
| 场景 | 推荐工具 | 关键参数 |
|------|---------|---------|
| **常规miRNA靶标预测** | psRNATarget (V2) | Expectation ≤ 5.0, HSP size = 20, 开启靶标可及性 |
| **严格高置信预测** | TargetFinder | Score cutoff = 4.0 |
| **非经典靶标挖掘**（如含长gap） | psRNATarget (自定义) | 开放gap罚分降至1.0，期望阈值放宽至7.0–10.0 |
| **翻译抑制候选筛选** | psRNATarget | 重点关注中心区（9–12位）有错配的靶标 |
| **大规模全基因组筛选** | TargetFinder | Score cutoff = 5.0, threads = 多核 |
### 期望值/罚分阈值的意义
**罚分得分本质上是对"miRNA–mRNA互补质量"的量化评估——得分越低，互补性越强，预测可信度越高。** 具体而言：
- **Expectation ≤ 3.0**：极高置信度，几乎无假阳性（但可能遗漏部分真实靶标）
- **Expectation ≤ 5.0**：推荐常规标准，平衡了灵敏度和精确度
- **Expectation ≤ 7.0–10.0**：宽松筛选，适用于非经典靶标或假说生成
对于TargetFinder的score cutoff：
- **Score ≤ 4.0**：严格筛选，适合后续实验验证
- **Score ≤ 5.0**：标准筛选，适用于大多数情况
- **Score ≤ 7.0**：宽松筛选，适合初筛
### 实验验证策略
计算预测的靶标必须通过实验证据支持，植物领域的金标准验证方法包括：
1. **降解组测序**：在转录组水平直接检测miRNA介导的靶mRNA切割产物（5'端片段），是最可靠的验证方法
2. **5' RLM-RACE**：通过RNA连接酶介导的cDNA末端快速扩增，验证预测的切割位点（通常位于miRNA第10–11位核苷酸对应的位置）
3. **双荧光素酶报告系统**：将预测的靶基因3'UTR（或CDS区靶位点）克隆至荧光素酶下游，与miRNA前体共转化烟草/原生质体，检测荧光活性变化

## 五、算法局限性与互补使用建议
两款软件共同的局限性源于其算法假设——**植物miRNA与靶标mRNA之间存在较高程度的序列互补性**。这一假设在大多数经典植物miRNA–靶标对中成立，但对以下情况可能失效：
1. **非经典靶标**：如靶标类似物（target mimics，含有大loop结构）或仅有部分互补的靶标
2. **翻译抑制型靶标**：部分植物miRNA通过翻译抑制而非mRNA切割发挥功能，其互补模式可能有所不同
3. **协同调控**：多个miRNA同时靶向同一转录本的情况
**建议的互补使用策略**：在研究中可同时使用psRNATarget（开启靶标可及性）和TargetFinder进行预测，取两者的交集作为高置信靶标集，再通过并集拓展潜在靶标范围，最后通过降解组数据或5' RACE进行实验验证。这种策略已被多项研究证明能显著提高植物miRNA靶标预测的准确性。
