# 用液态神经网络（LNN）建模代谢网络：原理、数据、训练与产出
## 一、核心结论与适配性判断
液态神经网络（Liquid Neural Network, LNN，尤其是其代表架构 **Liquid Time-Constant network, LTC** 及其闭式变体 **CfC**）之所以适合代谢网络建模，根本原因在于它与代谢动力学的数学结构天然同构——代谢网络本质上是一组由常微分方程（ODE）刻画的连续时间动态系统，而 LNN 正是用"输入依赖的连续时间 ODE"作为神经元更新规则的网络。把代谢物浓度或代谢通量作为网络状态、把底物浓度 / 酶表达量 / 基因表达量作为外部驱动信号，LNN 就能以数据驱动的方式学习代谢系统的非线性动态，而不必像传统动力学模型那样手工指认每一个米氏常数。
LNN 相较 LSTM/GRU 的关键优势有三点：一是天然处理**不规则采样时间序列**（代谢组学实测数据的时间点常常不等间隔）；二是模型规模小（数千到百万级参数即可），在生物这种小样本场景下不易过拟合；三是"液态时间常数 τ(h, x)"使每个隐藏单元具备**自适应记忆长度**，可以同时捕捉快反应（如糖酵解）和慢反应（如转录调控引起的代谢重编程）。
一个需要明确的概念是：LNN 不是直接替代基因组尺度模型（GEM）的工具，而更适合做**中小规模代谢通路 / 子网络**的动力学代理与时空序列预测。它与近期出现的 MINN（Metabolic-Informed Neural Network）、Artificial Metabolic Network (AMN)以及结构化神经 ODE 过程（SNODEP）等工作属于同一"神经-机制混合"家族，可组合使用。

## 二、计算原理：为什么"液态"适合代谢动力学
### 1. LTC 的核心方程
LTC 把每个神经元建模为一个一阶漏积分系统，其更新规则是：
$$
\tau_i(h, x)\,\frac{d h_i(t)}{d t} = -h_i(t) + \sum_{j=1}^{N} W_{ij}\, g_{ij}(h, x) + b_i
$$
其中：
- $h_i(t)$：第 $i$ 个神经元的隐藏状态（可以对应某一**代谢物浓度**或**通量**）；
- $x(t)$：外部输入（底物浓度、酶浓度、温度等）；
- $W_{ij}$：可学习的连接权重（可解释为反应之间的耦合强度）；
- $g_{ij}(h,x)$：sigmoid 型门控（可解释为酶活或调节作用）；
- $\tau_i(h, x)$：**输入与状态依赖的时间常数**——这是 LNN 的核心创新。
矩阵化形式为：
$$
\dot{h}(t) = -\big(\tau^{-1} + f(h, x)\big) \odot h(t) + f(h, x) \odot A
$$
其中 $f(\cdot)$ 是一个小 MLP，$\odot$ 是逐元素乘。
### 2. "液态时间常数"的物理意义
把上式重新整理成**基线时间常数 + 调制项**的形式：
$$
\tau_i^{sys} = \frac{\tau_i}{1 + \tau_i \cdot f_i(h, x)}
$$
- 当门控 $f_i$ 输出**小**时，系统时间常数趋近 $\tau_i$，隐藏状态缓慢衰减 → **长期记忆**（适合慢代谢重编程）；
- 当门控 $f_i$ 输出**大**时，状态快速更新 → **快速响应**（适合秒级的酶促反应）。
这与代谢网络中"同一网络内不同反应速率常数跨越多个数量级"（stiff 系统）的特性**完全一致**，是 LNN 适配代谢动力学的数学根基。
### 3. 与传统方法的对应关系
把代谢动力学 $d\mathbf{c}/dt = \mathbf{S}\mathbf{v}(\mathbf{c}, \mathbf{e})$（$\mathbf{S}$ 为化学计量矩阵，$\mathbf{v}$ 为反应速率，$\mathbf{e}$ 为酶活性）与 LTC 对照：
| 代谢动力学术语 | LTC 对应项 |
|---|---|
| 代谢物浓度向量 $\mathbf{c}(t)$ | 隐藏状态 $h(t)$ |
| 反应速率函数 $\mathbf{v}(\mathbf{c}, \mathbf{e})$ | 门控加权和 $\sum_j W_{ij} g_{ij}(h, x)$ |
| 酶/调节因子 $\mathbf{e}(t)$ | 外部输入 $x(t)$ |
| 反应时间尺度 $k_{cat}/K_M$ | 液态时间常数 $\tau_i(h, x)$ |
| 化学计量约束 $\mathbf{S}$ | 可嵌入到损失函数或读取头中 |
### 4. CfC（Closed-form Continuous-time）变体
原始 LTC 在每一步推理都需用 Runge-Kutta 等 ODE 求解器积分，速度较慢。Hasani 等人在 2022 年提出 **CfC**，用近似解析解替代数值积分，推理速度提升 1-5 个数量级，同时保持 LTC 的自适应动态特性。建模代谢网络时，若数据量大、迭代次数多，推荐用 CfC；若追求动力学可解释性，可用原始 LTC。
### 5. LNN vs Neural ODE vs ODE-RNN
这三种模型都基于 ODE，但定位不同：
| 模型 | 连续时间动力 | 不规则采样 | 状态依赖 τ | 适用场景 |
|---|---|---|---|---|
| **Neural ODE** | ✓ | ✓（需编码器） | ✗ | 静态 ODE 学习 |
| **ODE-RNN / Latent ODE** | ✓ | ✓ | ✗ | 不规则序列，变分框架 |
| **LTC / LNN** | ✓ | ✓ | ✓（核心创新） | 需要自适应时间尺度的动态系统 |
Latent ODE/ODE-RNN 用 ODE 替换 RNN 的隐藏动态，处理不等间隔观测；而 LTC 在此基础上让 τ 本身也依赖于 $h, x$，表达力更强、稳定性有理论保证（hidden state 有界）。

## 三、数据准备清单
建模前需要按"网络结构 + 动态数据 + 先验约束"三类准备数据。下表给出 LNN 代谢建模的最小数据集要求：
| 数据类别 | 具体内容 | 来源建议 | 作用 |
|---|---|---|---|
| **网络拓扑** | 代谢物-反应邻接关系、化学计量矩阵 $\mathbf{S}$ | BiGG、KEGG、Reactome、MetaCyc；E. coli 推荐 iJO1366/iML1515 | 约束网络连接；可在损失函数中加入 $\mathbf{S}\mathbf{v} \approx 0$ 的稳态约束 |
| **动态浓度数据** | 代谢物浓度随时间的变化 $\mathbf{c}(t_k)$ | LC-MS/GC-MS 定量代谢组学；同位素示踪 | **监督信号（输出端）** |
| **驱动信号（输入）** | 底物/产物外浓度、酶表达、基因表达、环境扰动 | 转录组、蛋白组、培养基记录 | **网络输入 $x(t)$** |
| **通量数据（可选）** | ${}^{13}C$-MFA 测得的反应通量 $\mathbf{v}(t)$ | 同位素示踪实验；scFEA 从 scRNA-seq 估计 | 监督通量读取头；或作为先验 |
| **稳态/约束** | 质量守恒、能量守恒、热力学方向性 | GEM 数据库、eQuilibrator | 软约束项（PINN 风格） |
| **先验动力学参数（可选）** | $K_M$、$k_{cat}$ | BRENDA、SABIO-RK | 用于初始化 τ 或 $W$，加速收敛 |
**关键数据集参考**：
- **Ishii et al. (2007) E. coli 化学恒化器数据**：29 个实验（5 个稀释率 + 24 个单基因敲除），包含转录组、蛋白组、${}^{13}C$-MFA 通量组数据，是 MINN 等混合模型的标准基准；
- **scRNA-seq 时间序列 + scFEA 通量估计**：SNODEP 用的数据范式，适合缺少直接通量测量的场景；
- **Faure et al. AMN 数据集**：73 种培养基下 E. coli 生长率，适合作为外源驱动-生长响应建模。
**数据预处理要点**：
1. **归一化**：代谢物浓度跨越多个数量级，建议 log-transform 后做 z-score；
2. **缺失值处理**：LTC/CfC 的连续时间性质天然支持不规则观测，无需插值到等间隔；缺失时间点直接跳过即可；
3. **对齐时间戳**：把多组学数据的时间点归并到统一时间轴，为每个观测记录一个 $t_k$；
4. **批次效应**：不同批次实验需做 ComBat 或类似方法去除系统偏差；
5. **反应通量约束**：若使用 FBA 求得的通量作为目标，需注意实验测得通量可能落在 FBA 解空间之外，MINN 论文对此提出了几种缓解策略。

## 四、模型构建与训练流程
整体流程可概括为"**网络结构定义 → 节点状态映射 → 数据编码 → 损失函数设计 → 数值积分训练 → 评估外推**"。
### 1. 网络结构设计
针对代谢网络，有三种典型的 LNN 架构变体：
- **纯 LTC 序列模型**：把代谢物浓度作为多变量时序输入，LTC 作为普通时序模型学习其演化。最简单、最通用，适合缺机制先验时；
- **结构化 LTC（推荐）**：把 LTC 的连接矩阵 $W$ 用代谢网络邻接矩阵 $A_{adj}$ 做掩码（$W_{ij}=0$ 当代谢物 $i$ 与 $j$ 无反应关联），保证学习到的动态符合生化拓扑；
- **LTC + FBA 混合（类 MINN）**：LTC 产生通量初值 $V_0$，再经过一个基于化学计量约束 $\mathbf{S}\mathbf{v} \approx 0$ 的可微机制层（梯度下降精化）输出 $V_{out}$，损失同时包含数据项和约束项。
### 2. 输入输出定义
- **输入 $x(t)$**：底物/产物浓度、温度、pH、酶或基因表达量；
- **初始状态 $h(0)$**：初始代谢物浓度向量，或用编码器（如 ODE-RNN encoder）从早期观测推断；
- **输出**：代谢物浓度轨迹 $\hat{c}(t)$、通量轨迹 $\hat{v}(t)$、或生长率。
### 3. 损失函数设计（PINN 风格）
$$
\mathcal{L} = \underbrace{\|\hat{c}(t) - c(t)\|^2}_{\text{数据拟合}} + \lambda_1 \underbrace{\|\mathbf{S}\hat{\mathbf{v}}\|^2}_{\text{稳态/质量守恒}} + \lambda_2 \underbrace{\mathcal{R}_{thermo}}_{\text{热力学约束}} + \lambda_3 \underbrace{\|\hat{v} - v_{MFA}\|^2}_{\text{通量监督（如有）}}
$$
MINN 论文专门讨论了"数据驱动目标 vs 机制目标"的冲突及缓解策略，包括调整 $\lambda$ 权重、对数据先投影到 FBA 解空间等。
### 4. 数值求解与训练
- **原始 LTC**：用 `torchdiffeq` 或 `diffrax` 的自适应 Runge-Kutta（如 `dopri5`、`dopri8`）积分，代谢系统往往是 stiff 系统，建议用 `implicit_adams` 或 LSODA；
- **CfC**：无需 ODE 求解器，直接前向计算；
- **优化器**：Adam + 学习率预热；由于 ODE 求解器内部步长自适应，梯度通过伴随方法（adjoint method）回传，注意显存与梯度爆炸问题，建议梯度裁剪。
### 5. 训练技巧
- **小样本场景**：代谢数据集普遍样本少（几十条时序），LTC 参数量小是优势；可加 dropout、weight decay；
- **多任务学习**：同时预测浓度和通量，让网络学到更一致的动力学；
- **teacher forcing**：训练早期用真实历史状态作输入，后期逐步切换为模型自身预测，提升长程稳定性；
- **半监督扩展**：用 FBA 在大量虚拟培养基上生成模拟数据预训练，再用实验数据微调（Faure 等的"reservoir computing"思路）。
### 6. 代码实现路径
开源生态已较为成熟：
- **nca / LNN 官方仓库**：`mlech26l/ncps`（含 LTC、CfC 的 PyTorch/TensorFlow 实现）；
- **torchdiffeq**（Ricky Chen）：通用 Neural ODE 工具；
- **MINN**：参考 `SPICO-quantum/MINN` 类似仓库（MINN 论文有代码链接）；
- **SNODEP**：`github.com/TrustMLRG/SNODEP`；
- **代谢模型工具链**：COBRApy（FBA/GEM）、Scikit-fba；与 LTC 耦合时可把 COBRApy 的求解结果作为约束或预训练数据。

## 五、可获得的输出结果
完成训练后，LNN 模型可以产出以下几类结果，且**每项都有明确的下游应用**：
| 输出类型 | 具体形式 | 下游应用 |
|---|---|---|
| **代谢物浓度轨迹** | 每个代谢物随时间变化曲线 $\hat{c}(t)$ | 预测基因敲除后中间代谢物累积，识别毒性代谢物 |
| **代谢通量分布** | 每条反应的通量 $\hat{v}(t)$ | 代谢工程靶点识别、产物优化 |
| **动力学参数** | 学习到的 $W_{ij}$、$\tau_i$ | 反向推断未知的反应速率常数；与 BRENDA 已知参数对比 |
| **稳态/扰动响应** | 新底物或基因扰动下的新稳态 | 设计培养基、预测敲除表型 |
| **外推预测** | 未见时间点、未见扰动配置的响应 | 减少实验成本，指导 DoE（实验设计）|
| **可解释性输出** | 时间常数 τ 的变化轨迹 | 识别哪些反应在何时被"激活"或"抑制" |
### 具体应用示例
1. **基因敲除表型预测**：把敲除后的酶活性（如设为 0）作为输入扰动，LTC 外推出代谢物与生长率的稳态变化；SNODEP 论文证明这类模型在未见过的敲除配置上也能合理外推；
2. **药物靶点筛选**：把药物作用视为对某反应 $v_i$ 的抑制，预测代谢物累积造成的毒性，与 MINN 等方法对比；
3. **代谢工程优化**：在多条虚拟路径上预测产物通量，挑选最优改造组合，再用 AMN 框架做培养基优化；
4. **疾病代谢重编程分析**：癌症、糖尿病的代谢组时序数据可用 LNN 拟合，τ 的变化轨迹反映调控速度的改变。
### 模型验证方法
- **留一扰动交叉验证**：留出若干基因敲除或培养基条件做测试，评估外推能力；
- **与 FBA/pFBA 对比**：MINN 论文显示，混合模型在小样本多组学数据上优于纯 pFBA 和随机森林；
- **通量重建误差**：与 ${}^{13}C$-MFA 实测通量比较 RMSE；
- **动力学一致性检验**：用学到的参数跑传统动力学求解器（如 COPASI）看能否复现轨迹；
- **稳态约束违反度**：$\|\mathbf{S}\hat{v}\|$ 应接近 0（如用 FBA 解空间内的数据训练时）。

## 六、典型工作流小结与展望
把上面所有内容压缩成一条可执行 pipeline：
```
1. 选定代谢子网络（如糖酵解、TCA、氨基酸合成）
   ↓ 从 BiGG/KEGG 拉取化学计量矩阵 S
2. 收集时序多组学 + 代谢组 + （可选）通量数据
   ↓ log-transform, 对齐时间戳, 标记不规则观测
3. 构建结构化 LTC/CfC 网络（邻接矩阵掩码 W）
4. 设计损失：数据拟合 + S·v≈0 + （可选）通量监督
5. torchdiffeq 或 ncps 库训练；梯度裁剪 + Adam
6. 验证：留出扰动条件测外推；与 pFBA/RF 对比
7. 应用：敲除预测、靶点筛选、代谢工程设计
```
LNN 在代谢建模领域仍是较新的方向，目前公开的"LNN + 代谢"直接文献还不多，但其姊妹方法——Neural ODE Process（SNODEP）、代谢-知情神经网络（MINN）、AMN——已经在 E. coli 上验证了"连续时间神经网络 + 机制约束"范式的可行性。液态时间常数的引入会带来两方面的独特价值：一是对 stiff 动力系统的原生适配，二是 τ 作为可读出的"反应速率代理"提供额外的可解释性，这是 LSTM 类方法难以提供的。
如果要把 LNN 真正落到代谢建模上，建议从**一个 10–30 个代谢物的子网络**起步（如 E. coli 糖酵解 + TCA），用 Ishii 数据集中对应的通量与浓度子集做基准，再逐步扩展到基因组尺度。这样可以避免一开始就被全局 GEM 的复杂性淹没，也能在可控范围内验证 τ 学习到的动力学是否与已知 $K_M$、$k_{cat}$ 一致。
