## 用户需求

在当前基于动态贝叶斯网络（DBN/BN）的基因表达调控网络模拟引擎（VB.NET，BNLearn 项目）中，补充"从外部导入新检测的转录组数据并基于其进行虚拟扰动实验"的能力，并在 DEMO 中对比"导入前/后"的虚拟扰动结果差异。

## 产品概述

现有引擎已完成网络结构与参数训练，并支持基于训练数据/网络本身的虚拟扰动。但所有扰动入口均不接收外部新表达数据，无法基于用户新检测的转录组（部分基因子集）作为上下文执行扰动。本次需新增外部数据导入与两种融入模式，使扰动实验能反映"用户真实样本背景"下的因果效应。

## 核心功能

- 新增单样本向量表达文件解析：读取 gene,expression 两列表格，解析为按基因名索引的表达向量。
- 在核心工作流中维护"外部导入表达数据"（按基因名对齐，仅取与训练网络重叠的基因作为观测证据/初始状态）。
- 观测证据模式：将新数据重叠基因作为已观测证据，在给定该表达水平条件下执行虚拟扰动（do-演算 + 条件推断）。
- 动态初始状态模式：将新数据均值作为动态级联模拟（DynamicKnockout）的起始状态，模拟在用户样本背景下的级联传播。
- 更新 test/Program.vb DEMO：展示未导入新数据（理论野生型基线）与导入新数据（两种模式）后同一次虚拟扰动（如敲除 codY）的结果差异，并输出对比。

## 技术栈

- 语言/框架：VB.NET（与现有项目一致，.NET Framework）
- 依赖库：Microsoft.VisualBasic、Microsoft.VisualBasic.Data.Framework、Microsoft.VisualBasic.Linq、SMRUCC.genomics.Analysis.HTS.DataFrame（现有项目已引用）
- 复用组件：BNLearnWorkflow（核心 API）、BnInterventionAnalyzer（扰动实现）、BnInferenceEngine（含 InferEvidence 条件推断）、BnIO（数据读写）、BayesianNetwork/CloneStructure/TopologicalSort

## 实现方案

### 总体策略

在现有 BNLearnWorkflow 上扩展，不改动既有扰动语义，而是新增"外部上下文（external context）"状态与两类新入口。扰动实现层（Intervention）新增可选参数 `evidence` 与 `initialState`，缺省时退化为现有行为，保证向后兼容。

### 关键技术决策

1. **外部数据载体**：在 BNLearnWorkflow 新增属性 `ExternalExpression As Dictionary(Of String, Double)`（基因名→表达值，单样本向量）与 `ExternalEvidence As Dictionary(Of String, Double)`（对齐后仅保留与网络重叠的基因）。理由：单样本向量无需引入完整 GeneExpressionData 多维结构，轻量且贴合用户"一组均值"的数据形态。
2. **基因名对齐**：导入时调用 `FittedNetwork.GetNodeIndex(gene)` 仅保留命中网络的基因，忽略未建模基因，避免 KeyError；未命中任何基因时抛友好异常。
3. **观测证据模式**：调用现有 `BnInferenceEngine.InferEvidence`（已有 evidence 条件推断能力）计算在外部证据条件下的野生型/参考分布，再执行 do-演算获取扰动后分布，二者相减得到"基于新样本背景"的效应。复用现有推断能力，不重复造轮子。
4. **动态初始状态模式**：扩展 `DynamicKnockout` 允许传入 `initialState As Double()`（按网络节点序），外部重叠基因用其表达值初始化，其余保留现有 wildtype 基线；级联仍按拓扑序传播。
5. **性能**：对齐与字典查找 O(nGenes)；条件推断与采样复杂度 inherit 现有实现（O(nSamples·nNodes)），无新增瓶颈。仅在导入时做一次对齐，扰动调用不重复遍历。

### 避免技术债

- 不修改 `ExpressionData`（训练数据）语义，外部数据完全独立。
- 扰动公共 API 保持原有签名可用，新能力以重载/新属性暴露，避免破坏现有 DEMO 与调用方。

## 实现要点（防回归）

- 外部证据为空（未导入）时，新入口必须等价于现有 `KnockoutGene` 行为，确保 DEMO 前半段与旧逻辑一致。
- `InferEvidence` 的 evidence 字典键必须与 `FittedNetwork.Nodes(i).Name` 完全一致（大小写不敏感已在内建字典处理），导入对齐步骤统一用 `GetNodeIndex` 映射。
- 日志/输出复用现有 `Console.WriteLine`/导出方式，不新增日志框架；DEMO 中清晰标注"导入前"与"导入后（证据模式/初始状态模式）"三段对比。
