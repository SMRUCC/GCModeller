针对多组学数据做"一体化GSVA"的设想，目前已有少量接近的工作，但**直接基于"拼接好的归一化多组学矩阵 + 组学来源标签"做联合GSVA评分、并显式建模跨组学一致性的方法尚未见正式发表**，下面是梳理好的相关工作、差异定位和具体实现路径。
## 一、已有的相近工作梳理
多组学通路活性评分方向已有若干代表性工作，但它们的整合策略与目前设想的"拼接矩阵直接做GSVA"都有明显区别：
| 方法 | 文献 | 核心思路 | 整合策略 | 是否样本级打分 | 与设想的关键差异 |
|------|------|---------|---------|--------------|------------------|
| **MOGSA** | Meng et al., *Mol Cell Proteomics*, 2019 | 多组学矩阵 → MFA/STATIS矩阵分解学习潜在因子 → 在低维空间投影基因集打分 | 早期整合（矩阵分解阶段） | 是 | 用MFA降维而非GSVA的KDE+KS随机游走；打分依赖全局因子结构 |
| **MOPA** | Jeon et al., *PLoS ONE*, 2023 | 输出多组学富集评分mES与组学贡献率OCR，强调组学间调控关系 | 监督式（需要表型标签） | 是 | 需要临床/表型标签，偏监督；打分逻辑基于调控关系而非GSVA的分布变换 |
| **multiGSEA** | Canzler et al., *Bioinformatics*, 2020 | 各组学层分别做GSEA → 合并p值 | 后期整合（p值合并） | 否（队列级） | 本质仍是"分开做再合并"，正是目前想区别的范式 |
| **ActivePathways / DPM** | Paczkowska 2020 / Slobodyanyuk et al., *Nat Commun*, 2024 | 基因级p值融合 → 超几何检验 | 后期整合（p值合并） | 否（队列级） | 不输出样本级通路活性矩阵；整合在p值层面 |
| **MOFA+** | Argelaguet et al., *Genome Biology*, 2020 | 多组学因子分析学习潜在因子 → 对因子做GSVA注释 | 早期整合（因子分解） | 因子级，间接 | GSVA仅作为下游因子注释，并非直接对多组学矩阵打分 |
| **JOANA** | Amerifar et al., *Brief Bioinform*, 2026 | 贝叶斯网络 + Beta混合模型，连续建模显著性 | 概率图模型整合 | 否（队列级） | 不输出样本级评分；基于差异分析结果输入 |
**差异化定位**：现有方法要么"分开做再合并p值"（multiGSEA、ActivePathways），要么"先降维再打分"（MOGSA、MOFA+），要么"需要表型标签做监督整合"（MOPA）。目前设想的"保留组学标签的拼接矩阵上直接做GSVA式KDE+KS随机游走，并通过组学加权融合与跨组学一致性检验"这一路径，目前文献中没有直接对应实现，属于可发表的方法学空白。
## 二、核心算法设计建议
参照GSVA原算法（Hanzelmann et al., *BMC Bioinformatics*, 2013），GSVA的流水线为：**逐基因KDE估计样本级累计密度 → 分位数/秩变换 → KS-like随机游走富集打分**。将这一框架扩展到拼接多组学矩阵，关键在于在每个步骤中引入"组学来源"这一维度。建议按如下流程设计：
### 步骤1：输入规范与预处理对齐
输入为拼接矩阵 $X \in \mathbb{R}^{(N_1+N_2+\dots+N_K) \times M}$，其中 $N_k$ 为第 $k$ 种组学的特征数，$M$ 为样本数；特征标签表包含 `(feature_id, omics_source, KEGG_id)`。预处理阶段需处理：
- **量纲对齐**：不同组学（如RNA-seq的log-count、甲基化的beta值、蛋白的log2-intensity）分布形态差异大，需在KDE之前做组学特异的稳健标准化（如分位数归一化或rank-based统一到[0,1]）。
- **特征到通路的映射**：同一KEGG通路在不同组学中可能包含不同特征子集（如某基因在mRNA层有探针但蛋白层缺失），需保留 `(omics_source, KEGG_id)` 二元组作为通路×组学的索引单元。
### 步骤2：样本级分布估计（保留组学来源）
对每个特征 $i$（属于组学 $k$），在样本群体上估计其累计密度函数 $F_{i}(x)$。可直接沿用GSVA的两种核密度估计方案：
- **高斯核KDE**：$F_i(x) = \frac{1}{Nh}\sum_{m}\Phi(\frac{x-x_m}{h})$
- **经验CDF**：对样本量小的组学更稳健
关键设计点：**估计在组学内部进行，不跨组学混合**。即甲基化特征的分布只在甲基化特征群体内估计，避免不同组学的尺度差异污染密度估计。这一点是相对于"直接把拼接矩阵当单组学做GSVA"的核心区别。
### 步骤3：组学特异性富集打分
对通路 $S$ 在组学 $k$ 下的特征子集 $S_k$，基于变换后的值计算组学特异的KS-like随机游走富集得分 $ES_{k}^{(S)}(j)$，公式与ssGSEA/GSVA一致：
$$ES_k^{(S)}(j) = \max_{r}\left[\sum_{i \in S_k, rank(i)\le r} \frac{|z_{ij}^k|^{p}}{N_R^+} - \sum_{i \notin S_k, rank(i)\le r} \frac{1}{N-N_H}\right]$$
其中 $z_{ij}^k$ 为特征 $i$ 在组学 $k$ 下经过KDE变换后的样本 $j$ 的值，$rank$ 在组学 $k$ 内部排序。这一步等价于对每种组学分别做GSVA，但保留了后续融合的接口。
### 步骤4：组学加权融合策略（核心创新点）
这是目前所设想的方法相对于"分开做再平均"或"MOGSA降维打分"的核心差异。建议设计一个可配置的融合层，提供多种加权方案：
- **等权融合**：$ES^{(S)}(j) = \frac{1}{K}\sum_k ES_k^{(S)}(j)$，作为baseline。
- **方差加权**：$w_k \propto 1/\text{Var}(ES_k^{(S)})$，降低噪声大的组学权重。
- **信息熵加权**：$w_k \propto H(ES_k^{(S)})$，偏好区分度高的组学。
- **互信息一致性加权**：计算组学间 $ES_k$ 与 $ES_{k'}$ 的互信息 $I(k,k')$，对一致性高的组学组合赋予更高融合权重，并对组学间方向矛盾的通路施加惩罚。
- **跨组学一致性奖励项**：$\text{sign-agreement}(ES_1^{(S)}, \dots, ES_K^{(S)})$，当多组学对通路方向判断一致时给予奖励，矛盾时打折。这一项是已有方法（multiGSEA的p值合并、MOGSA的因子打分）都未显式建模的。
最终融合评分：$ES_{multi}^{(S)}(j) = \sum_k w_k \cdot ES_k^{(S)}(j) + \lambda \cdot C^{(S)}(j)$，其中 $C^{(S)}(j)$ 为一致性奖励项，$\lambda$ 为超参。
### 步骤5：显著性评估
- **样本级置换检验**：对每个通路，在特征标签上做随机置换（保持组学来源标签不变，只打乱feature→KEGG映射），构建零分布，计算p值。
- **组学特异性贡献分解**：输出每个通路的 $ES_{multi}$ 及其各组学分项 $ES_k$，便于下游解释"该通路活性主要由哪种组学驱动"，类似于MOPA的OCR思路但无需表型标签。
## 三、与现有方法的差异化优势
相对于已有工作，所期望构建出来的方法可主张三方面创新：
1. **保持GSVA的样本级无监督特性**：不同于MOPA需要表型标签，不同于ActivePathways/multiGSEA输出队列级p值。
2. **保留组学来源而非降维消解**：不同于MOGSA将组学信息融入MFA潜在因子后丢失显式组学身份，目前设想的框架在打分全程保留 `(omics, pathway)` 二元结构，可输出组学贡献分解。
3. **显式建模跨组学一致性**：现有p值合并方法（multiGSEA、ActivePathways）对组学间方向矛盾无感知，MOGSA的因子打分也无法区分"多组学一致上调"与"组学间互相抵消"。一致性奖励项是可主张的方法学贡献。
## 四、验证与对比策略
**数据集选择**：
- TCGA PanCan（mRNA + methylation + miRNA，9种癌型）——与MOPA/MOGSA所用数据一致，便于直接对比
- CPTAC蛋白质基因组学（mRNA + protein + phospho）——MOGSA原论文用例
- 单细胞多组学（CITE-seq）——验证扩展性
**对比基线**：
- Baseline 1：各组学分别GSVA后简单平均（"分开做再合并"的代表）
- Baseline 2：MOGSA（Bioconductor `mogsa`包）
- Baseline 3：MOPA（GitHub `jaeminjj/MOPA`）
- Baseline 4：multiGSEA（Bioconductor `multiGSEA`）
**评估指标**：
- 通路活性对临床表型（如癌型分型、生存）的预测AUC
- 通路活性矩阵对已知生物学标注的富集回收率
- 跨数据集重复性（如TCGA vs CPTAC同癌型通路活性相关性）
- 组学贡献分解的生物学合理性（如代谢通路是否主要由代谢组学驱动）
## 五、潜在风险与可借鉴的规避方案
- **拼接矩阵的尺度异质性**：若不同组学尺度差异未充分标准化，KDE会被大量纲组学主导。MOGSA通过MFA对各组学做组内标准化后再分解，可借鉴其组内标准化（每组学除以第一奇异值）作为预处理。
- **特征重叠偏倚**：若多数通路特征集中在某一组学（如mRNA），融合评分会被该组学主导。建议在融合层引入组学特征数平衡项 $w_k \propto 1/\log(|S_k|)$。
- **KEGG通路在不同组学中的覆盖不均**：某些通路在蛋白层无注释，需在设计时处理 $S_k = \emptyset$ 的情况（跳过该组学或用其他组学插补）。
- **专利与商业风险**：MOFA等部分多组学整合算法已被纳入商业分析流程（如部分云平台的多组学模块），建议在正式开发前检索Google Patents与CNIPA中"multi-omics pathway enrichment"、"gene set variation analysis multi-omics"等关键词，确认GSVA扩展式实现是否落入已有专利权利要求范围；GSVA原算法本身（Hanzelmann et al. 2013）以开源发布，扩展方法在其基础上构建通常不构成侵权，但若涉及商业发行仍需法务确认。
## 六、着手开发的实操建议
1. **先复现**：在R/Bioconductor中跑通 `GSVA` 包和 `mogsa` 包在TCGA测试集上的结果，建立baseline性能。
2. **MVP实现**：先用Python实现"等权融合"版本（步骤1-3+等权融合），验证流水线正确性，再逐步加入方差加权、一致性奖励等模块。
3. **消融实验**：每加入一个加权策略，做消融对比，量化其增益，为论文/专利提供实验证据。
4. **特征标签表设计**：建议支持多数据库（KEGG、Reactome、Hallmark），标签表schema预留 `pathway_db` 字段以扩展。
5. **输出标准化**：输出样本×通路评分矩阵 + 通路×组学贡献矩阵 + 通路显著性p值表，对齐现有工具输出格式便于下游衔接。
