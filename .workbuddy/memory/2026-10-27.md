- 图 9（`fig9_wgcna_networks.R`）：软阈值曲线 + 五张网络（β=5/12/6/7/9，
  模块 2/2/4/2/3，未归属 65/64/2/17/39%）。融合网络 top hub = TCR/TLR/TNF/

- 图 10（`fig10_network_topology.R`）：度分布 CCDF；聚类系数 0.50/0.82/0.82/0.47/0.59、
  最大连通分量 91/28/27/58/53%；模块 ARI（MET–TX 0.91、融合–TX 0.52，其余 ≤0.14）；

坑与结论：
- `layer_matrix(d, omics)` 里参数名不能叫 `omics`，会遮蔽同名列表列，导致
  dcast 出现重复行并按 length 聚合成常数（现象：SD 全为 0）。
- 不同 β 下 connectivity 不可比，节点大小只能按面板内缩放；拓扑比较必须固定边数。
- WGCNA 的 `pickSoftThreshold` 在 156 节点上会自动打印拟合表，`verbose=0` 也拦不住。

## moGSVA vs「逐组学 GSVA 后合并」的对照（2026-10-28）

新增 `compare_naive_merge.R` + `comparison_vs_merge.md`，用 layer_scores 重建等权
合并基线（含 z-score 变体），并在 285 条共同通路上与 moGSVA、池化基线三方对比。
结论（写论文时要按这个口径，否则会被审稿人打回）：

- 与**合并**基线高度等价：逐通路 Spearman ρ 中位 0.994；组件分解后，权重项
  ρ=0.9987、一致性项 ρ=0.9976 —— 两个设计主要改"幅度"不改"排序"。
- ER 命中：moGSVA 173 / 合并 185 / z 化合并 199 / 池化 135（285 条共同通路）；
  效应量 r=0.986。**"检出更强"不成立**。
- 与**池化**的差距是实质性的：最小 q 相差 17 个数量级，逐层还原 0.46–0.82 vs
  甲基化 −0.20、蛋白 0.16。
- 方差预算（156 条四层通路）：融合 = CNA 4.1 / MET 9.4 / TX 13.6 / **蛋白 72.8%**；
  等权合并 = 8.5 / 18.5 / 27.7 / 45.4。**"更均衡"也不成立**，Balanced 反而放大蛋白。
- 真正可主张：组学归因（每条通路中位 3 种主导层、42.3% 观测非众数层）、
  冲突量化（a 作置信度；a=−1/3 时合并幅度是融合的 1.36×，a=−1 时 1.67×）、
  覆盖不均显式化、全流程可审计。
